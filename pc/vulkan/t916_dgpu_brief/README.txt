目标 13 · T916 在 Windows 独显上的短测

1. 整包解压到有写权限的本地目录。使用装好 Vulkan 驱动的 Windows x64 独显 PC。程序使用该机已有的 Visual C++ x64 运行库，无需安装 Vulkan SDK 或构建工程。若缺 MSVCP140.dll／VCRUNTIME140.dll，把终端结果发回即可识别。
2. 双击 Run-Test.cmd。该步骤做 OP_48 单角色资格检查。终端出结果后查看显卡名和 OP48 返回值。观察窗口是管线进入后 60 秒，最外层进程窗口是 120 秒。
3. 确认打印的是目标独显。双显卡设备若仍选中集显，在 Windows 图形设置中为包内 hello_world_pc.exe 选择高性能 GPU 后再跑一次。测试以日志实际选中的适配器为准。
4. 只告诉我们终端最后一行 REPLY T916 的内容。OK 表示本次管线创建成功。TIMEOUT 表示本次观察期间没有返回。其他结果照抄。日志保存在本机，回传只需要这行文字。

管线在目标独显成功返回后，可在本目录的 PowerShell 执行：

    .\Run-Test.cmd -Stage Business

该可选步骤会运行 T868 冻结输入的 F02、F03、F05，终端最后一行同样可以手抄。摘要仅用于看运行到了哪一步。F03 实际接受步及 F05 的速度、压力、黏性要按原判据验证。此短测覆盖目标 13 的启动和分段定位。

可用 .\Run-Test.cmd -Stage Verify 只核工件和输入指纹，不会启动 GPU。
