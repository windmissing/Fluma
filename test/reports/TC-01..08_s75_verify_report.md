## 修复内容

SandCanvas.ets `renderFluid()` 从"行号拟合"改为"分相计数渲染"：

- 逐列统计 heavyCount（绿粒总数）/ lightCount（蓝粒总数），不再取每列"第一个沙粒/第一个绿粒"行号——CA 渗透产生的列内交错（[绿,蓝,绿,蓝]）不影响计数，根治漏画
- 高度定义：界面线 = rows - heavyS，液面线 = rows - heavyS - lightS（heavyS/lightS 为双次移动平均平滑后的计数曲线，线性变换保总量）
- 蓝带 Path = 液面曲线与界面曲线围合 → 每列蓝带面积恒等于蓝粒总数，渲染层分相体积严格守恒
- 渗入量 mixDepth（界面行以下绿区内的蓝粒数）驱动界面下方蓝绿渐变过渡带，保留"渗入感"；静置分层态 mixDepth=0，过渡带消失，与旧版视觉一致
- 未动部分：CA 物理引擎 SandGrid、FluidField/混合模式、传感器/手势/帧循环
