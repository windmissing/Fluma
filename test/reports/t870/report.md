# T870 · 首轮离线预研实验报告

**PASS。** 同一段 6 N 切向脉冲下，有法向支撑的 B 只发生贴床搬移，法向失支撑的 C 先离床、后回捕。只看切向的基线对 B、C 均报离床，B 是假阳性。静水 A 全程保持 S。两档共记录 366 个时间样本，55 项判据全部通过。 [冻结设计](../../../docs/design-T870-v1.md) · [逐项结果](summary.json) · [原始时间序列](samples.jsonl)

## 固定输入与复现

Windows 11 10.0.26200 x64，CPython 3.12.10，标准库。质量 1 kg，来源 1，种子 0，静摩擦和动摩擦系数均为 0.50。区间 0–0.40 s，步长 0.010 s 和 0.005 s。法向输入不含床反力，推进器只消费声明的切向和法向载荷。

| 用例 | 脉冲期 T、N（N） | 0.10 s 起 T、N（N） |
| --- | --- | --- |
| A | 0，−10 | 0，−10 |
| B | 6，−10 | 0，−10 |
| C | 6，+1 | 0，−1 |

```powershell
python -m py_compile test/t870/contact_lift.py
python test/t870/contact_lift.py --out test/reports/t870
```

采用常加速度整步和子步内事件截断。原始序列的 T/N 是样本时刻的载荷，`appliedPreviousInterval` 是实际推进到该样本所用载荷，便于复核 0.10 s 切换。C 只推进法向，首个正位移采样点记录 S→P。回捕事件用下降过零求得子步时刻，并保留未截断端点和入床速度。

B 按 S→F→S，全程 P=0。C 按 S→P→F，粗步和半步首个正位移分别为 0.000050 m 和 0.0000125 m，同期累计外向冲量分别为 0.010 N·s 和 0.005 N·s。两档回捕前均观察到向下速度和跨零，回捕后的 y、vᵧ 和 P 归零。所有样本均保持 1 kg 唯一归属和来源身份。两档位移、速度与时刻均在容差内，逐项半步比较通过。首次失败为 `null`。

本轮支持在**给定净载荷的单份额合成用例**中将贴床起动与离床分开。交由 designer 据报告决定正式算法反馈和下一轮输入。真实起沙量、材料参数及目标12验收仍需各自证据。
