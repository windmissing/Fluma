# T871 · 实验 2 短脉冲离床判定

**PASS。** 12 组共 732 个共用轨迹样本，163/163 项检查通过。20 ms 脉冲产生试探间隙，候选始终保持 F，基线在四组中均误报 P。50 ms 脉冲结束后仍凭已有速度跨过 2 mm。100 ms 脉冲在加载期间跨过阈值。 [实验设计](../../../docs/design-T871-v1.md) · [逐项结果与事件](summary.json) · [原始样本](samples.jsonl)

## 输入与复现

Windows 11 10.0.26200 x64，CPython 3.12.10，标准库。质量 1 kg，来源 1，种子 0，初始状态 F。切向净载荷为零，法向净载荷为 −1/+1/−1 N，脉冲长度 20/50/100 ms，起点为 0/3 ms，输出步长为 10/5 ms。窗口为 0–0.40 s。

```powershell
python -m py_compile test/t871/pulse_release.py
python test/t871/pulse_release.py --out test/reports/t871
```

载荷切换按真实时间划分常加速度段，3 ms 相位直接进入积分。基线和候选读取同一份试探轨迹。发布继承穿越点的实际位置、速度和累计冲量。原件分别保存事件时间与下一输出样本，并保存每次回碰的入床速度和未截断的过零证据。复跑的样本和摘要逐字节相同。

## 参考与观测

时间从各组的脉冲起点计算。观测列为 0 ms 相位、10 ms 输出步长的代表值。其余三组的完整浮点原值在摘要中。

| 50 ms | 0.002500 / 0.002500 | 0.068377223 / 0.068377223 | 0.170710678 / 0.170710678 |
| 100 ms | 0.010000 / 0.010000 | 0.063245553 / 0.063245553 | 0.341421356 / 0.341421356 |

50 ms 组发布速度为 0.031622777 m/s，发布时累计外向冲量仍为 0.050 N·s。100 ms 组发布速度为 0.063245553 m/s。两组在 2 mm 处沿外向发布，回碰后恢复 F，法向位置与速度归零。扣除相位后，各步长与相位组合的同名事件最大时间差为 2.78×10⁻¹⁷ s。顶点恰触阈值的负控未发布 P。所有样本的 1 kg 归属和来源保持唯一，首次失败为 `null`。

结果支持将 2 mm 作为本合成实验的连续确认尺度。正式方案取舍及真实边界载荷下的尺度核定由 designer 接续。
