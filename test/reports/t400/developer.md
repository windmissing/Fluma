# T400 · CPU 确定性近床 LAND 取证

签包由 T392 隔离工程生成，默认进入 P051 Derived V2 的 XComponent + shader 页。签包及 SHA256 见[签包回执](../t257/T400-delivery.json)。设备续证沿原 T393。

- 「近床正控 0°」重置空床并预约 ID 1/2/3。预约绑定后才用原干沙入口准入 H=0.3、x=63.5、y=0.004、seed=51、Nmax=512。核对原准入收据、入量、三笔出生的 slot、ID、generation、相别和质量。该臂暂停 sensor/manual 覆盖，每个有效回调只提交一个 1/60 子步。
- 「受限对照 25°」用 x=63.99999 和原倾角规划复现参考的实际 12°/24°。普通触摸臂可用「预约首个 T3」，包括零获准和票据余量也会封档。跨列 companion 与同列 T3 分开。
- 状态随回调更新，记录 armId、run/epoch、绑定、准入、见到目标 ID、成功子步数和回调数。8 成功子步、16 前台回调或 15 秒单调墙时先达即封档，定时器可在无物理步时终止。重复预约拒绝，隐藏和重置保留各自取消档。旧定时器按 armId 拒绝。导出失败显示原错误，可重试冻结内容。
- 归档保留首次已提交 T3、首次正授予、该回调全部候选、实际选中 publication、P013 原回执和独立故障。只有选中候选含已验证的正 LAND 且同 token CURRENT swap 成功才记 `landCurrentSwap`。系统呈现继续单列。

[离线结果](units.jsonl)来自实际生成模型和原物理事务。0° 在第二成功子步列 63 三笔正授予 0.1、0.1、0.09999999999999998，三次退役，最终床 0.3。25° 在第二成功子步列 64 得 0.1、0.032121583881089655、0，最终床 0.13212158388108966。另测仅零授予封档、三重超时、重复/隐藏/重置、错 epoch 拒配。离线呈现用受控 P013 收据核对身份，真实交换由 T393 取证。ArkTS/native Hvigor 和验签通过。
