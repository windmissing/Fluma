## 测试用例与视频对照

### TC-01 静止零抖动
- **视频**：`selfcheck/tc_videos/tc01.mp4`（24 帧 / 4s 慢放 / 实际静置约 8s）
- **操作**：应用启动后不注入任何手势，平放静置
- **预期**：画面完全静止（逐帧 diff=0），蓝上绿下水平分层稳定；FPS 稳定后可降载
- **判定**：VV-02 液面恒定 + 逐帧 diff≈0。任何"自己动起来"= FAIL

### TC-02 慢倾渐变
- **视频**：`selfcheck/tc_videos/tc02.mp4`（30 帧 / 5s / 8 次小幅 swipe 阶梯加角）
- **操作**：分 8 次逐步加大倾角（模拟慢慢倾斜手机）
- **预期**：界面随角度单调倾斜，流动连续无跳变；每个角度增量都伴随平滑响应
- **判定**：VV-03 斜率单调 + VV-04 质心单调。角度与界面斜率不成比例 = FAIL

### TC-03 快速翻转渐变（关键用例）
- **视频**：`selfcheck/tc_videos/tc03.mp4`（30 帧 / 5s / 左倾稳态→瞬翻右倾）
- **操作**：先 4 次左倾建稳态 → 瞬间翻到右倾并保持
- **预期**：界面以 1-3s 平滑转到右侧（角速度限制），轻相被压后逐渐翻越重相，无瞬间换位
- **判定**：SV-03 核心用例。跳变 = FAIL（历史上这是反复出问题的点）

### TC-04 往复振荡
- **视频**：`selfcheck/tc_videos/tc04.mp4`（24 帧 / 4s / 左右快速交替 6 轮）
- **操作**：±60° 快速交替甩动
- **预期**：液体随甩动整体迁移但始终连续；无锁死、无跳变、无粒子丢失观感
- **判定**：VV-01 分相占比恒定 + 无 NaN 表现（画面不出现异常色块）

### TC-05 渗透静置（混合带演化）
- **视频**：`selfcheck/tc_videos/tc05.mp4`（45 帧 / 7.5s / 翻转后回正静置 15s+）
- **操作**：右倾建稳态 → 回正 → 长静置
- **预期**：回正后重新分层；界面附近混合带（蓝渗入绿）随时间缓慢加深（40s 量级），液面本身纹丝不动
- **判定**：SV-04 核心用例。渗透期间液面高度必须恒定（VV-02），分层"秒完成"= FAIL

### TC-06 回正铺平
- **视频**：`selfcheck/tc_videos/tc06.mp4`（24 帧 / 4s / 大角度→归零）
- **操作**：大角度右倾稳态 → 中心 swipe 归零
- **预期**：界面在 2-3s 内平滑回到水平（|tilt|<8° 有 3 倍收敛加速），最终完全铺平
- **判定**：终态界面水平（VV-02+VV-03），收敛拖尾过长或残留倾斜 = FAIL

### TC-07 重复翻转守恒
- **视频**：`selfcheck/tc_videos/tc07.mp4`（24 帧 / 4s / 6 轮大幅翻转+回正）
- **操作**：6 轮 ±60° 交替翻转后回正
- **预期**：反复翻转后蓝/绿两相依然都在（观感上蓝不消失、绿不霸屏），回正后正常分层
- **判定**：**VV-01 最重要的用例**——历史事故"蓝被压没"就是在此场景暴露。分相占比漂移 >±3% = FAIL

### TC-08 边界小角度（安息角行为）
- **视频**：`selfcheck/tc_videos/tc08.mp4`（18 帧 / 3s / 小幅 swipe 至安息角以内）
- **操作**：短 swipe 注入 ~3-4° 小倾角并保持
- **预期**：坡度低于安息角时液体基本不动（物理正确），不应出现持续蠕变或异常抖动
- **判定**：小角度静止 = PASS；小角度下持续大幅流动反而可疑（标定值问题）

### TC-09 强制倒立稳态（s77 新增）
- **前置**：testMode 开 + 调参面板"强制倒立"按钮开（橙红=开，仅 testMode 下可点；或 `aa start --ps testmode true --ps forceinvert true` 直启）
- **操作**：开启强制倒立（重力直接置 180°，经 maxOmega 渐变过渡约 0.75s）→ 静置 ≥30s 连拍
- **预期**：绿相（重相）渐变迁移到画面顶部、蓝相沉底，界面连续翻转无跳变；稳态后完全静止
- **判定**：
  1. VV-01 蓝漂移 ≤±3%；
  2. **相序检查（本用例新增）**：稳态帧绿质心行号 < 蓝质心行号（绿在上方，重相到达重力反方向顶部）；
  3. VV-02 液面线稳定（倒立时"液面"语义 = 画面下缘的重相边界）；
  4. 翻转渐变过程无阶跃。

### TC-10 倒立↔正立翻转渐变（s77 新增）
- **前置**：testMode 开
- **操作**：强制倒立 开→关→开→关（往复 2 轮），全程连拍
- **预期**：每次切换界面以连续渐变过渡（maxOmega 限速 240°/s），无瞬间换位、无阶跃；两相全程存在
- **判定**：
  1. SV-03 同标准：界面连续渐变无阶跃、斜率时序单调连续；
  2. VD-NEW 动态有效性：首尾斜率方向改变 + 非稳态段存在；
  3. 全程 VV-01 ≤±3%；
  4. 相序随开关正确翻转（开=绿上蓝下，关=蓝上绿下）。

### TC-11 液体模式静置水平界面（M1' 场景一，s79 新增）
- **前置**：面板"模式:液体"（四态循环第 4 态，模拟层=SandGrid 液体相规则：类型不可变 + 单向置换 dc=0.5 + 铺平）
- **操作**：切到液体模式 → 静置 ≥30s 连拍
- **预期**：界面水平（波动 ≤2 格）、蓝上绿下、稳态后完全静止（零抖动）
- **判定**：
  1. **VV-01 双口径**（leader 澄清要求）：分相占比按粒子计数（模拟层恒等式，Node 标定 3360/2400 恒定）与按像素面积（渲染层）分列报告，两口径偏差 ≤±3%；
  2. 界面波动（每列首粒行号 max-min，忽略两端 10% 列）≤2 格；
  3. 稳态段逐帧 diff≈0（完全静止，m1_final_check 标定：终态连续静止 ≥300 帧）。

### TC-12 液体模式摇晃暂时混合→静置恢复分层（M1'，s79 新增）
- **前置**：液体模式
- **操作**：左右交替强 swipe 摇晃 6s（混合段连拍）→ 停止静置 30s（恢复段连拍）
- **预期**：摇晃期间两相碎块化（视觉=暂时混浊），静置后重沉轻浮恢复蓝上绿下
- **判定**：
  1. **混色带占比曲线**（leader 澄清要求）：混合段占比上升（上开）、恢复段收敛下降（下收）——用曲线形态判定"暂时混合→恢复"，不用单一终态阈值（避免把恢复过程误判 FAIL）；
  2. 全程 VV-01 双口径 ≤±3%（激烈摇晃期间守恒：Node 逐帧抽查 PASS）；
  3. 恢复终态：绿质心行号 > 蓝质心行号 + 界面波动 ≤3 格。

### TC-13 液体模式翻转回复 2~4s（M1'，s79 新增）
- **前置**：液体模式，正立稳态
- **操作**：强制倒立开（或 180° 手势）→ 静置至稳定 → 强制倒立关 → 静置
- **预期**：每次翻转后 2~4s 内完成重排（Node 标定 dc=0.5 翻转 2.8s / 翻回 0.8s），界面连续无阶跃
- **判定**：
  1. 重排时间窗 2~4s（质心交越 + 界面波动 ≤3 格判定稳定点）；
  2. 翻转渐变连续（SV-03 同标准）；
  3. 相序正确翻转（复用 phase_order_check.py）；
  4. 全程 VV-01 双口径 ≤±3%。

## 测试执行说明（给测试智能体）

1. **判定顺序**：先跑 §4.5.1 硬指标 VV-01..06（tc_frames 原始帧可直接算），全 PASS 后再按 §4.5.5 打 SV 主观分。硬指标不过则 SV 分无效。
2. **颜色分类阈值**：混合模式用渐变渲染，固定 RGB 阈值会失真。先对任一帧做竖直 BGR 切片标定阈值（方法见 §4.5.2 第 3 条），把混合带像素归类规则写进脚本注释。
3. **对照基线**：SV-05/06/07 打分时打开 https://liuma-baseline.app.workbuddy.host/ 与视频并排对比。
4. **视频特性**：6fps 慢放合成（0.33s 间隔连拍）。TC-05 静置 15s 内渗透变化细微，如需观察更长时程可基于 tc05 的 actions 重录加帧（脚本 record_tc_all.py 可复用：`python record_tc_all.py 05`）。
5. **已知环境因素**：uitest swipe 位移强衰减（全宽 swipe 实收约 6-8°），视频中倾角普遍低于真实手指操作；录屏期间设备曾弹 USB 弹窗的话按 §4.5.2 第 4 条剔除。
6. **被测版本确认**：真机当前为 s79（面板 BindSheet 修复 + M1' 液体模式）。如测试时需重新部署，HAP 在 `D:\hmprojects\HelloWorld\entry-default-s79-signed.hap`。
7. **TC-09/10 快速入口**（免面板操作，录制脚本已内置）：
   - `aa start -b com.example.helloworld -a EntryAbility --ps testmode true --ps forceinvert true`（testMode + 强制倒立直启）；
   - 录制：`python record_tc_all.py 09` / `python record_tc_all.py 10`；
   - 相序判定脚本：`python phase_order_check.py tc09 inverted`（TC-09 稳态段）/ TC-10 按开关时段分段调用 inverted/upright。
