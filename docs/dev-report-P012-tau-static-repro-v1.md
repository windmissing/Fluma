## 2. 旧脚本与生产路径的 5 处不一致（本次整改内容）

| # | 旧脚本 | 生产路径（`P012WaterSandRenderer.ets`） | 影响 |
| --- | --- | --- | --- |
| ① | alpha 固定cap `0.55` | `P012_A_FOG_ALPHA_MAX = 0.78`（12 档，alphaStep = 0.065） | 雾强度上限被低估，单档alpha 从 0.0458 变 0.065 |
| ② | 无拉伸，`stretched = mottle` | `stretched = clamp(1 + (mottle-1)*2.2, 0.2, 2.0)`（`P012_A_MOTTLE_STRETCH`）| mottle 分布形状未拉开，range 偏窄 |
| ③ | tau 链只有 `tauStatic` | `tau = max(0, tauOpt + 0.9*qH + 0.7*qL + tauStatic)`，`P012_A_TAU_INTERFACE = 1.35` | 静息场景（q=0）恰好不受影响，但接口带与界面贡献未建模 |
| ④ | 混色端点硬编码 `187`/`236`，与底色做**一次** lerp | 雾色 `rgb(232,240,236)`，按 12 档**逐档独立 alpha 填充**（source-over 逐档叠加） | 一次 lerp 与逐档量化的最终亮度不同|
| ⑤ | alpha 用解析式 `1-exp(-tau)` 直接求值 | 走 `fogLut`：`t=clamp(tau,0,4)`、`idx=round(t*16)`、65 点 LUT | 缺clamp 与量化，尾部（tau≥4）会被解析式继续放大 |

> ①②⑤ 是本次「预测 15.3 无法复现」的**主因**：旧配置（alpha 0.55 + stretch 1.0）下雾单独贡献 std 仅 **3.37**，生产配置（alpha 0.78 + stretch 2.2）下为 **5.52**。

## 3. 参数快照与可追溯性

脚本**不复制**生产常量到计算路径，而是 `require` 生产渲染器实例并调用其私有方法 `staticTau()` / `fogAlpha()`。脚本内保留的常量仅作为**快照**，并在脚本启动时做交叉校验：

```
[cross-check] staticTau 最大偏差=0.00e+0  fogAlpha 最大偏差=0.00e+0  → PASS 与生产逐项一致
```

（即2000 个采样点上，本脚本的独立实现与生产实例输出逐位相同。）

| 常量 | 值| 用途 |
| --- | --- | --- |
| `P012_A_FOG_ALPHA_MAX` | 0.78 | 雾 alpha 上限 |
| `P012_A_ALPHA_TIERS` | 12 | alpha 量化档数，alphaStep = 0.78/12 = 0.065 |
| `P012_A_TAU_STATIC_BASE` | 0.55 | `tauStatic` 基值 |
| `P012_A_TAU_STATIC_AMP` | 1.8 | `tauStatic` 斜率 |
| `P012_A_MOTTLE_STRETCH` | 2.2 | mottle 线性拉伸系数，clamp[0.2, 2.0] |
| `P012_A_KH` / `P012_A_KL` | 0.9 / 0.7 | qH/qL 权重 |
| `P012_A_TAU_INTERFACE` | 1.35 | 界面带 tau 偏置 |
| `P012_A_WFULL_PX` | 56 | 界面带半宽 |
| `P012_A_TILE` | 64 | mottle 噪声 tile 尺寸 |
| `MOTTLE_SEED` | 20261021 | mottle 噪声种子 |
| 雾色 `FOG_RGB` | (232, 240, 236) | `fillFogTiers` 的 fogR/G/B |
| fogLut | 65 点，`idx=round(clamp(tau,0,4)*16)` | alpha LUT |
| 颗粒 seed | 20261022 / 20261023 / 20261024 | 重/轻/中层沙粒位图种子 |

### mottle 分布实测（生产 tile 直接采样，n=4096）

```
[mottle] mean=1.0000  std=0.5494  min=-0.8762  max=2.4549（seed=20261021, tile=64）
```

> **可追溯发现（与生产注释不符）**：`algorithm-P012-render-v1.md` 与 EA 报告中把mottle std 记为「0.12 → 0.35」（对应 a1/a2从 0.45/0.35 提到 1.3/1.0）。本次按生产 `mottleAt()` 在64×64 tile 上直接实测得 **std = 0.5494**，明显高于文档声称的 0.35。
> 该差异**不影响** 15.3 的复现结论（复现用的是同一生产函数，参数自然一致），但说明文档中「mottle std 0.35」这一中间量是估算值而非实测值，后续若以「mottle std」为验收指标须改用实测口径。

## 5. 完整画面合成与 15.3 的复现

单纯「雾单独std」无法达到 15.3 —— EA 报告的 15.3 是**完整画面**（底色竖向渐变 + 界面带 + 雾斑驳）叠加后的结果。合成模型：

- ROI：`off-ws0` 水体段 `y1400..1720, x240..1035`（1280×2832 截图绝对像素）
- 底色：水体竖向渐变 `rgb(192,202,196)` → `rgb(168,186,182)`，沿 `boxY..boxY+boxH`（boxY=883, boxH=1099）
- 界面带：中心 `ifaceBandY=1660`，半宽 28px（`P012_A_WFULL_PX/2`）的smoothstep 包络，权重 `w` 决定该行底色在「水色」与「沙色 lum 210」之间插值
- **界面带及其以下（y ≥ 1660）不叠雾** —— 界面带在沙体之后绘制，会覆盖水体侧的雾（实测该段 std 仅 5.4，证实此建模必要）
- 雾叠加：按 12 档枚举量化，单档 source-over `L = base*(1-a) + L_fog*a`，`L_fog = lum(232,240,236)`

方差分解与实测对照：

| 分量 | 模型 | 真机同项（cv2 实测同一ROI） |
| --- | --- | --- |
| (a) 底色（含界面带），沿行平均 | 5.25 | 8.69 |
| (b) 雾斑驳净贡献，沿列平均 | 14.40 | 11.43 |
| **(a)+(b) 渲染层理论 std** | **15.33**（mean 209.66, range 40.2） | 17.38（总std） |

**判定：15.33 vs EA 报告 15.3，偏差 0.03 → PASS（阈值 ≤0.5）。**

> 说明：模型与真机的分量分配方向相反（模型底色占比小、真机底色占比大），但总 std 自洽；分量差异源于真机 JPEG 量化和 B 档颗粒使高频噪声抬升，而模型把高频结构全部归入「斑驳」项。总 std 是唯一被冻结的锚点口径，也是本复现的判定量。

## 6. 与真机 17.38 的剩余差 2.05 归因

四项均可叠加核对，按预期量级排序：

1. **JPEG 压缩与 8bit 量化噪声** —— 截图测量必含，仿真不含。
2. **B 档颗粒叠加** —— 真机截图取自 EAB 档，含 `sigmaG=15 × globalAlpha 0.75` 的颗粒层；本模型只建模 A 档雾。
3. **界面带 smoothstep 包络的列间差异** —— 模型用单一 `sandLum=210` 近似，未建模界面带随列的起伏。
4. **液面高光带（alpha ≤ 0.12）** —— 位于 ROI 上缘，模型未计入。
