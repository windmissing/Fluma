## 2. μ_y 三方案对比与推荐

二轮报告把现状概括为 `p_eff≈250` 导致 `μ_y p_eff≫Δbh`。当前阈值项比较量纲尚未登记闭合：若 `p_eff` 是长度代理，则 `μ_y p_eff` 与压力/高度差不能直接比较；如果 `p_eff` 是压力，则 `Δbh` 必须先转换为同量纲驱动压力。所有 `μ_y=0.1` 网格均 `NO_DRIVE`，因此不能靠将旧 μ 值换个名字继续使用。

| 方案 | 可实施定义 | 对 `ΔE` 语义的影响 | 候选值域重定标与取舍 |
|---|---|---|---|
| a. 归一化 `p_eff` | 选本路线固定的 `S_ref` 与 `P_ref=(ρ_H−ρ_L)gS_ref`，定义 `δ=Δbh/S_ref`、`π=p_eff/P_ref`，屈服余量 `D̂=max(0,δ−μ_yπ)`。`S_ref` 必须来自冻结的容量/参考厚度定义并写入run身份，不能按每帧自适应。 | `ΔE=g(ρ_H−ρ_L)q[q−Δbh]` 完全不改。此项只将候选屈服比较无量纲化；接受通量仍须满足 `0<q≤Δbh/2` 等原耗散条件。 | μ 变成两无量纲比值的比例系数。旧裸乘积及 μ=0.1 的行为不可直接映射；需根据二轮/三轮场景记录的 `δ/π` 与活跃边分布重建候选域。数值实现简单，但须把参考尺度版本化，避免不同容量场下暗中换门槛。 |
| b. μ_y 明确定义为无量纲摩擦比（**推荐**） | 令 `p_eff` 为有效压力 Pa，`P_drive=(ρ_H−ρ_L)gΔbh` Pa，`D=max(0,P_drive−μ_y p_eff)`。如现有状态只提供几何厚度 `H_eff`，显式换算 `p_eff=ρ_eff g H_eff`；明确 `ρ_eff`、浮力/水压是否纳入及其来源字段。可按方案 a 以固定参考压强对两压力同时归一化实现。 | 势能式及 q 的耗散条件不变；`μ_y p_eff` 是独立屈服门，不是新增势能或额外能量源。屈服通过仅允许候选边进入速率律，不能代替 `ΔE<0`、无过冲与守恒检查。 | μ 采用无量纲摩擦系数的物理含义，但项目数值仍须定标。当前 `p_eff≈250` 的裸值不具备转换依据，旧 μ 值作废；用各预注册边的 `P_drive/p_eff` 正值分布挑候选阈值。方案 b 给清楚可解释的物理量，方案 a 是它的无量纲计算形式；二者不应成为两套并行参数。 |
| c. 改相对判据 | 例如以局部参考界面尺度 `S_loc` 定义 `r=|Δbh|/max(S_loc,S_floor)`，仅当 `r>τ_rel` 才允许；或要求预测相对势能降 `−ΔE/E_ref>τ_E`。选一种单一 reference、guard 与冻结口径。 | 原重力势能式仍可用于已提交 q 的耗散核查；但触发不再是摩擦压力阈值，而是几何/相对能量对比。若 `S_loc` 随列变动，尺度小的列会有不同绝对起伏门槛；若采用 `E_ref`，需明确定义，否则容易把稳定性门与可见度门混为一谈。 | τ 是形状相对阈值，不再可称为 μ_y 或摩擦系数。值域要按 `Δbh/S_loc` 或相对能量样本全新重定标。比值对缩放较稳健，但物理可解释性弱于压力闭合方案；不作为本轮首选。 |

**选型要求：b 是唯一模型语义；a 可作为等价数值实现。** 公式必须先做单位检查：`P_drive` 与 `p_eff` 同单位；若实现使用无量纲压力量，分子、阻力与参考压强三者统一除以同一个固定 `P_ref`。不能只对 `p_eff` 除 `S_ref`，却仍与未归一化的 `Δbh` 比较。对候选状态要记录 `P_drive`、`p_eff`、`μ_y p_eff`、`D`、结果码，便于解释 `NO_DRIVE`。`p_eff≤0`、非有限值、密度缺失或参考尺度缺失必须 fail-closed 并单独记为配置/数据错误，不能当作零阻力放行。

### 2.1 对开题势能式的安全约束

对开题稿假设（相邻列、等截面、`S_i/S_j` 在交换期间不变、`ρ_H>ρ_L`）采用既有公式：

`ΔE = g(ρ_H−ρ_L) q [q−Δbh]`，其中 `Δbh=bh_i−bh_j>0`。

该式在 `0<q<Δbh` 时为负；为防止高低界面反转，沿用更强约束 `q≤Δbh/2`。新的屈服门只决定 `D>0` 时可提出 `q_req`，不改变方向、两相反向交换、预算按实际运动量 `2q` 记账、guard预演、原子提交/回滚或逐步能量核查。若引入真实压力/倾角、浮力或 `S` 变化，必须重新推导广义势能；本卡不假设旧简式自动适用于这些状态。

1. **先冻结量纲定义，不先挑好看的 μ。** 在 sweep 配置头记录 `yieldModelId=P011_S4_COULOMB_PRESSURE_V1_CANDIDATE`（名字仅建议）、`pEffDefinition`、`rhoEffDefinition`、`S_ref/P_ref`（若采用归一化）、单位、公式版本、输入场hash、seed、dt与场景。无法从当前字段定义压力时，本轮只跑 `μ=0` 基线并把 μ 分支记 `BLOCKED_MISSING_PRESSURE_DEFINITION`，由 designer/manager补物理定义，不要用扫参替代定义。
2. **候选网格由驱动比生成。** 在同一固定非均匀驱动样本上记录每个可用边的 `r_i=P_drive_i/p_eff_i`（`p_eff>0`，同一时间窗、同一场景）；列出正值样本计数与 P10/P25/P50/P75/P90。候选 μ 包含 `0` 对照及从有效 `r_i` 分位点选出的稀疏低/中/高档，边界到零驱动档单独记录；完整输出数值网格后再执行，数值全标 **TUNING_CANDIDATE / NOT_FROZEN**。没有正值样本时不要造候选 μ，报告 `NO_CALIBRATION_SUPPORT`。
3. **对照臂和范围：** 固定 sweep-v2 seed/初态/300s实验身份以可比；包括均匀场零驱动对照、开题A路线非均匀场、2–8px探索域；每组对照 μ=0 和同一驱动比网格。维持 `k≤0.2`、`hMin`既有扫描定义及既有总/local/bottom预算；不因拟合 μ 扩展 k 域或改能量/守恒/对称闸门。
4. **每组必须输出：** `muY`、`pEffDefinitionId`、驱动比样本摘要、`eligibleEdges`、`noDrive`、`noInventory`、`budgetClipped`、`guardBlocked`、`requested/granted/clipped`、每实际事务 `q`、H/L总量漂移、`maxAbsDeltaS`、`zeroFluxGate`、`explorationDomainHit`、峰谷/幅度的初末值与 ratio、运行时序及 `S4`消融对照身份。不要以总 used 或最终 amplitude 单项替代分流。

## 4. 域上限裁定：维持 fail-closed

二轮证据与 S4 定位一致：

- 大起伏73px初态：300s中，域内 `k≤0.2` 只有约0.9%–8%衰减；报告估算快磨平需要 `k≈2–5`，是当前上限的10–25倍。此结果说明机制速率上限，**不说明现有S4职责失败**。
- 目标探索域的小起伏：`k=0.1` 时 5.41px→4.68px（ratio 0.865）；`k=0.2` 时 5.41px→4.38px（ratio 0.810）；边缘样本 `10.83px→8.77px`（ratio 0.810）。观察窗口300s，符合数百秒衰减的慢时标方向。数值不是通过阈值或效果验收线。
- sweep JSON `explorationDomainHits=[]` 是该报告所定义的域内命中登记；零通量闸门失败数为0。不得将 JSON 命中登记误读为已完成真机或主观效果验证。

因此维持 `kDeep≤0.2`，超域仍 fail-closed；不把73px快速磨平作为 S4 本轮验收目标。若产品后续明确需要快速平整大幅起伏，应另提需求并由 manager 决定是否设一个独立快时标机制/配置；届时先重审守恒、能量、预算、抖振与 C 层理耦合，再由 tester/developer 走独立域外安全验证和 fail-closed 变更审批。单纯把 S4 的 cap 提到 `2–5` 会同时改变时间尺度与用户可感知行为，现有二轮结果不足以支撑。
