### 2.3 编码与量化注意事项

1. **两侧都是 JPEG（均非无损）**：不存在"压缩参考 vs 无损真机"的对照；G3 统一再编码只作敏感性，不恢复原视频编码历史。
2. 量化表摘要方法：PIL `Image.quantization` 字典 → JSON（键排序、值排序）→ SHA-256 前 16 位。可复现脚本内嵌于 manifest 生成过程（`q1-manifest-media.json` 附字段）。
3. 不能靠文件名推断无损来源——全部按字节哈希与文件头登记。
4. **effector 复核补充（2026-10-21，冻结项 5 收口）**：原登记摘要 `815c7333…`/`8363be41…` 的精确算法未随脚本留存（多种复现变体均未命中原值）。用可复现方法（PIL quantization 按键序平铺 → JSON → SHA-256 前 16，记为 `quant-flat-v1`）重验：**参考侧全部 8 帧 = `19fe9dcb59eee0b6`、设备侧全部 42 帧（s99w 18 + s96 24）= `921c6b6c74067314`——"同侧各自一致、两侧互不相同"论断成立**（新方法独立复现）。机器可读副本已补齐 20 条缺失帧（s96 static 8 + s99w w0/w2 12），条目总数 30→50，字段 `quantTableSha16` 用 `quant-flat-v1` 口径（与原 `quantTableHash16` 并存，冻结前 tester 统一口径）。

## 4. 沙材质 mask（候选初稿，冻结前须人工复核）

### 4.1 设备侧（s99w sand ROI 内）

- 六帧 `gDom`（G>R 且 G>B）像素比全部 = 1.0，G 主导行覆盖 ROI 全部 26 行——**该 ROI 内为纯沙带**，无黄带/界面渗入。
- mask 候选 = v1 sand ROI 原样 (240,1950,1035,1976)；**effector 复核（2026-10-21）**：上缘 y=1948..1950 纯沙（RGB≈(147-154,170-177,114-121)）无过渡；**下缘 y=1972 起出现沙→白框过渡亚像素**（y1971=(162,181,135) 纯沙 → y1972=(182,199,155) 过渡 → y1977=白框），三对帧一致。**终稿：sand mask 下缘收到 y≤1971（ROI 高 26→22 行），排除 1972..1976 过渡亚像素**。v1 历史数值（hfH=8.075 等）在该 26 行 ROI 上测得——双轨口径下 `hfH_native_v1` 保留原 ROI 值不重算，v2 算子用 22 行新 mask。

### 4.2 参考侧（260×330 帧内）

- **effector 人工复核终稿（2026-10-21）**：mask = §3.2 终稿表的纯沙列 × 纯沙行交集——f0 (42,169)-(252,314)、f5 (10,150)-(236,304)、f2 (53,210)-(257,314)、f6 (7,150)-(229,305)。判据与收窄过程见 §3.2（G 主导 + 亮度带 + 8/8 行连续列判据 + 80% 列行判据）。
- 左缘排除依据：f0 x<42 容器壁暗影（沙样率 3-5/11）、f2 x<53 手/背景棕色（0 沙样）——两者都不是沙材质。
- 深度分层：参考沙体厚（105~156 行）vs 设备薄带（26px→归一后 ~5.6 行）——分层规则（上/中/下 patch）在 revision 草案 §3 冻结，本 manifest 只登记几何事实。
