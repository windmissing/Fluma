## 2. 几何与缩放冻结

1. **比较单位 = 容器内部显示宽度**（非整图、非沙 ROI 宽）。边界与裁剪原点按 manifest（`q1-input-manifest-P012-v1.md` §3）冻结；manifest 冻结前置项（内宽 921 vs 931 收口、参考 mask 人工收窄、透视宽度范围）完成前本节不生效。
2. **主档：容器内部统一 200 分析像素宽**。保持纵横比，两侧用各自已确认内宽计算缩放比（设备 921→200；参考按每帧内宽→200）。
3. **内宽不足回退**：任一参考有效内宽 <200 → 主档改为**全组最小有效内宽**，并在**首次出数前重新冻结**；禁止先看 EAB 结果再选宽度。参考帧局部宽度候选 229~257（manifest §3.2）——若 effector 复核后最小有效内宽 ≥200 则主档维持 200。
4. **敏感性档**：主档宽度的一半（200→100；主档 <200 时取其一半）。仅作降尺度敏感性，不与主档混报，不挑更接近参考的一档作最终答案。
5. 透视帧（参考）：内宽取登记范围中值定主缩放比，敏感性检查用范围两端；不拉直、不非等比变形。

## 3. 重采样与算子冻结

1. **单次面积覆盖重采样**：解码原图 → 浮点 Y（`Y=0.299R+0.587G+0.114B`，8bit 输入）→ 按像素面积交叠平均一次完成原图→目标图；固定像素中心/边界与取整规则（实现于 `measure_render_p012_q1.py`，先经常量图/线性对比/无有效像素对三类算子自测）。
2. **禁止**：锐化、补噪、对比度归一化、连续多次缩小、主档输出重编码。
3. 派生图存 PNG 供追溯；**数值以浮点算子结果为准**，PNG 展示值不作测量输入。
4. **mask 先于统计**：从原图标注纯沙区（manifest §4 候选 + 人工复核终稿）；目标像素面积支撑完全落在有效 mask 内才纳入；hfH 只统计左右相邻且均有效的像素对。双侧同一排除规则；**mask 与坐标在看新 hfH 前冻结**。
5. **薄沙带 SUPPORT_LIMITED**：设备 26px 沙带缩到 200 内宽约 5.6 行（按内宽 921 估）——必须报告有效行数/相邻对数并标 `SUPPORT_LIMITED`；不拉伸成参考 110 行块、不复制行增样；无有效相邻对输出 N/A。
6. 参考深度分层：同归一化尺寸的上/中/下沙内 patch（选位规则：沙区行范围三等分的中段 patch 为主，上/下段作敏感性），不同深度/材质不混成一个平均数。

## 4. 分组矩阵与报告规则（继承方案 §3.2，冻结要点）

- G0 原生复现 / G1 主尺度静态 / G2 尺度敏感性 / G3 编码敏感性（JPEG Q=75/90、4:2:0、同版本编码器）/ G4 动态（s96 单独分组，不与 s99w 合并）/ G5 尺度对比辅助（lumStd+归一化频谱，仅诊断）。
- 主参考集 = f0/f5（静态）+ f2/f6（动态）；f1/f3/f4/f7 全量登记仅作敏感性，出数后不得换入更宽带。
- **首轮每状态仅 2 个主参考帧：只报单帧值与描述性 min/max，不冒充置信区间**；静态/动态带分开。
- 归因规则（对比候选/尺度候选/不可辨识）按方案 §3.2；主观"无网格感"不撤销数字差异。

1. 算子 + 几何 + mask + 主参考集 + 报告规则全部冻结（本草案 §2–§5 + manifest 冻结）→ tester 实现算子并过算子自测。

3. 描述带是否升格为正式验收区间：**manager 在 revision 评审单独裁决**——本草案零预填。
