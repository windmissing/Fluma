# T814 目标10左右镜像协变离线核验

T557 的 15 个 A 用例已逐项复核，11 个用例有可独立重算的局部结果。对 13 份候选原件核对后，合格 GPU 或图像镜像对为 **0**。因此实测总 q、逐来源 q、图像差异均为 **NOT_OBSERVED**。以下数值来自有限构造。 [逐例原值、SHA 与排除理由](../test/reports/t814/offline.json)
