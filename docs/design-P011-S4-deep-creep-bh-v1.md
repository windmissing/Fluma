## 1. 核心效果链与能力边界

`bh[c]` 是盒底到重沙层顶的高度，既是重沙/轻沙内部界面，也是当前重沙库存；`S[c]=bh+bl+mh+ml` 是沙顶。现有 `settleSandV2` 将悬重沙转入混合层，`percolateHeavyConservative` 在列内把 `mh` 转入 `bh`；`creepBottom` 主要随倾斜搬运沉积库存，受目标形状请求、10/s 底部额度与总额度限制。上述途径即使使 `bh` 改变，也未提供**以内部界面自身应力松弛为目的、长时标且可独立归因**的机制。不能仅据“加料后看起来平”推断所有现有运行中 `bh` 数学上恒平；基线必须实测。

目标链：**有空间差异的重沙厚度/负载 → 深层缓慢重排 → `bh` 局部下陷与邻域隆起并存 → C 的材质深度条纹随实际界面弯曲 → 非直线沙层分界及地质层次感**。S4 只负责物理形状；P-012 C 仍只读物理场，不写库存或 checker。仅 `bh` mask 轮廓弯曲不保证内部条纹跟着弯；C 的 `depth_j=materialHeight−base_j(x)`、稳定相位和渲染消融必须单独确认。沙层“年代”仍是视觉代理，`bh` 起伏不等于真实沉积年龄记录。

**对称性/可达性闸门：**如果初始 `bh`、上覆层、水压、材料参数、边界条件及输入关于 x 完全均匀，任何局部、守恒且左右对称的应力律都应给零通量，不能自发生成指定的自然波形。本稿禁止隐含正弦目标、预置每列高度或为过锚点凭空注入起伏。S4 的有效验收场景必须先具备真实非均匀驱动，例如合法的局部注入/沉降历史、局部上覆厚度差、倾斜往返后的非均匀库存或可登记的材料阻力差；均匀控制组应保持平直。若产品要求无任何非均匀输入的静置平堆自行长出起伏，需 manager 先决定是否允许外观生成/外源扰动，该要求不能伪装成守恒深层蠕动。

## 3. 守恒框架：`bh` 形变不等于凭空加减沙

当前模型把 `bh` 直接作为**重沙库存的列高度等价值**，重沙总量 `V_H=Σ(bh+mh+suspH)`、轻沙总量 `V_L=Σ(bl+ml+suspL)`；不存在独立孔隙率、孔隙水或固体体积字段。因此当前字段下 `bh[c]−=q` 必须同时在别处给重沙 `+q`，或转入该列另一个重沙相；仅改 `bh` 显示高度会破坏 checker 与相库存。

**推荐的第一步：深层重/轻逆向交换，不声称孔隙压实。** 在相邻列 `i→j`，重沙下层 `bh_i−=q, bh_j+=q`；为保持沙顶近静止，轻沙在相反方向 `bl_j−=q, bl_i+=q`。于是每相全局 `ΔV_H=ΔV_L=0`，每列 `ΔS=0`，`bh` 的下陷/隆起严格成对，重沙失量恰是邻列所得量，隆起有可追溯来源。需同时满足 `q≤bh_i`、`q≤bl_j`、列内相非负、承载层连通及其它既有容量条件。**这是深层界面剪切/反向占位的最小守恒代理，不是颗粒被压小，也不是已证实的实际水排出过程。**若采用无反向占位的重沙单向搬运，则 `ΔS_i=−q, ΔS_j=+q`，必须由 §19.5 guard 对中央边及两邻边逐笔预演，沙顶改变也要计入效果与容量。

逆向交换虽然 `ΔS=0`，仍须把两笔相反搬运按**实际运动量 `2q`**计入共享 `300·dt`，每端 local 账也计两笔，不能因净沙顶位移零而免费；独立 S4 channel cap 若将来设置，仍是总账子集。对 `ΔS=0` 的 guard 调用/审计保留，结果不能被写作“guard 已保证内部 `bh` 坡度安全”：它只管沙顶残差。另需内部界面有效性（`0≤bh≤S`、轻层足量、无反向过冲）及逐步能量/形变上限。任何方案都不得占用 correction 的预留额度或以 S4 名称绕过其路线隔离。

**真正压实是另一种账本。** 若孔隙率 `n_H` 从高到低，重沙固体体积 `M_H=φ_H·bh`（`φ_H=1−n_H`）可不变而 `bh=M_H/φ_H` 下降；消失的是孔隙体积，不是重沙固体。饱和情况下减少的孔隙水须排到上覆水/邻列水账；沙顶及上层的位移、容量也须重算。当前 `bh` 与固体库存同值，直接压缩 `bh` 会被误判为重沙消失；实现真压实必须先把固体库存、孔隙体积、排水和可视体积拆账，并给 snapshot/checker/guard 新契约。**纯局部压实只能使该列下陷，不能让薄邻列隆起**；隆起还需侧向固体/孔隙流入或局部胀缩有明确体积来源。

### 4.1 A 的可检验最小数学语义（项目新候选，非论文方程）

在相邻 `i,j`、等截面、`S_i/S_j` 在逆向交换期间不变、重沙有效密度大于轻沙的近似下，底层重沙及其上方轻沙的重力势能为 `E_c = g·[ρ_L S_c² +(ρ_H−ρ_L)bh_c²]/2`。若 `bh_i>bh_j`，重沙 `i→j`、轻沙 `j→i` 同量 `q`，则

`ΔE = g(ρ_H−ρ_L) q [q−(bh_i−bh_j)]`。

所以在库存允许、`0<q≤(bh_i−bh_j)/2` 时，势能严格下降且不会把界面高低反转。这给出**方向、无过冲与可证伪的耗散条件**，不是凭目标形状拉沙。可选屈服/速率原型写成 `D_ij = max(0, (ρ_H−ρ_L)g(bh_i−bh_j) − μ_y p_eff,ij)`、`q_req = min(k_deep·dt·D_ij, (bh_i−bh_j)/2, bh_i, bl_j)`；`p_eff` 是局部上覆有效压力的待定义/待标定代理，`k_deep` 的单位须使通量为材料高度，`μ_y` 不从 253/255 数值移植。若压力代理使所有边 `D=0`，不得暗中调低屈服值求起伏；先报告 `NO_DRIVE/NO_INVENTORY/BUDGET_CLIPPED/GUARD_BLOCKED` 分解。若真实倾角参与体力，必须用 `effectiveTilt` 与重力方向而非旧目标形状残差，且证明正负翻转/回正时无能量注入或振荡。上述势能证明只覆盖所列简化条件；任意倾角、浮力与不同 `S` 时须重新推导能量账，不能直接沿用此式。

单对峰谷的界面高度差每接受 `q` 最多缩小 `2q` 材料单位。若一对原始峰谷要出现 `A_px` 显示像素的差值变化，必要条件是 `q≥A_px/(2·pxPerMaterial)`；相应共享预算至少支出 `2q≥A_px/pxPerMaterial`。这是**单对下界**，不是全幅 8–40 列形变的充分预算证明；正式可达性审计必须按所有受影响边求和、计两相搬运、guard 与库存截断，再与 `300·T` 比较。

## 5. S4 × C 层理联合验收候选

1. **物理先行**：同源输入比较 S4 OFF/ON 的 `bh` 形状、H/L 守恒、总运动量、`S` 残差及 `bh` 变形的逐笔归因；均匀对照必须给零驱动/零 grant，非均匀场才检验 §2 候选。至少记录 0/5.1/30/60/120s 与连续时序，真实采样窗由 tester/effector 预注册。
2. **只读耦合**：对同一 S4 ON 物理快照分别渲染 C OFF/ON；沿 `bh` 上下固定**材质深度**追踪同一条层纹在 x 上的纵向位移，报其与 `bh` 起伏的相关系数、相位差及局部幅度，不用整图 row-mean 一项替代曲线跟踪。候选要求方向同号、无逐列折角/纹理滑屏；具体相关阈值由 C/E1 参考和 effector 冻结。
3. **交叉消融**：四格 `S4 OFF/C OFF`、`S4 ON/C OFF`、`S4 OFF/C ON`、`S4 ON/C ON`。第一行辨认 bh 物理轮廓，第二行辨认 C 条纹是否真正随界面弯；`S4 OFF/C ON` 的水平纹路不能冒称 S4 成功。E/A/B 与 C 已冻结/候选锚点各走原有适用域，不因 S4 新增而改阈值。
4. **主观出口**：effector 在静置、慢倾、回正后长窗评价“非平线重/轻沙分界、宽缓非周期波、层纹顺着界面、无呼吸/突跳”；沿现有 SV 量表登记，S4 候选不自行新设 PASS 分数。

若当前 C 实现只按列区域裁剪位图而层纹相位仍固定屏幕 y，可能出现“轮廓弯了、内部条纹没弯”；这是 E1 映射接口缺口，需 P-012 renderer 只读适配修订，**不能让 S4 直接改渲染像素或以物理 PASS 代替联合观感 PASS**。

## 6. 与 correction 基底的对接和决策门

当前调度为 `settle → percolate → creepBottom → relax/correction → lift`，请求先收集、恢复快照后按 total scale 应用；`vSandTopMax·dt` 是每列 local，`vBottomCreepMax·dt` 是既有 bottom 专账，`totalMotionBudget·dt=300·dt` 是共享硬顶。S4 是新增**深层**通道，不能无说明复用既有 10/s bottom 专账、duneResidual 或 correction 预留；建议先定义 S4 自己的 channel cap 候选但全部实际相搬运照常扣 local/total。A 的两笔逆向交换按固定事务原子提交或全部回滚，防一笔成功一笔失败留下沙顶变化、相比例和 guard 预演不一致。两轮 preview/apply 必须有相同排序与库存重验；guard 拒绝后 local/total/S4 channel 的 used/remaining 同步退款，审计 `requested=used+clipped`，不重复计两相运动为一份免费 q。

correction 矩阵尚未裁定前，只冻结**接口约束**：独立 routeId、默认关闭、同 seed/初态配对；正式槽位（相对 creepBottom 和 correction）、总额预留优先级、是否共享 10/s bottom 子账、长期 dormant 唤醒/休眠及遥测 schema 交 architect 复审。S4 不得混入今晚 correction A/B/C/D 同批结果，也不改其 26°/20° 基线。若 correction 满额占用使 S4 没有预算，结果登记为可达性/排期冲突，不能偷增总额度。S4 的长窗机制与既有“5.1s 内 ±45° 收敛”目标分开，不宣称解决阶段二全宽可达性或 legacy FAIL。

**建议裁决：**先批准 A 的守恒界面交换作为离线可达性/效果原型，配套“初始非均匀驱动是否存在”审计；若目标视频要求的是**真实孔隙压实**或上覆沙顶同时下陷，则 A 只覆盖界面观感，需另立 C 的固相/孔隙/水账；若 A 无法在 guard、库存、300/s 内产生可见慢变化，再评估 B。此顺序是设计推荐，非实现授权、非锚点冻结。交 architect 前需要 correction 裁决、S4 驱动场样本、目标视频 `bh` 同尺度量尺、各候选 shadow 成本与最小合法事务证明。
