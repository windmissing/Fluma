# STORY.md — 水沙三相算法方案讲解 PPT

## ① 用户意图对齐

- **目标受众**：用户本人（wind）——流沙画项目的决策者。读过算法方案文档但觉得纯文字+伪码难懂，需要用图讲明白「这套列标量三相模型到底怎么工作、为什么可信」。
- **核心目标**：看完能 ① 理解六状态列模型与四个动力学机制（沉降/分选/滑移/扬起）如何协作；② 明白 v1→v2.4 每一轮在修什么、为什么；③ 记住三条硬底线（分相守恒、无瞬移、峰值目标带）。
- **PPT 长度**：14 页（3 个 Hero 页 + 目录 + 3 章节扉页 + 8 内容页）。
- **视觉调性**：技术图纸感 / 清爽图表 / 大数字锚点 / 工程蓝。
- **内容边界**：
  - 必讲：列标量模型（六状态）、四机制、守恒账本、v1 硬伤、v2 修正、v2.2 速率限幅、v2.3 峰值推导、v2.4 坡度判据、测试底线。
  - 不讲：工程架构细节（模块划分、快照传输）、渲染集成、HarmonyOS 适配。
  - 禁碰：不出现内部实现字眼；公式全部翻译成图或大字标注。

## ② 构建页面布局骨架

- 页面总数 14，分 3 章：
  - 开场（P1 封面、P2 目录）
  - 第一章「模型是什么」（P3 扉页、P4 六状态列、P5 四机制流水线、P6 守恒账本）
  - 第二章「四轮迭代修了什么」（P7 扉页、P8 v1 硬伤、P9 v2 账本修正、P10 v2.2 速率限幅）
  - 第三章「数字怎么验证」（P11 扉页、P12 峰值推导、P13 测试底线、P14 结束页）
- 目录声明 3 章 → 3 个 section 扉页（P3/P7/P11），编号 01/02/03 连续，标题与目录逐字一致。
- Hero 页：P1 封面、P6 守恒账本（本 PPT 最核心的「为什么可信」）、P12 峰值推导（数字高潮）。P14 结束页默认 Hero。共 4/14 = 29%，占比合规，且两两不相邻。
- rhythm：P4 valley → P5 peak → P6 hero/peak → P7 transition → P8 valley → P9 valley → P10 peak → P11 transition → P12 hero/peak → P13 valley → P14 peak。无连续 ≥3 valley。
- 非对称版式：P1（全幅骑线）、P4（左图右文）、P5（左标题+右内容）、P6（居中巨型数字+环形账本图）、P8（非对称双栏 60:40）、P10（左大图+右文字）、P12（巨型数字+洞察）共 7/14 = 50% ≥ 40% ✅。
- 对称版式仅 P2（目录左标题右内容其实非对称，改为对称的 N 条目列表）、P13（图表+洞察）、P9（上下分栏 before/after）共 3 页，其中 N卡片横排 0 页 ✅。
