# DESIGN.md — 水沙三相算法讲解 PPT

## 画布与母版（三区）

- 画布：1280 × 720
- A 标题块：y 0–120，含上 padding 20；主标题 32–36px bold，左对齐 x=60
- B 内容区：y 120–660（可用 540px）
- C 页脚条：y 660–720；左侧「水沙三相算法 · HelloWorld」14px 灰，右侧页码 `NN / 14`
- 页面 padding：上下 20、左右 60

## 色彩池（4 hex，工程蓝图风）

| 角色 | hex | 用途 |
|---|---|---|
| 主色（深） | `#0F2A43` | 深蓝底（封面/扉页/结束页背景）、表头 |
| 主色（浅） | `#1D4E79` | 标题、图示主体线条、柱状图系列1 |
| 辅色 | `#7FB3D5` | 浅蓝填充、卡片底、水面/沙层图示 |
| 强调色 | `#F39C12` | 巨型数字、阈值线、警告标记（琥珀橙） |
| 中性 | `#2C3E50` 文本 / `#ECF2F7` 浅背景 / `#5D6D7E` 次级文字 | — |

- 色彩面积：主色 ≤60%、辅色 ≤30%、强调色 ≤10%（Hero 页 ≤20%）。
- 强调色只出现在：锚点数字、阈值标注、FAIL 标记、推导结论。

## 渐变与半透明

- 封面/扉页背景：`linear-gradient(160deg, #0F2A43 0%, #1D4E79 100%)`
- 内容页浅背景块：`rgba(127,179,213,0.15)`
- 卡片：白底 `#FFFFFF` + `boxShadow: '0 4px 16px rgba(15,42,67,0.10)'`
- 蒙版：无（不用照片背景）

## 字体（2 套）

- 标题/锚点数字：思源黑体 bold（封面 64px、章节 60px、锚点 72–96px、页面标题 32px）
- 正文：思源黑体 regular（正文 20–22px、卡片头 22px bold、脚注 14px）
- 禁止出现第三种字体家族

## 配图策略

- 本 PPT 全部图示为**结构化示意图**（列剖面、流水线、账本环、推导链），按配图规则走 **内联 SVG**，不使用 ImageGen（无照片/场景类画面需求；hero_cylinder.png 与 ending_glass.png 同样用 SVG 绘制容器剖面，保持全篇同为矢量工程图风格）。
- L1 主视觉：P1 容器剖面 SVG、P4 列状态 SVG、P6 账本环 SVG、P10 图表、P12 推导链 SVG、P14 收束图 SVG
- L2：P8 错误交换示意、P9 对向交换示意、P13 坡度判据小图
- L3：页脚左侧小方块标记（12×12 主色方），全篇位置一致
