- 日期：2026-10-19
- 基线目的：记录 v2.11 加强驱动前的默认场景观感锚点；不作为 v2.11 正式验收报告。

## 可见性量表

0 = 无可见变化；1 = 反复对比后勉强可见；2 = 知道观察点后可见但不自然不醒目；3 = 正常注视可见；4 = 明显且连续；5 = 强烈、立即可见。

## 五相主观记录

### Phase 0：`wstilt=0`

- 证据：`effect-baseline-p011-phase0-a.jpeg`、`effect-baseline-p011-phase0-b.jpeg`
- 形态：蓝色水体在上、黄色重沙居中、绿色重沙 mask 在下，三段清晰可读。水线接近水平；黄/绿交界接近水平直线。
- 重沙变化：静止基态下无可见蠕动、颗粒迁移或界面漂移。
- 主观可见性：0/5。
- 观感：画面稳定，但沙体质感主要来自纵向纹理，看不出真实沙堆的弧形轮廓或内聚力。

### Phase 1：`wstilt=+15`

- 证据：`effect-baseline-p011-phase1-a.jpeg`、`effect-baseline-p011-phase1-b.jpeg`、`effect-baseline-p011-phase1-c.jpeg`
- 形态：水面对 +15° 方向响应清楚，蓝色水体出现明显斜向水面。黄色/绿色交界有极轻微偏斜：与 P0 相比，交界一端略高、另一端略低，幅度弱，不构成可感知的“沙层移动”。
- 重沙变化：绿色 mask 的面积和位置基本不变；没有可见的渐进崩塌、滑动舌或底面蠕动。需要把 P0 与 P1 截图并排/前后切换才能确认交界差异。
- 主观可见性：2/5。
- 观感：水已经“知道倾斜”，沙不像同一物理系统的一部分；重沙界面更像固定的色带被轻微扰动，而不是被重力驱动的沙层。

### Phase 2：回到 `wstilt=0`

- 证据：`effect-baseline-p011-phase2-a.jpeg`、`effect-baseline-p011-phase2-b.jpeg`、`effect-baseline-p011-phase2-c.jpeg`
- 形态：水面恢复水平。黄/绿交界不再显示明确单向坡度，仅留下很浅的弯曲或局部厚薄差。
- 重沙变化：没有可见回填、崩落或再堆积过程；变化更像轻微残留，而不是有方向性的恢复运动。
- 主观可见性：1/5。
- 观感：回正后的静止感尚可，但缺少“材料被搬回去”的连续过程，因此回正显得被动而非物理。

### Phase 3：`wstilt=-15`

- 证据：`effect-baseline-p011-phase3-a.jpeg`、`effect-baseline-p011-phase3-b.jpeg`、`effect-baseline-p011-phase3-c.jpeg`
- 形态：水面对 -15° 方向出现清楚反向斜面。黄/绿交界有与 +15 相反的轻微坡度，但同样需要刻意观察。绿色区域仍像整块色带。
- 重沙变化：未观察到反向滑动、底沙迁移或渐进崩塌；也没有颗粒纹理层面的蠕动。
- 主观可见性：2/5。
- 观感：与 +15 相比方向对称，但响应强度过弱。倾斜期间“沙在流动”的直觉不成立。

### Phase 4：最终回到 `wstilt=0`

- 证据：`effect-baseline-p011-phase4-a.jpeg`、`effect-baseline-p011-phase4-b.jpeg`、`effect-baseline-p011-phase4-c.jpeg`
- 形态：水面回到水平。黄/绿交界基本水平，残留弯曲比 P2 略浅或相近。
- 重沙变化：最终态稳定，无可见漂移、回弹或持续变形；也无可识别的收尾坍落。
- 主观可见性：1/5。
- 观感：作为终点是稳定的，但过程感不足，前后更像状态切换，不像材料经历完整运动后的自然余势。

**当前自然运动观感基线：1/5。**

依据：默认场景整体分区和水线可读，画面稳定；但作为“自然运动”，五相中缺少肉眼可直接跟随的重沙位移、渐进崩塌或蠕动过程。与观测实验的 `ruleDriveTooWeak` 结论一致，主观上表现为“倾斜只改变水，几乎不改变沙”。

## v2.11 建议对比点

1. **重沙界面位移可见性**：对比 P0/P1、P1/P3 的黄/绿交界斜率、端部高差与残差；v2.11 应从“并排对比才发现”提升到“正常注视可见”。
2. **渐进崩塌感**：观察 +15/-15 前中后三张证据是否出现边界逐步推进、局部坍落或滑动舌；不应跳变为整体瞬移。
3. **底面蠕动**：观察绿色 mask 底缘与内部纹理是否有低幅但连续的迁移信号；可重点对比同相位早/中/稳。
4. **回正恢复过程**：P2/P4 不应只剩静止残差，应能看到小幅回落、再堆积或余势收敛。
5. **水体与沙体耦合感**：水线响应已明显，v2.11 需避免只强化水；沙体应与倾斜输入形成同一时间尺度内的因果运动。
6. **相位对称性**：+15 与 -15 的交界响应方向、幅度和恢复形态应大致对称，方向感不能只来自水线。
