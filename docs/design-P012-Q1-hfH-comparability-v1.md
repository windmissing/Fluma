## 1. 开题结论与三选一建议

**推荐①：按冻结附表 §5 新建 revision，先冻结统一显示尺度、缩放方式、ROI对应关系及分组，再重算参考/OFF/EAB。** 不推荐只将低分辨率参考放大到设备分辨率来“重算参考带”；不预先承诺归一化后EAB会落入参考带。③保留为证据不足时的后备，当前素材足以启动离线方法学收口，无须直接延期。

当前可比性结论是 **存在尺度、编码及ROI内容混杂，不能唯一归因为分辨率/编码，也不能据hfH剩余差值判定颗粒尺寸真的不同**。已有降采样结果5.021仍高于历史参考摘要带，因此“缩放已解释全部差异”不成立；“剩余差异全是视频压缩”也没有受控证据。可疑因素还包括纹理对比度、颗粒/团簇空间频率、沙层位置、材质与流动状态。

本方案讨论的是屏幕上的表观颗粒尺度和对比，不估计真实物理粒径。Q1是否能关闭，须依据批准后的同口径结果；仅形成此方案不关闭Q1。

依据：[算法 §12.3/§14](algorithm-P012-render-v1.md)、[冻结附表 v1](measurement-frozen-appendix-P012-v1.md)、[EAB报告 §4.2](dev-report-P012-EAB-batch-v1.md)、[tester复验](test-report-P012-v1.md)、[S1正式回执](sv-receipt-P012-S1-v1.md)、[第一梯队复盘 §6](retro-P012-first-tier-signoff-v1.md)。

### 2.1 本轮只读溯源发现

1. **两侧都是JPEG，不是“压缩参考对无损真机帧缓冲”。** 检查参考f0/f2、s99w pair1 OFF/EAB w1与s96 tilt8文件头：均为JPEG、RGB解码、4:2:0采样；参考与设备JPEG量化表不同。对量化表字典排序后JSON的SHA-256前16位分别为`c3e17d917125326c`、`d02ab6b4cad74f18`。这只是文件属性，不是编码影响量的估计；也不能从JPEG表反推出原视频编码历史。
2. **4.655的几何依据不够。** 报告将931（设备canvas宽）除以200（参考sand ROI宽）。目前附表确认的200是ROI宽，不是参考容器内宽；设备对应sand ROI宽为795。必须先确定两侧同一个几何长度，不能混用画布宽与ROI宽。这里不直接改用795/200：ROI裁剪范围不同，同样不自动代表显示尺度比。
3. **指标本身依赖采样尺度与对比度。** v1定义为 `hfH=mean(|Y[x+1,y]-Y[x,y]|)`，Y沿用8bit RGB的`0.299R+0.587G+0.114B`。它不是尺度不变量；线性变换`Y'=aY+b`即使空间尺寸不变，也会使hfH乘以`|a|`（无裁剪时）。所以单个hfH值不能区分颗粒更细与明暗更强。
4. **冻结脚本未漂移。** 本轮只读SHA-256仍为`03a8092913c1dc7e35201460977c8eb2acfd9121c02c5d6bd5b22bb4fabbbd06`，与附表一致。冲突不是靠当前脚本换指标解决的。

## 3. 拟议 revision 的固定口径（待 manager 批准后实施）

### 3.1 几何、缩放和测量算子

- **比较单位：容器内部显示宽度，而非整张截图或沙ROI宽度。** effector先为各素材登记容器内壁左右边界、裁剪原点及沙材质mask，tester核对；参考透视导致有效宽度无法唯一确定时，登记可用局部宽度范围并作敏感性检查，不默默拉直或非等比变形。
- **主档：容器内部统一为200个分析像素宽。** 保持纵横比，用两侧已确认内宽各自计算缩放比。200是采样尺度候选，不是新的物理/验收阈值；若任一参考有效内宽小于200，主档改为全组最小有效内宽并在首次出数前重新冻结，禁止先看EAB结果再选宽度。100宽度仅作降尺度敏感性档，不与主档混合；主档小于200时敏感性档用其一半。
- **单次面积覆盖重采样。** 解码原图后按v1公式得到浮点Y，再按像素面积交叠做平均，固定像素中心/边界与取整规则；不锐化、不补噪、不归一化对比度、不重编码主档输出。原图→目标图一次完成，禁止连续缩小。最终派生图存PNG，数值保持浮点算子结果，PNG展示值不反向作为测量输入。
- **mask先于统计。** 从原图标注纯沙区，排除界面、容器边、背景、UI和明显跨相边；目标像素的面积支撑完全落在有效mask内才纳入，hfH只统计左右相邻且均有效的像素对。双侧采用同一排除规则；遮罩和坐标在看新hfH前冻结。
- **薄沙带不补高度。** s99w 26px沙ROI缩到200内宽时约仅5.6行（按设备内宽931估算），必须报告有效行数/相邻对数与`SUPPORT_LIMITED`。不能将它拉伸成参考110行高的纹理块，也不能靠复制行增加样本。无有效相邻对时输出N/A。参考取相同归一化尺寸的上/中/下沙内patch作深度敏感性对照，选位规则预先固定；不同材质/深度不混成一个平均数来掩盖差异。
- **双轨输出：** `hfH_native_v1`保留v1原ROI结果；`hfH_display_v2_proposed`采用以上算子，二者有独立列与methodId。v1 ≥0.8下限继续用于原生口径，不能自动搬到归一化口径；其它冻结指标不借本次改写。

### 3.2 分组矩阵与归因方法

| 组 | 处理/对照 | 回答的问题 | 输出纪律 |
|---|---|---|---|
| G0 原生复现 | 原始参考、OFF、EAB按v1原脚本 | 历史数字是否可重现 | 与旧JSON对照，保留旧值不覆盖 |
| G1 主尺度静态 | s99w三对分别处理；参考f0/f5同算子、同显示内宽，按材质/深度分层 | 统一尺度后差距是否仍存在 | pair逐项报告；重复w帧仅检查确定性，不把9张相同帧当n=9独立纹理 |
| G2 尺度敏感性 | G1同一素材再按冻结的半宽档处理 | 结论是否依赖采样尺度 | 主/敏感性档分别列；不挑更接近参考的一档作最终答案 |
| G3 编码敏感性 | 对参考/OFF/EAB各自主尺度派生图，统一做JPEG Q=75/90、4:2:0、同版本编码器；再测相同mask | 再编码对当前素材hfH的扰动方向与范围 | 只作敏感性，不将任一Q拟合到1–2。双侧已有损失不可逆，统一再编码不等于消除原始编码差异 |
| G4 动态分组 | s96 tilt0..15原JPEG，按既有序号全量登记；参考f2/f6同主尺度 | 流动时纹理与静态差距是否同方向 | 按流动/趋稳状态分别报，不能跨s96/s99构建或静/动态合并；素材不足不填结果 |
| G5 尺度/对比辅助 | 在G1/G4同mask输出lumStd、逐行归一化自相关/功率谱（频率换算为每容器内宽周期数） | 剩余差异更像对比差异、尺度差异还是混合 | 仅诊断，无新增MUST-PASS。若去均值/窗函数/归一化用于频谱，明确登记且不作用于主hfH；宽谱不得强报单一“粒径” |

**归因规则：** 单素材跨G0/G1/G2的变化可说明该处理链的尺度敏感性，但不能把两侧差距相减就当因果贡献率。G3只能检验编码敏感性，不恢复未知原视频。若统一尺度下hfH仍偏高而归一化频谱/相关尺度接近，优先记录“表观对比差异候选”；若空间频率分布也持续不同，记录“表观尺度差异候选”；二者均不稳或mask支持不足则维持不可辨识。无论哪一种，都不借主观“无网格感”撤销数字差异。

### 3.3 参考带与通过规则的冻结顺序

1. 主参考集仍为v1的f0/f5静态、f2/f6动态；其余f1/f3/f4/f7为全量登记的敏感性参考，不能在出数后换入更宽的带。完整8帧都保留。首轮每状态只有2个主参考帧，只报告单帧值和描述性min/max，**不冒充总体95%置信区间**。
2. 先冻结算子、几何标注、分层、主参考集和“按状态报告min/max”的生成规则，再只用参考形成新描述带；EAB数据不参与定带。静态/动态带分开，不用动态较大波动放宽静态范围。
3. 新描述带是否成为正式验收区间，由manager在revision评审中决定；本方案不预填数值、容差或PASS。v1的1–2方向与1.16–1.75摘要保留为历史适用口径，不静默替换。
4. 批准后把参考/OFF/E/E+A/EAB已有适用素材全部按新口径重算并带methodId归档；缺某档有效素材就报N/A及原因，不用跨构建代填。v1输出同时保留，以便追溯差异来自何种算子。

## 5. 三个选项与经理决策点

| 选项 | 建议 | 理由 |
|---|---|---|
| ① 固定显示尺度/缩放方式的revision | **推荐** | 同时明确尺度、ROI支撑、色度计算及编码敏感性，能解释新旧数值的适用范围；不是为8.075扩大参考带 |
| ② 单独重算参考带到设备分辨率 | 不单独采用；若选，仍须走revision | 低分辨率放大不会补回原视频丢失纹理，插值会改变相邻差值；只处理参考一侧仍不公平。作为①的辅助展示可行，不能直接成为通过证明 |
| ③ PENDING转阶段二 | 后备 | 若容器对应/材质mask不足、参考压缩导致尺度不可辨识，或manager不批准revision，则保留PENDING并登记缺口；不为出结论强行合并组 |

manager本次需裁决的是①的实施范围和口径冻结流程，**不是立即批准新参考带数值或Q1通过**。批准前不实现脚本、不重算；批准后先签manifest和算子，再出参考带与结果，最后由designer复核、manager记录Q1状态。

## 6. 收口结果的分支与交接

- 若同尺度方法可复现、比较支持充分且EAB符合批准的新参考口径：按新revision关闭Q1可比性冲突，保留旧值及映射，不称原生8.075落入旧带。
- 若方法成立但EAB仍偏离：输出可量化的**表观纹理差异**，按G5区分对比/尺度候选，交manager裁决后续外观调优；不能只把带扩大到包含EAB。方法学厘清可完成，但纹理差距不因此消失。
- 若结果随尺度/ROI/编码明显翻转或支持不足：`HF_COMPARABILITY_REVIEW_PENDING`继续，明确不能区分的因素和最低缺失输入，必要时转③；不输出单一“真实颗粒尺寸不符”结论。
- 以上分支均维持第一梯队已批准的非阻断边界。C/D调度归manager，Q1不成为暗中的新阻断；后续若涉及已通过门槛回退，另按正式证据及流程处理。

本轮交付仅为开题设计。后续顺序：manager批准范围→effector/tester冻结manifest与revision草案→tester实现离线算子并重算→effector同尺度观感核对→designer判断Q1收口/真实差距/不可辨识→manager记录。现有素材足够启动上述离线工作，不申请真机。
