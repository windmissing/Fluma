34 runs 的配置峰值 **A=18.7°** 是输入幅度，不是阈值候选 pair。pilot 执行身份登记的候选为 **26°/20°**，主速率为 0.5°/s；这些是实验配置，不是标定结论。`alpha=atan(abs(decisionR))` 不等于 effectiveTilt，18.7° 输入可以在局部边激励 26° 残差角。

统计门槛比“每 cell 总共 20 事件”更严格：**fit 与 holdout 分别**每方向/type ≥20 合格事件、来自 ≥5 runs；每组四主 cell 和 24 子 cell 各 ≥30 状态样本/≥10 runs，每 run 每状态 cell 最多 3 个。最低 34 runs 为 24 fit+10 holdout，不能把 34 个 run 的全部事件混在一起判断充分。

因此即便暂接受全部 14 个事件，start/− 两组总需求至少 40，仍至少缺 26 个；实际缺额须保留原角色分别计算。其他三 cell 各至少缺 40。高频状态记录百万级不能代替按 run 截断后的状态数，checker 当前噪声子 cell 仍以 `UNDEFINED_NO_FIT_NOISE` 占位，不能宣称 24 层已达标。

报告中的“当前结构产出上限”应理解为**本批实测产出**。34 次重复的零产出既不是数学不可达证明，也不是增加速率必然有效的证据。

## 3. stop 排除链：实现偏差与真实动力学分开处理

### 3.1 可直接定位的资格实现偏差

以下是按冻结原文对照代码的设计审查意见，需 manager 路由 tester 确认/修订，本文不执行修复。

| 位置/现象 | 原协议要求 | 本次发现与影响 |
|---|---|---|
| `prior_state` 保存 `state["stable"]`；后续 `if not prev_stable` | 两端可以同一预注册 ramp leg，或同一合格稳定平台 | 前端点被强制为稳定平台；当前端点却接受 ramp。合法 ramp 的前端点会被误排。`PREV_ENDPOINT_NOT_ELIGIBLE` 不能直接解释为输入不连续 |
| 只对当前 edge/context 调 `endpoint_planner_clear/endpoint_clip_clear` | 两端及 ramp 三点窗口均须提交、未受限、身份连续 | 前端点实际裁剪可能未独立记原因；取消上一行误排后不能漏掉这项。必须完整保存前序上下文、clip 和 attempt 状态 |
| ramp cell 按 leg 符号归类，未在 bracket 处逐端核验非零 accepted 符号 | 不跨零点；零为 neutral，不能补四 cell | pilot 唯一计入的 start/− 含零角前端点，见 §3.3；14 个扩批事件只保留原报告数，不能先认定修复后仍有 14 个 |
| `perRunTransitions` 在资格判定前累加，用 `maxStatesPerRunPerCell=3` 截断事件 | 3 是状态样本上限；事件按 `(run,segment,edge)` 首个全资格转折选取 | 前 3 个不合格事件也可耗尽后续事件额度；这是状态/事件分母混用。`eligibleBrackets++` 又先于首事件去重，故还须对齐计数和真正保留的 bracket 列表 |
| `PlatformWindow` 仅识别 0/±15/±30 | 注册平台包含实际 ±A；稳定须 ≥200ms | A=18.7 的平台不能被该名单识别。另 pilot `physicsTime` 已为 epoch ms，Pass 1 又乘 1000，稳定窗口时长单位须复核。新增 stop 平台前必须解决这两项，不能沿用失真平台资格 |

完整复核还应核验 `decisionR/decisionAlpha` 实际采样点、`hardGuardClipped/hardGuardRejected` 的字段映射、两端 timing breach、同 segment、adjacent command/attempt、postSchedule 排除和首事件规则。当前 helper 读 `guardClipped`，pilot 实际记录为 `hardGuardClipped` 等，不能靠缺字段默认为 clear。

这些修订应同时消除误排与漏检；**不能只删不利的 PREV 规则保留其他漏检以求绿**。保持三点单调、≤0.5°、限制排除、零点隔离及所有安全门槛不变。

### 3.2 pilot 逐边证据：NONMONOTONE 不是单纯命名问题

对公开 pilot 按 `interfaceIndex` 保留紧前两条 decision，计算 `atan(abs(decisionR))`；扫描正式 schedule 时间内，排除 H8 自由演化尾部。下表仅统计非零 accepted 符号的真实 stop，是机制诊断计数，不替代正式全资格重放。

| pilot stop | 数量 | 三点非升失败 | 前端点 requested>granted | 前端点位于 ramp |
|---|---:|---:|---:|---:|
| stop/+ | 16 | 16 | 16 | 16 |
| stop/− | 27 | 26 | 22 | 27 |

可复查的窗口（角度单位 °，未平滑）：

| 边/leg/子步 | 三点 alpha | 前端点请求/发放 | 排除原因 |
|---|---|---|---|
| c=126，L2，1356/1357/1358 | 20.012237 → 20.041189 → 19.963696 | 0.0004071623 / 0.0001349799 | 先升后降，非单调；前端点裁剪。1358 是真实阈值 stop，q=0，不能把这一点解释成限流 stop |
| c=0，L5，2573/2574/2575 | 20.000643 → 20.044813 → 19.934257 | 0.0004430036 / 0.0004430036 | 前端点没有裁剪，仍非单调；说明不能把 NONMONOTONE 全归给预算 |
| c=125，L5，2994/2995/2996 | 20.160531 → 20.134613 → 18.570048 | 0.0013314853 / 0.0006593539 | 唯一非升 stop 窗口宽 1.564565°>0.5°，同时前端点裁剪 |

所以，即便只修正“ramp 前端点必须 stable”的错误，**这个 pilot 的 43 次 stop 仍全部无法按现行资格入池**：42 次非单调，余下 1 次过宽。此结论不外推为 34 runs 的逐边结论；扩批重放应由 tester 在原分组下生成逐原因交集表。

动力学解释：令 `z=decisionG−tan(thetaAccepted)`、`alpha=atan(abs(z))`。小变化近似为

```text
Δalpha ≈ (180/pi) * sign(z)/(1+z²)
         * [ΔdecisionG − sec²(thetaAccepted) * ΔthetaAccepted_rad]
```

同一输入保持期间材料 writer 仍改变 G；同一单调 ramp 也不能保证 alpha 单调。1356→1357 输入均为 17.2°，alpha 仍上升；1358 输入为 17.3°时才跨 stop。现有逐命令阶梯、子步材料反馈、邻边作用与预算缩放叠加，形成阈值附近锯齿。具体 writer 对 ΔG 的份额尚未分解，不能断言某单一通道负责。

仅加长恒角平台也没有充分性保证：孤立边、无邻边/其他 writer/倾角变化时，设超停止线量 E>0，修正请求 E/2、实际比例 λ∈[0,1]，则 `E_next=(1−λ)E`。λ<1 时只从上方渐近，不保证有限时间真实 stop；需要真实受控的残差下降且连续窗口未受限。不得用延长等待、q≈0 或人工清 active 制造 stop。

### 3.3 14 个事件的可信度边界

pilot summary 唯一 `firstBrackets` 是 c=125、L5、substep=2522：alpha 25.967820→26.008505，宽 0.040685°。原账本 2521 的 accepted=0，2522 为 −0.05°；前端点零角应归 neutral，不能作为同非零符号 bracket。该例证明“summary eligible”尚不等于完整协议资格。

## 4. 路径 1：先修离线资格，再设计 stop 激励

### 4.1 1A：零新增真机成本的诊断前置

输入为原 ledger、schedule/role manifest、构建身份及完整预算/decision 记录；输出以下审计表，不输出阈值估计：

1. 每组/方向/type 的 raw transition、完整资格通过、首事件去重后 retained bracket、独立 run 数分别列出。
2. 排除原因既输出单项数，也输出交集：PREV-only、PREV∩NONMONOTONE、PREV∩prevClip、width、零点、boundary、timing；不能用可重叠原因相加还原事件数。
3. stop 的两端和紧前点逐笔记录 `run/substep/attempt/segment/edge/accepted/decisionAlpha/active/qRequested/qGranted/clip/command`。同一 shadow 与真机使用同一资格函数。
4. 区分原 run 完整安全性、protocol metadata、状态/事件充分性；`PILOT_REPORT` 不替代统计达标。

离线窗口逻辑（设计伪代码）：

```text
for each committed decision in temporal order:
    retain previous two raw decisions for this fixed edge (including invalid attempts)
    if real transition:
        verify identity + consecutive substeps/attempts + same preregistered segment
        verify nonzero same accepted sign + both endpoints clear + timing clear
        if ramp: verify three consecutive eligible decisions and direction monotonicity
        verify executed threshold crossing + width <= 0.5 degrees
        if all pass and (run, segment, edge) has no previously accepted event:
            retain event; do not consume state-sample quota
    collect state samples independently with original per-run-per-cell cap
```

记录 rejected/rollback attempt 可通过旁路索引完成，不能删除后假装相邻提交。离线处理 O(记录数×127)，每边前序窗口 O(128)，无需将 2GB pilot 账本整体载入内存；正式 bracket 输出按需要落表。测试修订和真实重放归 tester，本文只登记设计契约。

### 4.2 1B：schedule v2 候选，不是已冻结执行单

目标是获得**有 active 风险状态、三点真实下降、两端未裁剪**的 stop，而不是保证命令回零。优先审计“峰值只作反转点，停止激励平台放在回程”的结构，避免强制在峰值 hold 5.1s 后 active 已消失。

每个符号的两个重复块为：

```text
0 hold → +15 hold
       → +A+ [反转点，不 hold] → +B+ hold → +15 hold
       → +A+ [反转点，不 hold] → +B+ hold → +15 hold → 0 hold
       → −15 hold
       → −A− [反转点，不 hold] → −B− hold → −15 hold
       → −A− [反转点，不 hold] → −B− hold → −15 hold → 0 hold
```

`15 < B_s < A_s < 30`，每个已登记平台 hold 5100ms；每个 A 为新的 leg 反转边界，无平台样本。共 13 个 hold，正负各两个循环。A/B 数值须由原物理路线的影子审计选出，不能默认 18.7 可用；可以发现根本没有可行组合。正负初态集合分别登记，不能假设镜像可达。

采前选择规则：

- 固定候选网格、初态/历史、dt/接受时序轨迹集合和排序，再搜索；不使用 holdout 定峰值。初步网格沿用 0.1°，搜索域限制在 planner+guard 可提交包络，主档 0.5°/s。
- 上程须有合格 start；反转时须有真实 active 风险边。下程新 leg 至少形成三个相邻合格 decision 后才可能贡献 stop；不拼反转前端点。
- 若 stop 在 B 平台发生，必须在平台稳定窗口完成后仍有 active，之后取得同平台完整 bracket；窗口建立前的 stop 继续排除。若只在下程发生，按 ramp 规则计数，不要求硬等到平台。
- 验证所有 writer/预算和自然库存，不注入坡形、不清 active、不暂停竞争通道。以固定排序选择第一个满足四 cell 和噪声可定义性覆盖的安全候选；没有则 `SHADOW_UNCOVERED`，不强推输入越闸门。
- 重复块只增加机会，不保证重新 active 或重现初态；第二块产出必须单独审计。正式选择仍按 `(run,segment,edge)` 首事件，不允许事后挑最窄事件。
- 新平台名单、反转点命令归属、CSV/hash、时间边界、A+/A−/B+/B−、每个 leg、随机化版本、分析版本全部冻结后才能申请 pilot。改 schedule 后新建统计层，旧 34 runs 不拼进新版正式样本。

**预期产出是规划目标而非预测实测**：每个循环每 cell 至少 1 个完整 bracket，两循环目标 ≥2/cell/run；若稳定达到，则 24 fit≈48、10 holdout≈20，事件数量与原最低 34 runs 相容。三点单调/预算/24 子 cell 任一不足仍不能扩批；不将“两个循环”算作两个独立 run。

止损：建议 manager 先只批准离线审计。审计通过后另批 3 个独立 pilot（不进 fit/holdout）；若任一 cell 持续零产出，或某噪声子 cell 结构性缺失，停止正式扩批申请，提交路径 4。3-run pilot 不证明统计成功，只筛掉明显零产出与身份/时序问题。

## 5. 路径 2：速率或候选 pair 扩充

减速可能减小参考线单步变化，却不能消除每子步材料 ΔG 或预算竞争；加速可能更早跨阈值，也可能扩大 bracket/增加 planner 限制。因此没有数据支持为 0.3/0.7 档承诺更高事件率。

| 扩充项 | 设计动机与风险 | run 数与产出规划 |
|---|---|---|
| 0.3°/s | 测试参考阶梯是否主导不单调；更长轨迹也可能使 active 提前消失 | 先独立 shadow；如需正式确认，新层 ≥34，目标 ≥2/cell/run，实测 yield 未知 |
| 0.7°/s | 检验输入扫速能否压过材料回摆；宽度和 planner 风险更高 | 同上，不能与 0.3/0.5 混合计额 |
| 已注册敏感性 1.0°/s | 可优先于新增速率作独立可行性诊断，减少新协议变量 | 正式独立确认仍 ≥34；不补主档 |
| 额外 pair，例如配置 (26°,18°)、(28°,20°) | 前者考察 stop 风险持续区，后者考察 start 上端覆盖；均在原搜索窗内，但可能进一步降低 yield | 每 pair/速率/schedule/build 独立 ≥34；两个 pair 最低新增 68。例值仅为待批准候选，不是默认拟合值 |

100ms 命令间隔下 0.3/0.7 的角步分别为 0.03/0.07°；现有 15°、18.7° 分段不全落在该网格。不可静默截尾。若选择这两档，需冻结“末段短步、实际速率≤指定速率、独立端点归属”的新生成规则及 hash，时长按实际 CSV 求和；这是 protocol revision，不是调常数后沿用旧 schedule hash。

新增 pair 的估计对象是该候选实际执行的状态机阈值/行为可用性。不同 pair 的 bracket 不可拼成一个“天然安息角”，也不能因某候选制造了更多事件就跳过安全、库存、噪声与 holdout 验收。

## 6. 路径 3：14 个事件能否先交付单侧/部分标定

**不能按当前协议发布 thetaStart-only 或单方向点估计。** 原因独立成立：资格待复核、14<任一组所需 20、start/+ 为零、24 子 cell 未验证、holdout 未满足、stop 缺失使双角分离判据不可核验。不能使用另一方向、另一速率或另一个 pair 填缺。

CI 宽 ≤2°是必要条件，不是样本数豁免。单事件宽 ≤0.5°只约束区间分辨率，不保证跨 run 中位估计的 CI、选择偏差或 holdout 复现；即使 14 个中点偶然得到很窄的 bootstrap 区间也不得作为标定通过。当前不计算/发布正式 CI，更不能从 14 的计数反推出 CI 宽度。

允许交付的是覆盖诊断：原始真实转换数、资格重核后的 bracket 数/缺额、排除原因、风险状态覆盖；拟合值与区间保持 null。真实 stop 已发生但全被排除时输出 `STOP_TRANSITION_UNOBSERVED` 的资格原因细分，不说“物理没有停止”；RIGHT_CENSORED 只有满足原风险/边界证据才使用，不能把预算、非单调或 checker 缺陷冒充右删失。

若 manager 将来要求独立部分标定交付，需新的 estimand/验证范围预注册；仍不豁免该 estimand 的原统计门槛，且不得将其宣传为双角完成。本轮不推荐启动这一分支。

## 7. 产出—run 数—真机成本统一账本

### 7.1 公式、假设与角色分配

原结构理想时长 `T0=9×5.1+4A/v` 秒。A=18.7、v=0.5 时 T0=195.5s；扩批报告 34 runs 共约142min，折算固定开销 `o≈55.09s/run`。下表用 `(T+o)×N` 估排期，开销包含报告时间段内重置/采集/落盘等的平均影响，**不是精确设备常数**；建议排期另留 20% 缓冲，不包含离线处理等待。

### 10.1 什么计为一个变体，当前数据能学到什么

区分产品 SKU 数 `N_product` 与实际不同的物理配置数 `N_phys`。纯颜色、纹理、外观样式且经只读隔离证明不改变物理场/参数/输入时序的变体，可申请复用同一物理证据；不同材料或容器不能仅因名字相近合并。未证实等价前，成本按 `N_phys=N_product` 保守计算。等价分组由 manager/architect 验收，不由 designer 在此宣布豁免。

建议先登记变体 manifest：`variantId`、材料身份/粒径分布/密度/液体黏度与适用温度、混合体积分数、颗粒/壁面接触类别、容器物理尺寸及形状、cols/capacity、长度单位映射、装填率/初始沉积历史、实际物理参数、route/build/hash。缺失物理输入标 UNKNOWN，不用产品名称或视觉纹理推断。

本次源码核对：

- `WaterSandField.ets` 的 `WaterSandParams` 使用 settle speed、diffusion、percolationRate、lift/creep/avalanche 等工程参数；粒径、真实密度、液体黏度未在该接口中作为独立输入接入。`cols/capacity` 为构造参数，直接改变数组、库存和容量约束。
- `P011RelaxHysteresis.ets::p011RelaxHysteresisNextActive` 直接比较 `abs(residual)` 与传入的 `slopeStart/slopeStop`。因此对一个已配置 pair，转换夹值主要识别的是**实际执行阈值**，不是独立测得的材料天然起停角。
- [P-008 f_sl 设计](algorithm-P008-fsl-design-v1.md) 仍为 DESIGN_ONLY/NOT_CALIBRATED；它预测分选 rate，不能自动提供起停角函数。heavy/large 身份、物理长度和压力闭合等缺口仍在。

必须先在两种估计对象间作选择：①“哪个候选 pair 能满足该变体的既定安全/效果要求”（工程参数选型，需要独立效果指标和候选比较）；②“真实材料的起停角随参数如何变化”（需要独立材料实验/可信外部标注及与列模型的映射）。**不能把执行时预先写入的角度作为标签，再宣称从相同轨迹发现了材料规律。** 固定 pair 下不同变体的 bracket yield、限流率、可达包络仍有研究价值，但属于可观测性/执行验证。


### 10.3 物理依据：可研究有界参数族，不能假设全局线性

以下研究支持**选取解释变量与划分适用域**，并未给本项目的 thetaStart/thetaStop 插值系数或误差界：

| 因素 | 有依据的变化机制 | 对本项目插值的限制 |
|---|---|---|
| 液体黏度、有效压力、剪切活动 | 稠密悬浮液的流变可按无量纲黏性数描述，材料摩擦响应与装填也相关 | 黏度改变响应时间/流动状态，不等于起停角随黏度线性或单调变化；必须固定或记录扫速、压力和历史 |
| 粒径、密度、颗粒接触 | 惯性/黏性竞争及有效重力随材料变化；微观摩擦可在无惯性条件下产生滞回 | 相同粒径/密度/黏度未必对应相同滞回，表面粗糙度/形状/摩擦类别不能遗漏；干湿、摩擦/无摩擦区制不能跨域插值 |
| 容器宽度、深度、壁面 | 颗粒表面流实验发现侧壁效应能显著控制流动；内部Janssen预研亦登记了压力饱和与壁面/历史依赖 | 不能只用capacity代替真实壁面条件，也不能把容器形状类别当连续数字插值 |

资料：[Boyer等，2011，稠密悬浮液流变](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.107.188301)、[Perrin等，2019，微观摩擦与滞回实验](https://arxiv.org/abs/1904.03918)、[Jop等，2005，侧壁效应实验](https://arxiv.org/abs/cond-mat/0503425)。上述结论仅用于限定模型，不把这些实验的阈值移植到本产品。

作为后续候选特征，可研究粒径比 `dL/dS`、密度比/浮力重度、装填率、宽深比/粒径尺度、接触类别，以及活动与压力归一化后的黏性数 `J=η_f*γdot/p_eff`、惯性数 `I=d*γdot*sqrt(ρ_p/p_eff)`。这两类无量纲描述见[原始移动沉积床研究及其流变定义](https://www.cambridge.org/core/journals/journal-of-fluid-mechanics/article/rheology-of-mobile-sediment-beds-sheared-by-viscous-pressuredriven-flows/372791ACDA36423A8932090909BCB1DC)。本产品的 γdot/p_eff 目前只是未标定代理，缺测时不得计算出伪精确特征；接近零有效压力/中性浮力等奇异区应另分域。

**列数和容量尤其不能简单当两根材料坐标：**

- cols 是离散分辨率，也是相邻边数；当前残差使用列高差与 tan(tilt)，须先明确物理宽度、dx、列高单位如何共同缩放。相同容器换cols需要离散收敛验证，不能用线性插值阈值补偿分辨率误差。现行128列不变，本节不授权改变。
- capacity 既可能表示物理深度变化，也可能只是单位/可用库存上限变化；需分别登记真实尺寸、lengthPerModelUnit、装填率和初态。相同capacity不能证明几何等价，不同capacity也不必然代表材料角改变。
- 固定 total 300/s、bottom 10/s 与局部额度下，列数/库存变化会改变每边可用额度及可达时间。因此**阈值插值成功不等于该几何的激励可达或预算合格**；planner/guard/守恒、时序与效果仍独立验证，不按变体数放大预算。

### 10.4 锚点模型、锚点密度与误差界

**可行性判断：当前证据不足以批准插值部署；仅建议对固定几何、固定接触/区制、低维且有界的材料族预研。** 已有一个配置且双角尚未标定完成，不能用它生成所谓已验证锚点。候选工程pair的优选规则也可能是离散/多解的；无唯一、平滑的目标映射时不适用下述插值，改为分族查表或继续PENDING。

建议候选为可审计的分片线性模型，而非直接拟合高阶全域曲线：将可验证的连续特征归一化为 x∈D，类别变量分族，速率/历史分层。每个锚点 i 有合格标签 `μ_start,i=tan(thetaStart,i)`、`μ_stop,i=tan(thetaStop,i)` 及来源/不确定度。在同一域单纯形内部采用共同非负权重：

```text
λ_i >= 0, Σλ_i = 1, x = Σλ_i*x_i
μhat_t(x) = Σλ_i*μhat_t,i                // t=start 或 stop
thetahat_t(x) = atan(μhat_t(x))*180/pi
```

这使点预测留在锚点斜率范围内，并保持锚点共有的正滞回间隔；**不自动保持含不确定度的间隔或真实物理安全性**。不得事后clip到[25,30)/[15,25]来掩盖模型失败；域外、类别改变、未覆盖几何/构建、身份未知或预测区间触及不允许范围时输出 `MODEL_OUT_OF_DOMAIN/UNRESOLVED`，不填默认角。

锚点布局应先冻结域的边界/内部点和独立验证点，再看结果。只有在同一族且证实有效维度低时，少数锚点才有成本优势：

| 有效连续维度 p | 预研起始布局示例（不是充分样本证明） | 对成本的含义 |
|---|---|---|
| 1 | 低/中/高3锚点，另留未见过的区间内部变体验证 | 2–3个锚点有可能有用，但曲率和误差仍待证 |
| 2 | 每轴3档的9点网格，另留单元内部/风险边界验证 | 不是“任取3种材料覆盖全部二维空间” |
| 3 | 3³=27锚点 | 单锚点34run已约76.65h正式设备时间，未含pilot/验证 |
| 5 | 3⁵=243锚点 | 约689.85h正式设备时间；盲目全因子甚至比逐SKU更贵 |

稀疏设计/自适应补点可能节省，但不能先承诺降到2–3个锚点。两个锚点只约束线段，三个锚点最多张成二维单纯形，不能覆盖独立五维参数域。用fit/训练变体做敏感性筛选；外部验证变体不可用于反复挑特征或调域，若改模型，原验证变体转为已见数据并另留新验证集。

**可写出的误差界是条件式，而不是本轮已得到的数值保证。** 若同一族内目标斜率函数 f_t 有经独立论证的 Lipschitz 上界 L_t，锚点标签绝对误差界为 ε_i，输入测量误差范数≤δ_x，则由三角不等式：

```text
|f_t(x) − μhat_t(x)|
 <= Σλ_i*ε_i + L_t*Σλ_i*||x−x_i|| + L_t*δ_x = E_t(x)
theta_t(x) ∈ [atan(μhat_t−E_t), atan(μhat_t+E_t)] * 180/pi
```

给定经批准的斜率误差预算 E_max，局部锚点距离须满足 `L_t*Σλ_i*||x−x_i|| <= E_max−Σλ_iε_i−L_tδ_x`；右侧≤0时，再密的插值也不能弥补标签/测量误差。若以球覆盖半径h控制距离，锚点数量通常随 `h^(−p)` 增长，这就是有效维度必须先确定的原因。观测点之间的最大有限差分只提供敏感性线索，**不能当作L的已证明全域上界**。

另一可选条件界：若标量角度目标在矩形单元内二阶可微且各轴纯二阶导有界M_j，多线性插值的曲率误差≤`Σ M_j*h_j²/8`，再加标签/测量误差。仅作密度设计工具；min/max预算裁剪、接触区制切换和候选选择跳变附近不能假定这些光滑条件成立。

当前没有L、M、合格锚点CI或独立变体误差数据，故不能写“插值误差≤某个度数”。原CI宽≤2°和fit/holdout差≤1°继续作为原标定门槛，**不是插值误差的免费预算**。模型预测区间、原参数估计CI、实际执行bracket三者必须分开；后续revision才可定义模型误差预算/区间覆盖要求。

若锚点误差来自95% CI而非确定界，上述组合界只在“所有相关锚点区间同时覆盖”的事件上成立；K个边际95% CI不能直接宣称整体95%预测覆盖。revision需注册同时覆盖/模型残差验证办法，且未见变体验证不能由run-cluster bootstrap替代。

### 10.5 插值路线的真实成本与协议影响

设 K 个训练锚点、J 个完全未见过的验证变体。在**尚不减免任何现行单变体统计门槛**的保守预算中，锚点和验证变体各按34正式run+3pilot：

```text
C_model_capture ≈ 185.363*(K+J) min
另加：模型研发、物理映射/测量、域覆盖证明、离线逐变体shadow、后续漂移复核。
```

例：仅对已证明一维的有界族，假设K=3、J=2，研究采集约170正式run+15pilot，15.45h，含20%缓冲18.54h；20变体逐个采集为61.79h/含缓冲74.15h。但**K=3/J=2不是已批准的泛化验证充分性**，也不代表剩余15变体获得当前协议豁免。只有revision明确模型验证与部署域证据后，才可将此作为潜在节约；否则正式合格覆盖仍按每变体34run预算。J必须覆盖风险域/类别，不能按期望节省倒推。

采集层面的潜在盈亏条件是 `N_phys > K+J`，还需节约足以覆盖模型工程与维持成本。对2–3种固定物理变体，模型路线通常没有采集优势；对数量不断增长但有效维度低的族才值得研究。若每新增SKU都落在不同接触类别或凸包外，J/K持续增长，插值不会消除线性成本。

| 协议事项 | 当前纪律保持 | 插值路线待revision事项 |
|---|---|---|
| thresholdCalibrationId | 旧ID/manifest历史含义不改；现有run不追认成模型数据 | 新ID绑定校准制品：protocolRevision、variantDomainHash、anchorManifestHash、modelVersion/modelHash、featureSchema、目标定义与训练/验证划分 |
| 目标变体身份 | 每run保留configured/executed及实现hash一致性 | 另记variantId/material+geometry hash、输入特征/单位、不确定度、modelDomain判定、anchorIds及权重、预测区间、predictionId；同一模型ID不等于所有变体同一个统计层 |
| 运行时阈值 | 不允许配置与状态机读取不一致 | model输出冻结为本run的configuredThresholds，executedThresholds逐笔核验；不可边运行边换模型/锚点而沿用同ID |
| 样本与bootstrap | 锚点逐pair/速率/变体保留34run、24fit+10holdout、四cell/24层、事件/CI等全部现行门槛 | 增加“训练变体/完全未见验证变体”外层划分；run级holdout只证明同变体复现，不能证明跨变体泛化；跨变体推断需单独冻结抽样和误差控制 |
| 验证与选择 | 不用holdout调阈值/噪声/选段 | 锚点holdout、外部验证变体以及model训练各自登记用途；联合检验多变体/多输出时注册覆盖范围和多重比较处理 |
| schedule | leg/零点/三点/宽度/预算等资格不变 | 冻结族内共用模板与各变体可达包络/参数绑定；不得借“共用模型”省掉四cell/噪声可定义性审计 |
| 部署与失效 | tan30、预算、守恒、库存、planner/guard不变 | 域外、预测不确定度过大、起停区间重叠/触窗、输入缺失或新build未复核时拒绝模型标定状态；不得默认回落到30°/20° |

特别需要新revision回答：未采集变体的状态是 `MODEL_PREDICTED` 还是经何种额外证据可称 `MODEL_VALIDATED_IN_DOMAIN`；均不得冒充该变体已有34run的 `CALIBRATED`。在manager裁决前，这些只是拟议语义，不新增实际状态枚举或改现行checker。

### 10.6 变体决策对路径选择的影响矩阵

| 产品情景 | 1A | 1B启动前必须确定 | 推荐路径/代价 |
|---|---|---|---|
| 2–3种固定、真实物理不同 | 共享修复，现有数据逐层核验 | 完整变体列表、每种候选pair/初态/可达包络 | 逐变体1B最直接，68–102正式run；含pilot/缓冲约7.41–11.12h+切换；无需为少量SKU先建插值系统 |
| SKU很多，但物理场/参数完全相同 | 共用资格实现 | 等价证明、物理配置hash与外观只读隔离 | 经批准按N_phys计数，不能按外观数量机械乘34；仍验证新增外观不影响运行时序/性能 |
| 十几种以上，固定几何、同接触类别、仅1–2个连续自由度 | 先完成，不等待插值研究 | 参数上下界、独立目标标签、有效维度、K/J与域外策略 | 条件推荐锚点+模型研究；先协议revision+manager裁决，再按族设计1B和验证，不直接批34N |
| 大量材料×多种容器，3–5维或多接触/形状类别 | 共享修复仍有用 | 物理族划分、cols/dx/容量映射、预算和边界可达性 | 先阶段二泛化/可达性审计，或产品限制为已验证参数族；不得承诺2–3锚点覆盖全部组合 |
| 用户任意自定义/无界输入 | 只能修复工具，不能提供全域覆盖 | 明确受支持的有界域、超域产品行为和验证范围 | 有界域内研究模型，域外保持UNRESOLVED；若产品坚持全域支持则路径4，不伪造全域标定 |
| 任一族四cell或噪声层仍不可识别 | 按原门槛诊断 | 缺失机制证据 | 路径4；增加变体/速率或插值不能填补不存在的标签 |

因此修正 §8 的调度为：**D0并行登记变体域与执行1A → D0.5 manager确定标定对象/变体策略/预算 → 才进入D2的1B具体schedule设计**。D0.5至少应形成一页清单：N_product/N_phys或连续域；首批支持族；物理输入和实现映射；是否需要真实材料角标签；每层pair/速率数；逐变体还是锚点路线；预算上限与域外策略。本文没有足够产品信息填定这些项，也不把未知N默认为3。

若选择插值，先预注册模型研究与外部验证方案，再申请对应pilot；本轮不执行采集、不改协议、不改变阶段一/观测③状态。多变体信息使1B是否值得投入成为更早的产品/方法决策，不影响1A已发现的实现偏差应被如实修正。
