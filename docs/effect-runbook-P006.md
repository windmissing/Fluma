# P-006 主观测试执行脚本（EC-OL-01~03）

> 用途：为 P-006 场景一“油水分层与容器动态”提供可复现的手工执行脚本。本文件仅准备测试资产，不运行真机、不生成证据、不修改业务代码。
>
> 权威用例：`docs/effect-cases.md` 中 P-006 的 `EC-OL-01~EC-OL-03`、`HG-OL-01~HG-OL-07` 与 `U-OL-01~U-OL-04`。

## 1. 执行边界

1. 本脚本只覆盖主观观感，不替代 tester 的 TC-11~13；精确守恒、时限、帧率与漂移结果不得折算为主观分数。
2. 每个场景至少执行 2 轮；同一评分员、同一设备、同一环境连续完成。若任一适用维度两轮差值 `>= 1` 分，追加第 3 轮并取中位数。
3. 每轮均保存完整录像、规定截图与环境记录；缺证据的维度记 `BLOCKED(no_evidence)`，不得填写推测分。
4. 触发任一适用 `HG-OL-*` 硬门槛时立即停止该轮，保留异常前、后至少 1 秒录像与逐帧截图；该场景判 `FAIL`，继续记录客观线索并移交 tester。

## 2. 固定前置

1. 启动配置：液体模式 `rendermode=3`、`testmode=true`、`forceinvert=false`。
2. 输入约束：测试期间禁用传感器接管；摇晃、倒立、翻回只能由测试脚本、页面调试入口或 Want 参数触发。
3. 参数映射：若实际入口或参数名与上述配置不同，在证据记录中登记“等价映射”，不得改判据或临时修改业务代码。
4. 相序判据：以“重相在下、轻相在上”为物理判据；报告必须记录颜色映射，不能把颜色示例当作物理结论。
5. 环境固定：同一设备、系统版本、屏幕亮度、性能模式、帧率设置；测试前关闭无关后台应用，避免系统弹窗。
6. 计时口径：使用外部秒表或录像时间码计时；截图时间以录像时间码为准，误差不超过 `0.2s`。
7. 录制口径：完整画面可见，包含液面、容器边界和时间码；录制帧率不低于被测页面显示帧率。

## 3. 证据目录

按技术路线建立目录，禁止混合路线：

```text
evidence/P006/<route-slug>/<YYYY-MM-DD>/
  EC-OL-01/round-01/video.mp4
  EC-OL-01/round-01/T00.jpg
  EC-OL-01/round-01/environment.json
  EC-OL-02/round-01/video.mp4
  EC-OL-03/round-01/video.mp4
  report-source.md
```

文件名只使用大写场景 ID、小写 round 编号、`T` 加秒数与固定扩展名；新增截图不得覆盖既有文件。

## 4. 场景脚本

### EC-OL-01　静置水平界面

| 步骤 | 时间 | 固定操作 |
|---|---:|---|
| S01 | — | 进入液体模式，确认 `testmode=true` 且传感器接管已禁用。 |
| S02 | 0.0s~2.0s | 不做任何输入，等待初始稳定。 |
| S03 | 2.0s~32.0s | 持续静置观察 30 秒；双手离开设备或保持完全静止。 |
| S04 | T0/T5/T10/T20/T30 | 以静置开始时间为 T0，保存 5 张关键截图。 |
| S05 | 稳态末帧 | 分别以 100% 与 400% 缩放检查一次界面，保存检查结论。 |

评分维度：分层可读性、界面平滑度、稳定流畅度。硬门槛：`HG-OL-01~04`、`HG-OL-07`。可暂失败项：`U-OL-03`、`U-OL-04`。

### EC-OL-02　摇晃暂时混合与静置恢复

| 步骤 | 时间 | 固定操作 |
|---|---:|---|
| S01 | — | 先完成 EC-OL-01，或确认两相已达到等价稳定分层。 |
| S02 | 0.0s~6.0s | 执行 10 次强 swipe：第 1 次左→右，第 2 次右→左，后续交替；每次 swipe 在 0.3~0.5 秒内横穿屏幕中间 70% 宽度，每 0.6 秒启动 1 次。 |
| S03 | 6.0s | 停止输入，立即将双手移出触摸区；以停止时刻为恢复段 T+0。 |
| S04 | 6.0s~36.0s | 静置观察 30 秒，不做额外输入。 |
| S05 | 混合段 | 每整秒保存截图：M1~M6。 |
| S06 | 恢复段 | 保存 `T+0 / T+2 / T+4 / T+10 / T+30` 截图。 |

评分维度：分层可读性、动态自然度、恢复可信度、稳定流畅度。硬门槛：`HG-OL-01~05`、`HG-OL-07`。可暂失败项：`U-OL-02`、`U-OL-03`、`U-OL-04`。

### EC-OL-03　180° 倒立与翻回交换

| 步骤 | 时间 | 固定操作 |
|---|---:|---|
| S01 | — | 确认液体模式处于正立稳态；保存事件前截图。 |
| S02 | T0 | 触发 `invert180()` 开，只执行一次，不插入其他输入。 |
| S03 | T0+0.2s / +1s / +2s / +4s | 保存翻转后截图。 |
| S04 | 最多 10s | 静置等待稳定；稳定定义为连续 3 秒无可见整体流动或相序变化。若 10 秒内未稳定，如实记录未稳定并继续到稳定或 30 秒。 |
| S05 | 稳定末帧 | 保存倒立稳定末帧截图。 |
| S06 | T1 | 触发 `invert180()` 关，只执行一次；仍不插入其他输入。 |
| S07 | T1+0.2s / +1s / +2s / +4s | 保存翻回后截图。 |
| S08 | 最多 10s | 按 S04 口径等待翻回稳定；若未稳定，继续观察至稳定或 30 秒并记录。 |
| S09 | 稳定末帧 | 保存翻回稳定末帧截图，并确认回到重相在下、轻相在上。 |
| S10 | — | 导出 `invert180()` 两次事件日志与边界日志。 |

评分维度：分层可读性、界面平滑度、动态自然度、恢复可信度、稳定流畅度。硬门槛：`HG-OL-01~07`。可暂失败项：`U-OL-01`、`U-OL-03`、`U-OL-04`。

## 5. 评分流程

1. 每轮先记录硬门槛，再记录 `UNRESOLVED_FAIL`，最后给适用 TIERED 维度打 0~10 分。
2. 未实际观察到的维度记 `N/A` 并写明原因；不得给默认分。
3. 及格线为 `6` 分；任一适用有效维度 `< 6`，该场景判 `FAIL`。
4. `UNRESOLVED_FAIL` 只登记缺口与证据，不参与首轮恶化判定；后续转常规软门槛后必须达到 `>= 6`。
5. 评分以同一技术路线上一版为唯一对比对象；分数提升为改善，下降但仍在 `>= 6` 为可接受，跌破及格线或触发硬门槛为恶化/未通过。
