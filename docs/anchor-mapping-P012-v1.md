## 1. 核心结论：`<8` 与 `≤30` 是两个不同口径，非矛盾

| 项 | 算法 §4.3 / §8 的 `<8` | 冻结附表 §3.3 的 `≤30 量级` |
|---|---|---|
| **测量定义** | 竖向 8 段采样（段内阶梯 ≤2.2 亮度）+ 界面带顶部前 2 段 ramp 渐入——**渲染实现侧的段阶梯梯度**（EA 报告 §3 第 5 项，测量图像 `p012-ea-s87-on.jpeg`） | 冻结脚本 `measure_render_p012.py` 的 `max_grad()`：**法向带内逐像素垂直相邻行亮度差最大值**（无段聚合） |
| **ROI** | EA 报告未附具体带坐标（`p012-ea-s87-on.jpeg` 实测复算：hybrid0 profile 得 48.01 / ws15 profile 得 51.0，均非 5.6）——5.6 来自 8 段聚合口径，与冻结脚本口径**不可直接互换** | ws15 界面带 `(240,1700,1035,1900)`（附表 §2；ws0 界面 ROI 不适用，附表 §4 注 1） |
| **冻结依据** | 设计时点估算锚点（§4.3"平滑包络本身的最大导数约 1.5·ΔY/wFull，给 maxGrad<8 留余量"），**未进冻结附表**，developer 实现侧自证 | 附表 §1 定义冻结 + SHA-256 固定脚本；参考帧 20.7–60.9 与 OFF 基线 116.5 同口径 |
| **适用性** | 用于 EA 实现定标（8 段采样设计使段间阶梯达标）；**不能**用来判 EAB 交付帧 | 唯一可跨档对比的正式口径 |

**裁定**：两者对"梯度"的聚合方式不同（段阶梯 vs 逐像素），数值不可比。EAB 交付验收以冻结附表口径为准：`maxGrad 16.3`（ws15 界面带、逐像素）。**16.3 未通过 `<8`，但 `<8` 从未是冻结附表的验收线**；冻结附表的验收方向是"≤30 量级、配合 width 增大"（§3.3），16.3 满足。`<8` 若要成为交付验收线，须走附表 §5 revision（新增段聚合指标定义），本表不代做。
