## 3. 最小工程修订与验据

1. **确定性设备近床正控**只改 T392 隔离入口。重置空床、关闭该臂的 sensor 输入覆盖，固定实际 0°。用原 source 准入 H=0.3、x=63.5、y=0.004、seed=51、Nmax=512，检查 source 回执、真实入量及新生 ID/slot generation，拒绝非预期 ID 或分量。先创建并绑定预约，再在原事务入口执行准入。固定每次只提交一个 `1/60` 的有效子步，按真实成功子步计数，墙时另计。预期第二成功子步列63 三笔 kind=2 正授予、余量 0、各自一次退役及床增 0.3。沿原 T381 sink/guard/audit/commit，禁止模拟成功、越过容量或改 guard。
2. **受限对照**分两种。复用真实触摸臂，允许立即取到已提交零获准 T3 原因及票据，不必等待正授予才能导出。另用原近边界坐标、目标 25° 的确定性夹具验证一全额、一部分、一零授予，实际角 12°/24° 和列64 是离线参考，设备有偏差时保留原 guard 及账。按真实选择源、提交及显示身份记账，跨列记录与原列 LAND 分开。
3. **预约与等待**。记录 armId/run/epoch/起始时间，UI 显示真正的预约状态及有效回调、成功子步数。隔离近床预注册最多 **8 个成功子步、16 个前台回调、15 秒单调墙时**，任一先达即冻结并可导出。受限臂在预定目标 ID 的第一条已提交 T3（包括零获准）即留档，无目标事件也能导出有界终止证据。保留首次候选 T3、首次正授予及各自 publication/candidate/原码，重复 arm、reset、隐藏或超时显式终止/换代。区分未进入准入、未绑定、ID 不匹配、零获准、已有正授予但无对应 draw、保存失败等状态。检查 wall 到期无需等新的物理步，前台事件间断则在定时器或恢复时结束并披露实际 wall。
4. **呈现分账**。正控单子步可让 LAND 对应的 publication 直接进入同回调 draw。其他情况下保中间成功子步的真实 LAND 档，若被下一步覆盖则明确未选中。只有同一 publication identity、ledger、epoch、native request/rendered token、CURRENT 与实际成功交换均成立，才记该 LAND 同 token。系统呈现与交换继续分列。输出冻结证据与 SHA，维持 8 ID/有界事件存储、无常态额外扫描、原 rollback 与 endpoint wire。显示只走 XComponent+shader（前后景一致），错误发布 FAULT 或完整旧 token STALE。
