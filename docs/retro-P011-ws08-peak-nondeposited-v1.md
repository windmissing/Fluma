## 候选与选择

- A 仅保留旧peakSusp：历史可追溯，但第三桶改变U而非M，适合作迁移期双报，不能长期代表C的总非沉积库存。
- B 固定摇晃窗max((U+P)/E)：选为唯一推荐；质量转列/合并不变、与canonical床层互补。原0.5与分档锚点建议保留，仍待独立批准。
- C 输入最大时刻的库存：shake=1是平台，必须人为定tie；最早时刻可能尚未响应，挑库存最大tie又退化为B，故不选为主量。
- D 排除接触待准入：便于观察运动，但状态1→2并未入床就降低质量；且U不等于纯移动库存，保留分项诊断。
- E 净增量或累计LIFT：前者有助识别初始残余，后者受重复扬起污染；均不能沿用旧库存比例阈值，保留诊断。

1. 旧量是TIERED、0.5为6分及格；不能把迁移写成新增全部硬门槛。
2. checker当前取全序列max，未落实书面摇晃段；候选明确固定shake-on后3s，不把rest峰值捞进来，脚本修复交tester/developer后续流程。
3. manager后续已澄清历史分母D+U与C live分母D+U+P。新量相对live差P/E，相对历史参考差PD/[E(D+U)]，不能套前一设计里的同分母简式到所有比较。
4. 独立分项峰相加、250ms与全子步峰相减、全序列峰与摇晃峰混用，都可制造改进。新报告分列提交身份、时间窗、分母和采样密度。
5. state2计入是库存定义正确性，不证明正在飞行；初始已悬浮亦可制造高库存峰而无新增LIFT。明确限制结论，并列M0/净增量/接受LIFT/状态诊断，不暗设新及格线。

7. 历史直接证据是P003/P005的BLOCKED RED，未找到正式数字峰值结论；无证据不宣称历史通过。
