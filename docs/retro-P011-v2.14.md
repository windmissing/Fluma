# P-011 slip-overshoot-v2 设计复盘（v2.14）

> 日期：2026-10-19。路线：`slip-overshoot-v2`。状态：`BLOCKED / DESIGN_NOT_CALIBRATED`。本复盘只基于 `p011-slip-overshoot-v1` 真机 ledger/raster 与现有参数作解析，不修改代码、测试用例或历史观测。

## 设计修订

算法 §8.13 的固定 omega 选择改为“逐子步角度可行域投影 + 候选 omega 限速”：由真实已授予材料变更推导全边允许的 `effectiveTilt` 区间，再在区间内追随目标。该方式是 hard invariant 的必要结构；单独降低 `maxTiltOmega` 不能对任意 slack 作安全证明，也不保证坡面收敛或体验 P95。

## 30°±2°的几何反算

正式目标是 ±45°超角输入下 raster 全宽线性沙面坡度达到30°±2°。在 +45°稳态，停止状态基于 residual `r=tan(phi)-tan(45°)`，所以30°中心对应 `atan(|r|)=22.911°`；phi=28°/32°分别对应 residual angle 25.093°/20.563°。这给出候选 `thetaStop` 几何范围，不是经验参数。起动角必须严格小于 hard 30°且大于停止角；现有 ledger 没有 `activeBefore/After` 状态转换样本，故无法估计 start/stop 的点估计、区间或转折误判率。

## 额度与5.1秒审计

假设目标 raster 回归覆盖全128列，从平坦 `S0` 到线性斜率 `tan(phi)`。相邻守恒输运的累计边通量为 `sum F=tan(phi)*128*(128²-1)/12`，中央边通量为 `tan(phi)*128²/8`。30°中心分别需约100,893和1,182 model units；±2°内最低28°也需92,917及1,089。当前总额度即使把5.1秒全当物理时间并全部给该目标，也只有1,530；thick滑移单边80/s在5.1秒最多408，中央边速率本身至少需13.61~15.98秒。t90到27°（30°角度响应的90%）仍需总边通量约89,041、中央边约1,044，超出5.1秒预算与80/s边速率。因此**当前相邻表层滑移机制无法在既有速率/额度内形成全宽线性30°坡面，也无法满足5.1秒t90**。±45°真机证据的最终可见线性坡度仅0.23°/0.52°，测得t90约6.5秒，且484次逐边硬越界；这与解析否决方向一致。

该下界针对全宽线性目标和相邻坡面通量，不能被误写成全物理通道的绝对无解证明。lift/settle可能暂时改变 `sandTop`，但要证明可替代，必须用同一完整账本给出空间定向、库存、悬沙扩散、总预算和最终 raster 的合法递推。目前没有这种轨迹，不能把未证明当作预算已足够。

## 结论与交接

这轮完成几何关系和当前相邻滑移方案的预算否决，未完成真实角度经验标定。`thetaStop=22.911°` 仅为将30°目标映射到逐边 residual 的几何中心，不得直接配置；`thetaStart` 仍无观测估计。现有资料不足以宣称 `READY_FOR_ARCHITECT`。可将本节作为条件性 BLOCKED 数学审计交 architect 复核，但要批准路线必须先由 manager 裁决目标/路线或提供新观测授权；若目标与六项门槛不变，则不得以降门槛、加预算或更换几何制造通过结论。
