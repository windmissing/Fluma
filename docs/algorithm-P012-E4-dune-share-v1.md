- 日期：2026-10-24；责任：designer。
- 状态：`MEASUREMENT_DESIGN_READY / NOT_MEASURED / NO_THRESHOLD_FROZEN`。
- 输入：`gap.md` E4、`goals.md` G2/G2.7、`PROJECT_GOALS.md` 场景二、`p012-water-cloud-sand-demand-anchor-v1.md`、`design-P012-C-stratification-anchors-v1.md`、P-012 EAB 效果/测试报告及 E3 冻结材料。
- 边界：纯测量设计，不改物理初态、渲染、已冻结 E3 窗口或任何锚点；不使用真机，不预填精确比例/误差阈值。相机/裁切/透视和姿态构图在比较组间固定。

## 1. 问题拆分与目标语义

“沙丘约占画面 2/3”目前是目标帧的近似视觉描述，不是冻结的 66.7% PASS 线。E4 拆成两个独立问题：

1. **占比**：同一构图内，模型沙体轮廓所覆盖的面积比例；另报告渲染帧可见沙区面积，揭示雾遮挡。
2. **形态**：沙面轮廓与目标关键帧的尺度归一化差异，以及沉积层次是否仍可辨。面积相同不代表轮廓相同，轮廓接近也不代表内部层理通过。

主测为 `A_geom`（模型几何占比）；图像分割得出的 `A_visible` 作为遮挡诊断。这样“沙量/形状不足”不会被雾画得厚或薄改写。目标帧无法直接读取模型 `sandTop`，故对目标图按同一规则人工标注沙面轮廓并给出标注不确定带；当前目标素材压缩/遮挡导致边界不能唯一判定时，报告 `REFERENCE_BOUNDARY_AMBIGUOUS`，不得用猜定单值算差。

## 2. 占比口径与候选取舍

### 2.1 主口径：轮廓以下几何面积 `A_geom`

以容器内侧有效成像区域为 ROI，记录其四边坐标；所有图像先按相机/构图标定映射至同一归一坐标，保持纵横比，不做非等比拉伸。有效区域之外的黑边、装饰框、圆角外区域排除。容器底部内缘为 `y_bottom(x)`，沙体顶界 `y_sand(x)` 由连续 `sandTop` 映射到图像坐标。重力向下的规范朝向下：

```text
A_geom = ∫ROI max(0, y_bottom(x) - y_sand(x)) dx / area(ROI)
```

离散实现使用 `sandTop` 相邻列线性插值后按像素面积积分；分母是容器 ROI 全面积。几何 ROI 与 `sandTop` 使用同一 frame token、adapter/build、物理快照、旋转/倒立语义和显示变换。若图像只提供截图而无同源模型字段，只能计算图像轮廓近似值 `A_visible`，不得标成 `A_geom`。空沙输出0；缺列、非法几何或无法映射时输出 `INVALID_GEOMETRY/UNAVAILABLE`，不以全帧默认为零。

对于全画面字面占比，附报 `A_geom_frame = A_geom × area(ROI)/area(full frame)`；主判定与跨设备比较仍使用 ROI 内比例，避免边框、状态栏和设备截图裁切造成伪差异。若原目标帧没有可确认的容器内缘，标 `ROI_UNMATCHED`，停止比例对比，先补构图标注。

### 2.2 可见占比与薄沙厚雾诊断 `A_visible`

在冻结的容器 ROI 内，以像素标注分为 `sand / interface-fog / water / uncertain`。`A_visible = sand像素面积 / 有效ROI像素面积`；不确定像素只进入上下界：

```text
A_visible_low  = 明确 sand / 有效ROI
A_visible_high = (明确 sand + uncertain) / 有效ROI
```

固定色彩输入与标注规则，不用全局阈值自动分割后把浅色雾/沙误归一类；目标参考和 EAB 都保存原图、ROI、分类 mask、uncertain mask、标注者/复核记录。`A_geom − A_visible` 是可见性诊断差，不直接称为雾贡献，除非同快照雾消融配对支持因果结论。

### 2.3 候选方法比较

| 候选 | 可执行性 | 对目标帧可比性 | 对“薄沙厚雾”敏感度 | 结论 |
|---|---|---|---|---|
| a. sandTop 线以下面积（轮廓面积） | 模型字段直接可积；同源稳定 | 需在目标图按相同容器 ROI 标注沙面；可比但参考边界有标注不确定性 | 几何版不受雾影响；配套 `A_visible` 对遮挡敏感 | **主口径**：分开回答几何覆盖与被看见的覆盖 |
| b. 质心/轮廓同构图（IoU、边界距离） | 需两帧同构图、ROI和轮廓标注；可复核 | 最高，直接比目标形态；目标歧义需区间/NA | 可见轮廓受雾敏感；模型轮廓不受雾影响 | **备选/形态主指标**：报告模型与图像轮廓两条轨道 |
| c. 沙堆水平宽度/ROI宽度 | 易测，报告 `W50`（半高宽）及支撑宽度 | 同构图下可比，单值信息有限 | 雾通常影响较小，但边界模糊会扰动阈值宽度 | 辅助诊断，不独立定占比或形态通过 |

采用 a+b 而不把任一项单独替代另一项。宽度只解释形状，例如宽而薄与窄而高可有相同面积。对目标帧给轮廓 IoU、对称平均边界距离（归一化 ROI 对角线）、沙体面积质心 `(cx,cy)`、`W50`、`H95`（沙面相对ROI底部高度的95分位）及左右/分区面积；这些是描述量，**不设新的通过区间**。图像轮廓 IoU/距离均须与不确定边界上下界同时报告。

## 3. 图像身份、采样与报告字段

### 3.1 配对条件

- 固定：设备/build/renderer、容器内 ROI、显示尺寸/DPI、相机位置/镜头/透视、容器姿态、光照/色彩状态、场景时间/静置时长、输入序列、随机种子与 E/A/B 配置。记录 `buildHash, frameToken, physicalSnapshotHash, sceneConfigHash, renderSeed, geometryEpoch, orientation, ROIRevision, maskRevision`。
- 目标集：以 `PROJECT_GOALS` 场景二的目标效果和原始目标关键帧为准；参考帧需按静置/动态阶段对齐，不把 EAB 的最显眼帧换成参考主帧。静置与动态分组报告，原参考帧索引保留。
- 当前 EAB：先复现现有正式 EAB 取景并存基线；后续 E2/E3/S4 完成或配置身份变化后，在相同场景时点重采新版 E4 基线。每个静态条件至少3个独立配对快照作为重复性观察；动态序列按预注册 `frameId` 输出全序列，不挑帧。该重复次数为采样建议，不是PASS门槛。
- 目标与EAB原图只做一次几何映射/面积重采样，不裁剪沙面、不人工拉直或透视矫正到改变形状；有透视时同一相机映射或标记不可比。标注轮廓不确定段，不将JPEG边缘当作精确像素边界。

### 3.2 输出

每个 frame/ROI 同时报告：`A_geom`, `A_geom_frame`, `A_visible_low/high`, `(A_geom−A_visible)`，ROI有效/不确定面积，轮廓 IoU 与归一边界距离区间，质心偏差，`W50/ROI_width`, `H95/ROI_height`，左/中/右分区 `A_geom`，静置/动态标签，配对差及重复间 min/max。给测量 `methodId=P012_E4_DUNE_SHARE_V1`、算法版本、图像/mask 哈希和原始坐标。首轮只报原值、重复性与目标不确定范围；没有 manager 冻结的数值通过线时写 `MEASURED_NOT_CALIBRATED`。

## 4. 差异归因：几何量与可见量分路

初始沙量候选必须对应 scene config 中 `bh+bl+mh+ml` 的初始总量/分布；不改变求解器、守恒规则、材料参数、沙水比例语义或代码。雾候选仅为 P-012 appearance 域配置试验，保留 E3 冻结门槛和身份。建议用两个互补实验，不从单一截图归因：

### 4.1 沙量/物理初态效应

固定其余物理与 appearance 参数、构图、重力/输入序列、seed、模拟时长和稳定判据。预注册 baseline + 至少两个有序沙量候选（幅度待 manager/physics owner 决策，不在本稿给数），对每档独立运行仿真；逐档检查物理有效性、三相守恒、沙体支持高度/分布与同一时间点稳定性，再计算 `A_geom` 及形态量。画 `A_geom vs initial total sand` 与 `A_visible vs initial total sand`，记录边际变化和是否出现不单调/饱和。若 `A_geom` 随初态变化而响应，且同快照可见率差不主导，则证据支持场景初态贡献。不能把增大场景库存描述成渲染修复。

### 4.2 雾带可见性效应

从同一个物理快照/同一沙几何、同构图、同 seed 生成 `fog-current` 与 `fog-diagnostic-off`（诊断消融，不是产品配置）图像；另可对注册的候选雾参数做单变量 appearance 变体。测 `A_geom`（理论应完全相同）、`A_visible`区间、轮廓边界不确定面积及沙面局部对比。只有 `A_geom` 不变而 `A_visible`/边界可辨性改善，且 E3/J95/J90/std 与雾窗现有门槛仍满足，才支持雾遮挡对差异有贡献。雾完全关闭仅做归因探针，不作目标观感通过图，也不能据此修改冻结窗。

### 4.3 双因素与结论分类

| 观测结果 | 归因结论 |
|---|---|
| 初态沙量变化推动 `A_geom`/轮廓靠近参考；雾变量对同快照 `A_visible`影响小 | 初态主因证据 |
| `A_geom` 已接近参考；同快照雾变体显著改变 `A_visible`或边界辨识 | 雾遮挡主因证据 |
| 初态变化改善 `A_geom`，雾变体又改善其可见轮廓；联合效果不等于单项简单相加 | 混合/交互效应；按两项交叉格报告 |
| `A_geom` 与 `A_visible`均有差、变化不稳定或参考不可辨 | `UNRESOLVED/REFERENCE_LIMITED`；不硬分给渲染/物理 |

完整交叉格为 `sandInitial {baseline, candidate} × fog {current, diagnostic/candidate}`，但物理初态档必须独立仿真，fog 两档严格使用每个档位的同一个物理快照。因此每个沙量档内有严格配对的雾比较；沙量档之间用相同 build、seed、时间表和姿态作为重复条件，不声称物理快照相同。报告主效应与交互的观测方向、离散样本范围，不拟合/宣称无支撑的因果模型。

## 5. 仅登记的调整路径与兼容性

1. **场景初态加沙**：唯一归 scene/config 层，由 manager 与物理 owner 确认候选；designer 当前只登记量测变量。调整后必须重验水/各沙相守恒、沉降与堆积稳定、安息角、分选和层纹承载高度；不得改物理代码或通过画面 scale 伪造更多沙。
2. **雾带收窄/改 appearance**：只列为候选，先核对 E3 revision/测试。既有 A 档雾 alpha 上限 `0.78`、冻结的 E3 `stdRatio [0.90,1.10]` 与雾带窗 rows `950–1100` 属既有约束；本稿不改变任何一项，也不把alpha上限误作建议目标值。不得重解释冻结窗或用诊断关闭雾替代产品配置。任何候选如影响上述窗口必须独立走 revision、重采基线并由 manager 批准后才能成为实施输入。
3. **构图保持**：比较期间相机、zoom、容器ROI、裁切、画布比例、DPI、姿态/翻转规范和静态/动态时点严格不变。若目标图与EAB相机不一致，先登记不可同构比较；不得以改相机让占比接近。

本任务不选择最终调参方向，不下发数值，不修改 E3 冻结窗或 EAB `VALIDATED` 状态。

## 6. 与 E1/E2/E3/S4/P-011 的依赖及推荐时序

- **先完成口径和当前版本基线**：用现有 EAB 目标静态帧/同构图采一次 `A_geom/A_visible`及轮廓基线，标注不确定性；这只是诊断，不等于稳定目标基线。
- **E1/C 层理**：按 C 锚点使用同一 ROI 与高度映射，沙丘轮廓仍以 `sandTop` 定义；层理可辨性另报，不把深浅纹理像素计作新增沙面积。薄沙承载不足按 `INSUFFICIENT_LAYER_SUPPORT` 报告。
- **E2 顶光**：改变亮暗可能影响图像分割的 `A_visible`，不改变同快照 `A_geom`；E2 完成后重采可见面积/形态照片，主几何占比可用快照核验是否相同。
- **E3 雾带**：直接影响上方遮挡与图像分割边界；雾参数身份、`stdRatio`及 rows 窗必须按已冻结材料记录。E3 修复/配置revision后重采 `A_visible`；E3 的局部窗变化不自动改几何 `A_geom`。
- **S4 长时形变**：改变物理轮廓/沙面位置；在与目标时长匹配的静置与动态时间点重新测 `A_geom` 和形态，不能用早期快照替代长时状态。
- **P-011**：仅协调场景初态/沉积状态/时间点与已有标定链；E4 不改 P-011 protocol、字段、阈值、状态或裁决。若其场景配置不可交换或初态不可比，报告该依赖并请 manager 协调，不拼接不同 route/build 的数据。

推荐正式形态判定顺序：目标 ROI/边界先复核 → E1/E2/E3/S4 当前计划项完成并记录身份 → 选择与目标相同姿态/时点的 EAB 静态/动态快照 → 先做几何占比与轮廓，再看同帧可见占比/层理 → 独立开展初态与雾因素实验 → manager 冻结量化区间后才讨论通过。E3/E2等尚未完成时可以量测、不能把其观感混杂的单次结果宣称为最终达标。

## 7. 自检、风险与变更记录

候选方案取舍：选择可从物理轮廓直接计算的面积作为主指标，避免将云雾、亮度和颗粒风格误当沙量；选轮廓配准作形态备选；保留可见面积分路诊断薄沙厚雾；宽度仅为解释量。拒绝单独用整图 SSIM（背景/雾会稀释沙形差异）、单独用 width（丢失高度/轮廓）、单独用颜色阈值分割（E2/E3改变颜色会改变“面积”）。

| 风险 | 处理 |
|---|---|
| 目标帧边界模糊或容器内缘不确定 | 手工复核/不确定mask；不可唯一圈定时区间或 `REFERENCE_BOUNDARY_AMBIGUOUS`，不造百分点 |
| 当前EAB薄沙/厚雾导致轮廓难分 | 用模型 `A_geom`作几何主测；`A_visible`只作分层与可见度诊断 |
| 沙量变化触发不同物理演化/沉降时间 | 每档独立仿真，匹配时刻/序列，报告守恒和稳定性，禁止假称同快照 |
| E2/E3/S4版本或几何改变 | 新旧 build/配置分组，不混成重复样本；重采当前基线 |
| E3 冻结锚点受到雾候选影响 | 停止将候选用于产品，走 revision；保留原锚点 |
