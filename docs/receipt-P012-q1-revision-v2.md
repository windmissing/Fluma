### G5 诊断（匹配支撑自相关+频谱，单位=每容器内宽周期数）
- **lag-1 自相关**：参考 f0/f5 = 0.9955/0.9941（强平滑连续）；设备 OFF = **−0.102**（去均值后近似白噪声→高频网格）；设备 EAB = 0.1951（弱正，介于两者）。
- **频谱主周期**（每内宽 200px 周期数）：参考能量集中在低频（1–3 周期/内宽）；OFF 峰在 24–25 与 72 周期/内宽（对应 ~8.3px 与 ~2.8px 网格——与历史"网格感"一致）；EAB 峰在 10–11 与 32 周期/内宽（~18–20px 与 ~6px）——**EAB 空间频率分布与参考不同、与 OFF 也不同**：既非参考的低频起伏、也非 OFF 的规则网格。
- 归因规则（方案 §3.2）：EAB 与参考在 hfH（幅度）与频谱（空间频率分布）**均持续不同** → 按冻结规则记**"表观尺度+对比混合差异候选"**；不写真实粒径、不写 B 单独造成。诊断仅供 designer/manager 使用，无新增 MUST-PASS。
