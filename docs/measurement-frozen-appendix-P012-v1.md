## 1. 指标定义（全部冻结）

| 指标 | 定义 | 适用 ROI | 五维度归属 |
|---|---|---|---|
| `lumStd` | ROI 内逐像素亮度 Y=0.299R+0.587G+0.114B 的总体标准差 | 沙体内部 box | 颗粒感 |
| `hfH` | 水平相邻像素亮度差绝对值的均值 | 沙体内部 box | 颗粒感 |
| `hfV` | 垂直相邻像素亮度差绝对值的均值 | 沙体内部 box | 颗粒感（辅助） |
| `rowOscCount` | row-mean 序列经窗口=5 滑动平均后，局部极值计数；prominence≥2.0、相邻极值最小间隔 3 行 | 沙体内部 box | 层理 |
| `rowOscRange` | row-mean（未平滑）极差 | 沙体内部 box | 层理（辅助） |
| `maxGrad` | 界面法向带内垂直相邻行亮度差的最大值 | 界面 band | 云雾感 |
| `transitionWidthRows` | band 内 row-mean 剖面从首次达到 10% 幅值到首次达到 90% 幅值的行距（10-90% 过渡宽度） | 界面 band | 云雾感 |
| `flowSteps` | 行窗口内各行水平相邻亮度差 >6 的计数，取窗口最大值 | 流动前缘行窗 | 流痕 |
| `lumMean`/`rgbMean` | ROI 亮度均值 / RGB 均值 | 全部 | 光照（色调锚点） |

## 4. 口径备注（复现须知）

1. ws0 的 `interface` ROI 不适用：0° 时水/沙界面为水平薄带（黄条 1915–1945），10-90% 定义在 60px 带内会跨到边框；ws 档界面改在 ws15（有倾斜）测，ws0 只测 water/sand。
2. `flowSteps` 行窗取窗口最大值（流动纹理集中在前缘基底部，单行采样会漏）；hybrid-tilt3 得 4（前缘被贝塞尔平滑抹平），目标 9–23。
3. `hfH` 在 ws 档虚高（3.2–3.4）来自逐格纯色填充的网格周期噪声，不是颗粒质感——验收时须结合目视网格感排除，防"虚高达标"。
4. 截图分辨率：目标 260×330（视频压缩），OFF 档 1280×2832（真机截屏）。指标均为无量纲/相对量（std、hf、行数），跨分辨率可比性经 effector 主观核对成立；若 tester 复核要求归一化，另立 revision。
5. 每次新档测量输出 JSON 存 `test/artifacts/p012-measurements/<name>.json`，与本附表基线同目录管理。
