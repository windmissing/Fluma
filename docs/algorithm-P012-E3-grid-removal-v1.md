## 2. 与Q1协同的测量坐标及冻结顺序

### 2.1 共用尺度，不共用沙区mask或hfH阈值

Q1材料当前标 `READY_TO_ACTIVATE / PENDING_MANAGER_RULING`；本稿不自行使其生效。E3提议复用 [v2附表草案§2–3](measurement-frozen-appendix-P012-v2-draft.md) 的容器内宽200分析像素主档、100敏感性档、等比单次面积覆盖重采样、浮点亮度 `Y=0.299R+0.587G+0.114B`，无锐化/补噪/对比归一化。若manager另有已生效版本，执行前绑定该版本，不能悄悄混用。

- E3新增**雾带mask、清水斑驳mask、纯沙mask**，分别统计；前两者由effector在参考/基线看新指标前标注，tester复核。雾带包括真实过渡，不按颜色平滑程度筛选；排除容器壁、遮挡、字幕和确证的沙内层纹，边缘侵蚀1分析像素。Q1纯沙mask不能拿来量雾带。
- 主参考仍f0/f5静态、f2/f6动态，各自单列；补充参考须先修订manifest。当前构建的静态配对和同输入动态关键帧单列，旧s99w、s96分别单列，不混建构建平均数。
- 每mask至少有效面积400分析像素且有效横向跨度≥80，角点指标至少有效等值线弧长100分析像素，否则该指标 `SUPPORT_LIMITED/N_A`。不能复制行、放大薄区或合并不同状态凑支持量。
- 每张图登记sha、build、renderConfigId、seed、tier、尺寸/内宽、mask、methodId、状态/时刻。静态三对若逐位相同，只算重复性证据，不称三个独立视觉样本。
- 200宽下原生921px的10–30px块约2.17–6.51分析像素；128列的列距仅1.56分析像素。主档适合块形比较，**无法可靠分离所有列频**。原生列锁定指标作为伴随诊断，不能以100宽降采样把瑕疵滤没后宣称消失。

冻结流程：designer本候选 → tester/effector冻结算子、mask、支持量和参考名单 → **只用参考**生成每帧值与静/动态描述带 → designer评估敏感性和数值候选 → manager批准revision/正式门槛 → 才用于E3交付判定。主参考每状态仅2帧，min/max不是95%区间。EAB或E3输出不得参与参考带定界。

### 2.2 可执行的指标候选

全部标 `e3-grid-display-v1-proposed`；以下数字是方法/工程候选，非参考实测或已冻结MUST-PASS。最终合成图为主测量对象，纯alpha图仅用于developer定位，不替代参考图比较。

| 指标 | 提取定义 | 候选目标及依据 |
|---|---|---|
| `J95` 横向硬跳 | 雾mask内所有左右相邻有效像素的 `abs(Y[x+1,y]-Y[x,y])`，报P50/P95/max及有效对数，不先模糊 | 主档 `J95_new≤0.70 J95_base`（30%明确改善候选）；同时进入同状态参考描述带上界之内。小于参考下界不能自动称更好，须通过纹理/对比维持项 |
| `K90` 块状转折密度 | 固定Y等值线32/64/96/128/160/192/224；marching squares线性定位，鞍点用双线性中心判向；对每点沿弧长前后各2分析像素取切向，转角75°–105°，且两臂分别距水平/垂直≤15°；相邻4弧长内命中聚为一次（取最接近90°者，平手取较小坐标）；mask端点不足弧长者排除。`K90=100*事件数/有效弧长` | 相对基线减≥50%，且≤参考同状态上界。它针对直角连续结构，比色段数更直接；50%为“至少消掉一半”工程目标，不声称人眼阈值。无等值线支持报N/A，不报0达标 |
| `P64/P256` 重复纹样峰值 | 雾/清水用64、纯沙用256原生逻辑像素对应的归一化滞后，先登记截图px/Canvas单位比例。每mask拟合并减去一阶平面，横/纵方向分别对有效像素对算归一化相关系数，取中心滞后±10%窗口最大值；报两个方向、对数与残差std | 正峰下降≥30%且≤参考**相同归一化滞后**的描述上界。只在base峰>0.1时做比例判据，否则报无显著基线峰、改看参考上界；每滞后≥200像素对、可用跨度≥2个滞后，否则N/A。全滞后谱单列，防把重复峰搬到新周期 |
| `Lgrid` 原生列锁定（诊断） | 用真实boxX/colW映射128列边界；边界±0.1列距内的横向梯度均值除以列中央±0.1列距内的均值，取各行汇总；分母<0.5灰度/原生像素则N/A | 候选≤1.25，表示边界的额外梯度不超过中央25%；仅实现归因，不与无同一物理列网格的参考做假同源比较，也不替代J/K |
| `Nseg` 色段（诊断） | 固定mask高度25/50/75%三条扫描线，亮度量化到4灰度，连续同级且长≥2分析像素计段，报告每100有效横向像素段数、段宽分位数；敏感性量化2/8另列 | 暂无单向数值门槛；不可把旧138直接代入新尺子，不能靠减少纹理来减少段数 |

补充规则：分位数用排序后位置 `(n-1)*p` 的线性插值；等值线以0.5分析像素弧长重采样后计算K90，闭环从字典序最小坐标起算，开线从较小端点起算。参考描述区间定义为 `[min_ref,max_ref]`，不预填未知数值；候选上界为 `max_ref`，不额外从待验产品结果推导容差。主档因JPEG/透视参数敏感性导致通过与否翻转，记 `COMPARABILITY_PENDING`，交方法复议；不挑有利档位。J/K基线为0时不做比例除法，要求无新增且在参考界内。相关系数分母为0时N/A；自然层理的长波相关与tile周期峰分开归因。

**防“抹平求过”：** 原E/A/B/C/D已经冻结的颜色、云雾std、颗粒、层理/流痕和动态稳定门槛全部维持；Q1原生hfH≥0.8与其独立参考带轨道都保留。新候选另要求同输入配对的雾区亮度std比例在 `[0.90,1.10]`，超出即回designer解释/复议，不靠全面降对比降低J/K；该±10%也是待批准的保护候选，不替代原std>15等冻结口径。历史逐像素maxGrad≤30量级与实现侧<8不同，E3不将<8追认成旧验收线。

## 3. 三来源实现候选与选型

### 3.1 列/段阶梯：连续采样必须与连续合成配套

| 候选 | 具体算法 | 代价/局限与建议 |
|---|---|---|
| I1：共享sampler＋连续轮廓Path | 用同一sampler取上下边界，把相邻矩形边界改为连接折线/梯形；仅曲率或屏幕误差>0.5显示px处分裂，新增节点最多256。保持已有12档alpha | O(128+节点+既有光学样本)，draw不必随节点翻倍；可消除轮廓直角，但内部12档/竖段块仍在。适合作为低成本消融，不保证J/K全达标，禁止将“Path”本身作为修复完成证明 |
| **I2：连续光学alpha缓冲＋平滑缩放（推荐完整路线）** | water/fog与interface分别按原绘制时序绘制；显示缓冲主档宽256、备选384，纵向等比，不增物理列。按显示坐标采样层高和q，逐样本计算现有tau/alpha，移除12档alpha量化，输出预乘alpha雾色RGBA；双线性缩放到Canvas，连续clip限制层域 | 每层O(Wr*Hr)，一层至多1次主体drawImage＋clip。256宽映射到200分析宽步长0.78125，384为0.52083；两档不得按帧自适应切换。动态上传和putImageData可能比当前Path贵，须单独测CPU/上传/RS；无收益则回架构而非提高物理分辨率 |
| I3：256/512显示列＋原矩形段 | 插值生成更多显示列，保持原绘制 | 倍增样本/路径段，仍有alpha量化且更易加重F1。只做对照候选，不作为首选；C分段数不应因E3密度自动倍增 |

I2保持既有光学函数、雾上限0.78/界面上限0.55、先水雾后沙/颗粒再界面带的绘制顺序；若要改颜色/幅值须另行登记定标，不借E3改锚点。输出像素变连续不保证std原样，因此保护项必须复测。可预烘焙**静态噪声场**，不缓存为永远不变的全幅雾图：层高、q、平流相位、palette或scale变化均使对应光学缓冲失效。

预乘alpha是内部插值/合成约定，不表示可以把预乘RGB直接写给要求直通RGBA的ImageData接口。上传适配层须按实际API格式做转换（alpha=0时RGB置0），防止二次预乘产生暗边；由architect明确纹理格式和缩放平滑设置，离线检查透明/半透明边缘。API或设备无法提供所需连续采样时登记实现阻断，不退回最近邻矩形后仍声称连续。

### 3.2 64px噪声：连续非周期场优先，随机tile为备选

推荐N1：渲染专用种子与整数空间hash生成两尺度value noise，尺度沿现有细/粗团范围，在无限格点中取四角值，用 `w(t)=t*t*(3-2*t)` 双线性权重混合。`n(x,y)=Σ wi(x)wj(y) H(seed,i,j)`，权重非负且和为1；不再对64取模。两尺度叠加进入原mottle/tau链，采样坐标减现有材质运动相位。随机源不读/消耗物理RNG，不使用帧号或墙钟。

可按视口及运动余量预烘焙噪声，缓存移位时沿相同世界格点补边，不能重新播种整张图。数学上移除强制64周期，不证明任意有限图无偶然周期；由P64和全滞后谱验证。新噪声分布/方差不会自动等于旧mottle实测0.5494，必须在原种子+多种子离线报告实测均值/std、clamp占比，定标保持现有亮度锚点；不能再把旧估算0.35当测量值。

N2备选：4张64²独立tile按材质块坐标hash选取并拼缝混合。仅随机切换或镜像会留下接缝，且周期变大不等于消失；因此必须与N1同测P64和全谱。亮粒也用稳定空间hash决定位置/变体，保持既有稀疏密度/亮度分布，不能把亮粒关掉来消除周期。

### 3.3 256px颗粒：有限atlas＋材质锁定拼接

G1候选：每种H/L/M各4张确定性256²噪声变体，保留现有sigma/色板和三套材料位移；tile索引由**材质坐标**块号hash确定，静态不轮换、移动不按屏幕格跳变。先在epoch烘焙为≥2视口宽的稳定组合atlas，绘制时沿既有位移取样/平铺裁片；有界atlas仍会重复，周期必须列入全滞后诊断，不能声称无限非周期。

接缝候选：16px重叠，余弦互补权重 `w,1-w`，二维取乘积使总权重为1。凸混合保证值域有界，但独立同方差纹理的方差变成 `sigma²*(w²+(1-w)²)`，接缝中心方差减半，可能出现柔带。**不可忽略此风险或每帧局部放大补偿。** 烘焙阶段评估方差与接缝，必要时采用共享边界条件的tile族再交review；若P256不显著且主观未感知，先保留现行颗粒，将G1列第二批，不为轻微来源一次加入全部成本。

不推荐每帧随机tile、简单棋盘镜像或关闭grain；前两者分别闪烁/引入新周期，后者回退已闭环B。

## 4. MaterialColumnSampler复用边界与伪代码

现有 [P012MaterialSampler.ets](../entry/src/main/ets/render/P012MaterialSampler.ets) 接口可直接用于 `bhAtPx/mixStartAtPx/sandTopAtPx`；传入的是**相对boxX的局部x**，不是画布绝对x。现实现采样结点为 `x=c*colW`，末列区间退化到最后样本；本轮不改成列中心结点，避免C半列错位。实例持有renderer的smooth数组引用及boxW；cols/boxW或数组身份变化时重建，其余帧更新原数组，禁止逐像素new对象。

代码事实：`smoothMixStart=bh+bl`，因此实际层序是 **0≤bh≤mixStart≤sandTop**。sampler注释/架构§11.2写成 `mixStart≤bh` 的顺序与赋值不符；本设计采用上述实际顺序，交architect纠正文档注释，不据笔误重新排列物理层。相同非负插值权重对所有层边界作用，保持真实顺序和非负厚度；禁止无约束高阶样条造成过冲。

现接口没有q、水顶、材质配比。E3扩展应由architect安排**同一定位/权重实现**的只读通用标量采样，不能复制第二套坐标算法。先逐列按既有 `suspQ` 算有界q，再以同权重插值（与“先插库存后除深度”不是同一算法，不能悄悄互换）。waterTop连续采样沿同一实现。C维持自己的分段/缓存策略，D维持已有方向/运动数据；共享取值接口不等于共享一张所有用途的纹理。

```text
beginFrame(readOnlyView, displayEpoch):
  update existing smooth profiles once
  reuse/rebind sampler; precompute column qH/qL with existing formula
  assert physical inventories before == after appearance rendering
  if fog inputs or material phase changed:
    for each water/interface buffer sample (u,v):
      x = local display coordinate of u
      S = sampler.sandTopAtPx(x); q = sharedScalarSampler(qColumns,x)
      noise = stableMaterialNoise(x-phaseX,y-phaseY,renderSeed)
      alpha = existingOpticalLaw(S,q,noise,y) with existing bounds
      store premultiplied fogColor*alpha, alpha  // no 12-tier quantizer
    upload bounded buffers
  draw water fog; draw existing E/C/B/D at their established positions
  draw interface fog at its established position; preserve route isolation
  reuse buffers; dispose/rebuild only on epoch/size/palette/route lifecycle
```

伪代码的库存校验沿adapter既有只读断言，不把E3视觉指标写入物理checker/遥测。sampler只服务显示场，不能将采样后的高度/q回写模拟。bitmap/typedarray归renderer，reset/invert/route切换复用既有epoch和运动缓存清理，禁止旧场景纹理相位泄漏；具体释放API由architect按现SDK与既有bitmap生命周期落实。

## 5. 成本账本：与F1联评，不预支帧率

下表均为**静态容量估算/工程预算提案**，不是端侧计时。34–60fps是旧EAB窗口证据，不能视为当前CD所有动态帧均有空余。F1报告记录不同负载有明显物理耗时；`frameTime-physicsTime`还含vsync/其它，不能当纯GPU成本，两个P95也不能直接相减。本稿不承诺100fps/90fps，也不以F1未冻结的新统计定义替换原验收。

| 增量 | 内存/运算估算 | 建议预算与风险 |
|---|---|---|
| I1几何 | 每轮O(128+≤256新增节点)，可复用坐标数组；不增加屏幕覆盖面积 | 热帧增量CPU P95≤0.15ms候选；它可能仅部分解决E3 |
| I2光学缓冲 | 以box约921×1088为容量例，256×303=77568样本/层，2层155136；每层RGBA前后双缓冲总约1.18MiB，bitmap副本另约0.59MiB；384档约×2.25。**这不是按128列×少量竖段的旧成本** | 热帧增量CPU P95≤0.5ms、端到端P95增量≤1.0ms为设计分配候选，不保证可达；上传、透明fill-rate、重建峰值必须实测。ROI裁剪可降成本但须保持光学支撑完整 |
| N1噪声 | 两尺度每样本8格点值/插值；烘焙标量Float32每层256×303约0.30MiB，可在epoch复用 | 叠入I2的0.5ms预算，不能另算免费；移动补边峰值另报，不静置缓存后冒充动态成本 |
| G1四变体 | 原3张变12张256²：额外9张RGBA约2.25MiB；若保留Float32噪声再加2.25MiB，若沿用Float64则4.50MiB；组合atlas另外按实际尺寸计 | 单批建议新增常驻总额≤8MiB，热帧CPU增量≤0.15ms、draw增量≤6候选；atlas尺寸/双份纹理须纳入，不满足则缩路线回architect，不隐藏内存 |

推荐分两批：**I2＋N1优先（I1作机制消融），G1待P256及主观定位后选择**。I2若经原型证实上传超预算，回architect比较I1＋连续梯度条带或更窄ROI缓存；不要把384/512加密当自动补救，也不要用降低物理步频/关闭C/D/每隔几帧更新雾来省成本。仅当所有外观输入确实未变时复用缓存。

后续性能配对需同当前CD构建/seed/输入，交替基线与E3次序，分别统计静置、普通倾斜、重载动态，报告逐配对块CPU/上传、端到端帧时P50/P95、draw、实际呈现帧率、内存和epoch峰值；不能用总均值抵消重载退化。配对矩阵：当前CD→＋I1；当前CD→＋I2；＋I2→＋N1；＋I2N1→＋G1，最终整体还须与当前CD直配。

原已经生效的30fps/33ms对应场景维持；新增候选为同场景帧时P95≤基线×1.05且增量≤1.0ms，二者都满足。不把“+5%容许值”宣称为已批准帧率下降；若用户/manager沿用严格不降，则执行严格不降标准，此处需冻结时裁定。超预算登记 `PERF_BLOCKED` → architect给缓存/提交修订 → manager重排，不改F1目标求绿。
