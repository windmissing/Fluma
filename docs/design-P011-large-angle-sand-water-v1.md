# P-011 大角度沙水联动：约束裁决与候选解法 v1

日期：2026-10-23。责任：designer。状态：**DESIGN_PROPOSAL / CONSTRAINT_DECISION_REQUIRED / NOT_IMPLEMENTED / NOT_VALIDATED**。本稿回应“水是否也被大角度卡住、怎样解决”；不改现行 `tan30`、300/s、SLIP-02、跟手性或 checker，不授权实现/采集。

## 1. 当前问题不是单独的水面速率参数

`WaterSandField.planAndCommitTilt` 先决定共同的 `effectiveTilt`；`waterLevel` 再用 `tan(effectiveTilt)` 构造目标平面，按 `waterLevelRate` 从高于目标的列分配到低于目标的列。水有独立于沙的水量更新，但**重力参考与沙共用同一个被 planner 钳住的角度**。当前水状态无列间速度/动量，所以这个更新是趋向目标水面的松弛，不是带惯性、回摆、撞壁和飞溅的水流解算。[代码入口](../entry/src/main/ets/physics/WaterSandField.ets) 的 `planAndCommitTilt`、`waterLevel` 与 `substep` 为本结论的实现依据。

设 `g_e=S[e+1]−S[e]`、`H=tan30°≈0.57735`，现行逐边硬谓词为 `|g_e−tanθ|≤H`。平沙 `g_e=0` 时，真实 `θ=45°` 给残差 `1>H`；在现行“每个已提交子步都满足谓词”的定义下，系统不能一边保持平沙、一边立即把共同物理角提交到 45°。把水单独改读命令角、沙仍读 accepted 角，会让同一容器出现两套重力，不能作为联动解法。

在 `N=128、dx=1、初始平沙、最终沙全部沉积、目标全宽线性 28°` 的条件下，所需沉积一阶矩变化至少 `tan28°·N(N²−1)/12≈92,917`；原 `300/s×5.1s=1,530`。若**每跨一个列边的沙量 q 都从 total 扣 q**，则 `|ΔM|≤1,530`，仅此类输运的必要额度缺口约 `60.7×`。这是[阶段边界复议 §2–3](review-basis-P011-stage-boundary-v1.md)的条件性矩上界；不能外推成所有允许竖向交换、孔隙体变或非相邻转移策略的全局无解证明。任何新悬浮/颗粒路线必须声明跨列计费，不得借“粒子飞过”或“水带走”免费绕过预算。已有[阶段二审计](phase2-reachability-audit-P011-v1.md)和[方案 3 设计](algorithm-P011-phase2-suspension-advection-v1.md)均未证明 128 列 ±45° / 5.1s / 30°±2° 可达。

## 2. 先裁决两条互斥产品路线

| 路线 | 共同重力角与 `tan30` 语义 | 能给用户什么 | 当前结论 |
|---|---|---|---|
| **A：现有硬谓词原样保留** | 水与沙都只读 planner 接受角；每已提交子步零越界 | 安全、稳定；命令 45° 时可被长期钳在较小角 | 可继续作为已批准安全路线，但不能把“水/沙真的按45°响应”标为完成。只调 `waterLevelRate` 无法解除上游钳位；同预算下全宽时限尚无可达证书。 |
| **B：真实外部倾角 + 瞬态超临界沙床**（推荐作为目标路线，须正式修改约束定义） | 唯一 `θgravity` 从同一传感器/TEST 命令经过可测滤波得到，水沙均读它；`tan30` 数值仍是沙面相对重力的安息角上限，双角起停仍由单独的用户 pair（出厂推荐 26°/20°）决定；外部突然转动造成的超临界状态可暂存，材料 writer 逐笔不得恶化该状态，并须产生受守恒/预算限制的修正 | 水先按真实角晃动，沙随后流动/扬起/沉降；能讨论真实45°体验 | **需要 manager/用户批准改变现行“所有提交子步零超界”的 MUST-PASS 语义**。这不是偷偷放宽阈值：须新增超临界持续时间、恢复进度和 writer 零恶化闸门。若当前硬谓词绝不可修订，B 不可实施。 |

路线 B 的候选事务：外部姿态输入先更新 `θgravity` 并记录 `externalTiltInducedResidual`；planner 对材料请求做完整 preview，材料逐笔按 §19.5 两分支 guard（原来合法则提交后仍合法；因外部姿态已超临界则 `|r_after|≤|r_before|` 且不得制造新的超临界边）；只提交实际可用额度。超临界不是自动 PASS：若无起流/合法搬运，报告 `SUPERCRITICAL_STALLED`，由已批准的新恢复时限和最小进度判定失败。真实姿态更新、材料应力与水流使用**同一时钟、同一角度**；TEST 和 EXPERIENCE 仅输入来源不同。原硬约束下不得提前把这一事务写进生产路线。

## 3. 获批路线 B 后的最小工程次序

1. **先做水独立基线，仍保持沙现状隔离。** 每列把自由水体积 `h_w=max(0,waterTop−S−suspH−suspL)` 与水平动量 `m_w=h_w u_w` 分开存；相邻面以等量反向通量更新水量，倾角提供切向重力，沙床高度提供底形，墙为零穿透。选择可处理干湿交界、非负水深的有限体积通量，`dt` 受 `|u|+√(g_n h)` 的 CFL 候选约束；溢出容量前拒绝/回退整笔事务。先在只有水或静止固床的隔离 route 测 0→±45→0 的波前、撞壁、回摆、体积误差和真机帧时，再与沙耦合。现有 `waterLevel` 可留作 OFF 对照，不与动量解叠加重复搬水。
2. **加入可动沙表层与静止底床交换。** 床层仍用 `bh/bl/mh/ml`；另给有限厚度表层流动库存及水平动量（H/L 分相）、起流/停止和侵蚀/沉积同笔守恒。水下细沙可进入悬浮列库存，需见独立轨迹的沙进入有界颗粒层（[S3 §9.4](algorithm-P011-S3-moisture-grading-v1.md)）；摇晃、潮湿黏聚和水下拖曳分别决定请求率，不把 26/20 当摇晃阈值。水给沙的拖曳与沙给水的反作用须在同一耦合事务中登记；从床层取出的质量只归一个流动身份。S4 深层 `bh` 慢形变另计，不替代秒级表层流动。
3. **最后做全通道可达性审计。** 对同一 128 列初态、±45° 输入、真实物理 5.1s，逐子步导出水量/动量、沉积/悬浮/颗粒 H/L、每边沙通量、一阶矩、四层预算、writer guard、局部/全宽 raster 和终点。分别判断：姿态 P95≤100ms；水在真实角下有可见波前及守恒；沙的 `30°±2°`、target-based `t90≤5.1s`、`R²≥0.90`、末1s 稳定与悬沙≤5%。若沙所需额度仍大于冻结 300/s，则提交**预算/时限/目标三者的量化冲突**请 manager 裁决；水求解器与颗粒层不能替沙创造额度。

这套顺序的性能评审是分开的：水 `O(N)` 状态和面通量，沙表层 `O(N)`，活动颗粒 `O(N_active)`；真机 ArkTS 与 renderer 帧时必须配对测，不能把论文桌面 GPU 实时结果移植成手机性能承诺。若水出现翻卷、飞溅或同一列多个自由表面，再按证据加局部粒子/局部 3D；常规全域水面继续高度场，不预先体素化整个容器。

**设计结论：** 当前硬谓词若继续绝对禁止任何外部姿态导致的瞬态超临界，真实45°沙水同角响应不能作为已解决问题；先保留安全路线 A。若产品目标是“手机转到45°，水立即晃、沙逐渐塌”，推荐将路线 B 的**约束语义变更**提交 manager/用户审议，再按水动量→可动表层→全通道证书的顺序实施和验收。研究论文支持模型结构，不证明现有预算和5.1秒目标可达。
