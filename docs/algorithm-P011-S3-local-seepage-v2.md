# P-011 S3 局部渗透 v2：守恒孔隙水与湿沙响应设计草案

日期：2026-10-23。责任：designer。技术路线：`s3-local-seepage-v2`。状态：**DESIGN_PROPOSAL / SOURCE_CROSSCHECK_PENDING / NOT_IMPLEMENTED / NOT_VALIDATED**。本稿由 designer 负责模型、公式和取舍；外部智能体只核对原论文的公式、实验条件及参数来源。依据：[S3 首版 §2/§4/§6–9](algorithm-P011-S3-moisture-grading-v1.md)、[S3 架构](architecture-P011-S3-moisture-v1.md)、现行 `WaterSandField.ets` 的 `getWaterVolume`/`waterLevel`/`audit`。首版 `s[c,k]` 是代数代理；本文定义升级后**真正有水量身份**的 `s=W/P`，不追认首版代理为已测饱和度。

## 1. 要先解决的风险与版本边界

最危险的错误是把首版 `s` 当成一份新增水量，却不从现有自由水账扣除；次危险是水有了局部状态，但让湿沙的 `θstart/θstop` 或颗粒效果直接拿论文参数运行。先验证**可移动局部湿润前沿 + 逐相水量闭合 + 局部阈值响应**；真正的潮湿团簇、孔压液化和水中颗粒轨迹各属独立模型，不能借本稿自动签收。

建议两门：`v2a` 在冻结/弱移动沙床上验证渗透与局部起停响应；`v2b` 再把材料 writer 的携水、挤水及起沙接上。二门共享相同 `W/P` 状态和水账，不以 `v2a` 的成功代 `v2b` 验收。保留 `moistureRoute=OFF` 的位精确旧路线；用户实际双角 pair 仍是基准，26°/20° 只是出厂推荐且未标定。当前 300/s、各级预算、守恒、§19.5 writer guard、`tan30` 硬值和 128 列不变；大角度外部姿态新路线单独研究，不随 S3 偷渡。

## 2. 空间与体积身份

沿首版**绝对高度格**，`c∈[0,127]`、`k∈[0,K-1]`、`Δz=capacity/K`，`K=8` 主候选、`16` 分辨率臂。`B[c,k]=Δz·clip((S[c]−kΔz)/Δz,0,1)` 是该格被现有沙床包络占据的高度；`S=bh+bl+mh+ml`。首批固定孔隙率代理 `φ_p∈(0,1)`，`P[c,k]=φ_p B[c,k]` 是**包络内部**孔隙容积，`0≤W[c,k]≤P[c,k]` 是实际孔隙水，`s=W/P`，空格定义 `P=W=0、s=invalid`。`φ_p` 不是论文测量值，必须在真实材料/容器上定标；先固定它可隔离“渗透是否有用”的检验，变孔隙率/压实留独立版本。

**建模约定 ASSUMPTION-POROSITY：** 现行 `S` 作为沙床**包络高度**继续决定沙面与 tan30 几何；`P` 位于包络内部，不额外抬高 `S`，H/L 账仍按现行量纲。这个约定不是把 `bh` 等变量改称真正的颗粒固体体积；若将来要求密度/孔隙率/压实的绝对物理体积一致性，需版本化转换沙库存与 `S`，不可直接用本稿 `P` 反推真实 grain volume。

```text
F[c] = getWaterVolume(c)                         // 现有床外自由水
Vw_actual = Σc F[c] + Σc,k W[c,k]
Vw_expected = initialWater + waterTransactionNet // 旧 run 的起点；迁移时不增加它
VH/VL_actual = 旧沉积+悬浮等真实库存              // 湿度格不产生沙
```

现有 `waterTop` 仍为**床外自由水的几何水面**，不把 `W` 再加到 `waterTop−S−susp` 里。孔隙水吸入时自由水下降，排出时自由水上升；`waterLevel` 只搬自由水，孔隙水由本路线单独搬。仅有孔隙水而无床外自由水的列允许“湿沙、无自由水面”；`waterTop` 的 dry sentinel 与 `susp` 有水可用性需 architect 按现有代码逐态核对，不准用湿度渲染白雾替代物理自由水。

### 2.1 首版状态迁移

从旧 `moistureRoute=ON` 代理场进入 `v2` 时，先构造期望 `W* = P·s_proxy`，令当前自由水总量 `Ftot=ΣF`。若 `ΣW*>Ftot`，要么**拒绝迁移**，要么以统一 `λ=min(1,Ftot/ΣW*)` 缩放每格 `W=λW*` 并报告 `MIGRATION_WATER_SCALED`；不静默创造水。再从**明定的真实自由水供体列**转账给孔隙格，逐列执行供体/水面/容量准入；若无法构造该分布，整体拒绝、原状态不变。迁移后 `Vw_actual` 与旧 `ΣF` 相等。旧无湿度 run 不自动产生初始孔隙水；reset/route 切换不得把代理 `s` 重新当新增水源。

### 2.2 生命周期与自由水边界

运行中的 `addWater` 先加**自由水**，随后由 §3 的可提交面通量慢慢入孔；普通 `drainWater` 首版只排自由水，不能直接清零 `W` 来瞬时烘干。run/reset 将 `W`、水头缓存、通量请求及路线计时归零或由有账初态事务重建；TEST↔EXPERIENCE 切换保留 `F/W/S` 和总水基准，仅重置输入 epoch。旧 route↔v2 的中途切换只允许完成上述显式迁移和快照验证，不能静默把 `W` 丢掉。`invert180` 若现行算法会把沉积床转成悬浮库存，所占孔隙水必须在同一事务转入有容量的自由水或将来有正式携水身份的悬浮/粒子库存；若容量不够则整次变换拒绝或缩量，禁止独立清空 `W`。这些生命周期路径未有可提交证明前，v2 仅能处于隔离试验状态。

`v2a` 的初始证书固定 `suspH=suspL=0`；`v2b` 中若某列已有悬沙且继续入孔会使床外自由水耗尽，先拒绝该笔入孔，直到“悬沙需要多少载体水”有明确的体积契约。现行悬沙列总量没有这份载体水身份，不能靠 `waterTop=S+susp` 的几何等式推断水还够用。

## 3. 低阶水力闭合：候选，不从论文复制数值

选有限体积**水量通量**，以 `z_k=(k+1/2)Δz` 为上升高度。为得到“重力向下 + 湿格向干格毛细回润”的最小可证伪候选，定义水头 `H_i=z_i+ψ(s_i)`，其中 `ψ(s)=-h_cap(1-s)^m`、`h_cap≥0、m≥1`。它只是项目的**有界单调毛细势代理**，并非论文给出的通用保水曲线；需与真实湿润前沿测量比较后保留/替换。面 `i→j` 的候选量：

```text
q_req(i→j) = dt · K_face(s_i,s_j) · max(0,H_i−H_j)/ℓ_ij
K_face = Ksat · max(s_donor,s_floor)^n       // 湿端供体迁移率候选
```

`Ksat` 量纲为高度/时间，`ℓ_ij` 是格心距；竖向格先启用，左右相邻列同高度格为第二验证臂。上下、左右和自由水↔顶端可接触格共用一张**有向流量请求表**；反向请求互斥，壁/底无外漏。自由水面到孔隙格的边只在供体有**真实自由水**时开放，以水头差生成请求；上方干空气不等于可无限供水的外部水库。外部加水事务仍通过 `addWater` 等真实源，之后才允许流入孔隙。若接触面几何不连通，请求为零，不通过任意远程列直灌。`h_cap/Ksat/n/s_floor/φ_p` 都待定标；`s_floor>0` 只能用于数值正则，不得在 `W=0` 格凭空启动流出。

所有请求从同一子步快照生成，按固定面序和同相水身份准入。为避免一个供体/受体同时参加多个面而超卖/超容，先算 `Qout_i=Σj q_req(i→j)`，令 `α_i=min(1, available_i/Qout_i)`；再算 `Qin_j=Σi α_i q_req(i→j)`，令 `β_j=min(1, capacity_j/Qin_j)`；最终 `q_ij=α_i β_j q_req(i→j)`。孔隙供体 `available=W`，孔隙受体 `capacity=P−W`，自由水供体是实际 `F`，自由水受体要经 `waterTop≤capacity` 及已有水面事务核对。以**同一 q**写供体 `−q` 与受体 `+q`，因而对内部面：

```text
ΔVw = Σfaces(−q_ij+q_ij)=0,
0≤W'≤P,  F'≥0;
```

边界外源只通过有回执的 `waterTransactionNet` 改 `Vw_expected`。两轮比例缩减不保证通量最大，但保证非负、容量和守恒；若浮点审计失败，回滚整个水力子步。为避免显式水头计算跨大 Δt 振荡，`dt` 由最大面迁移率/最小 `P` 给稳定上限或做整数子循环；边界水头不稳定时降子步/报 `SEEPAGE_TIME_STEP_BLOCKED`，不能直接 clamp `W` 而丢水。复杂度 `O(NK)` 状态/面/账，快照与请求数组同阶；真机帧时后验，不拿复杂度当性能证明。

**一笔方向验算**：同列上格湿、下格干时，`z_top>z_bottom` 且 `ψ(s_top)>ψ(s_bottom)`，故 `H_top>H_bottom`、请求向下；同高度左湿右干时 `ψ(s_left)>ψ(s_right)`，请求横向入干格。若实测出现更快的毛细上升或湿润指进，当前 `ψ/K` 闭合可能失配，必须改模型/分辨率，不能只调渲染遮掩。

## 4. 与沙材 writer 的水账耦合

`v2a` 的首个隔离证书在固定沙床上验证 §3；用于产品主链的 `v2b` 必须继续过本节。每个使 `S`/占据格变化的材料事务，先从当前 `B,P,W,F` 快照预演**沙与随沙携带的孔隙水**。沉积沙跨列搬运 `q_sand` 时，候选携水量 `u=min(W_donor_bin, φ_p·q_sand·s_donor_bin)`，与该笔沙同方向、同事务扣增；`u` 是随行水，**不再额外算成 300/s 沙位移额度**，但沙 `q_sand` 本身照旧计真实跨边成本/一阶矩，水仍守恒。接收格若容量不足，先按几何溢水出口把超量转给本列自由水且检查水面容量；无合法出口则缩小整笔沙 grant，不允许材料先写后丢水。

同列 `settle` 增 `S` 所建新孔隙默认空水，不从自由水自动填满；`lift` 减 `S` 使孔隙消失，所占 `W` 必须同笔转入有容量的自由水，或在将来有正式“湿悬沙/湿粒子携水”库存时转入该身份。当前 `suspH/L` 不含水量身份，所以不能假定它免费携孔隙水。分选/S4 的 H/L 逆向重排若 `S` 不变、`P` 不变，水格不因材质名称改变而重建；若以后 `φ_p` 依材质/压实变化，另需局部挤水与体积审计。所有路径必须与现有材料 `preview/apply`、§19.5 guard 和四层预算**同一原子事务**预演；任一 water capacity/guard/预算失败整体拒绝或整体缩量。以“忽略这笔水”保持沙 writer 成功是禁止路径。

本节把**材料移动下的自由水出口、水面重建与跨格 bin 映射**列为 architect 必须验证的实现契约；若现有单 `waterTop` 几何无法同时表示局部湿床与无自由水的悬沙，先退回 designer 调整表示，不通过测试豁免。v2a 不能据此宣称 v2b 已可实施。

## 5. 湿度如何传入力学；可表达边界

直接消费者仍是 S3 首版已建的 `s_e→C(s),B(s)→θstart,e/θstop,e→relax` 链，只把 `s_e` 的来源由代数代理换成 `W/P`。**整个映射需重新定标**，首版 26/20 的默认等价只适用于 `moistureRoute=OFF` 或明确登记的 `v2` 参考饱和态；不能拿旧代理 `s_ref` 数值直接当真实孔隙饱和度。`C(s)` 对应水桥内聚，`B(s)` 代表高湿浮力/润滑的项目代理；现有 `tan30` guard 不随它改变。若湿沙真实稳定坡需要超过 30°，当前模型**结构性表达不了该效果**，应如实登记与现有安全目标的冲突，交 manager/用户决策；不在本路线私自放宽。

`θstart/stop` 移动只改变**流动何时开始/停止**，不产生真实拉伸应力、湿沙团簇或孔压液化。若目标是“湿沙结块被摇起”或“过饱和后快速液化”，还需要独立的内聚/粒子团簇与有效应力状态。把 [Su 等 §3.3.3](https://kuiwuchn.github.io/RTWaterAndSand.pdf) 的分段 `c_c(φ)` 误作本项目 `s=W/P` 的现成函数是错误：其 `φ` 是模型混合体积分数代理，且论文没有给 P-011 材质的角度映射。Richefeu 等的低水量剪切实验支持水桥效应，但不提供本机沙种/容器的阈值。[Garres-Díaz 等](https://arxiv.org/abs/2001.04672)的膨胀→孔压→有效摩擦涉及强耦合和非平衡瞬态；它是需要单独立项的升级证据，不属于这份低阶水头算子的已实现功能。

## 6. 可辨识验证与是否升 2D/局部体素

从四类**独立观察**分辨水力与力学：①固定沙床局部加已知水量，逐格 `W/P` 与可见湿润前沿随时间/高度/相邻列迁移；②同场总水 `Vfree+ΣW` 守恒、拒绝水事务零变化；③固定局部饱和度但改变角/摇晃，逐边读取 `thresholdUsed`、实际 start/stop 与 `grant`；④相同材料/倾角下对照干/中湿/饱和的床面与粒子效果。不能仅用一条角度轨迹同时反推 `Ksat、h_cap、φ_p、C(s)`：这些参数可相互补偿；先用湿润前沿定水力，再用独立坡面/剪切试验定本构。采前冻结参考水量、空间/时间测量误差与参数扫描域，当前不填假实验值。

首轮 `Ny=1` 的 128×K 模型如果已能复现目标截面前沿和局部响应，继续用它；只有明确出现前后方向水流/绕障碍，而 `Ny=1` 不可表达时，才设计 `S[x,y]+W[x,y,k]`。若二维高度场仍不能表示同一竖列不连通几何或观测到的局部湿前沿，即使 K/水力参数校正仍系统性失配，才讨论局部 3D 体素；不得把显示镜头有深度等同于必须全物理体素。[S3 §7–8](algorithm-P011-S3-moisture-grading-v1.md)的粗细水量唯一所有权继续有效。

**验收状态分三层**：`WATER_LEDGER_PASS`（水量/容量/快照/事务）、`WETTING_FRONT_VALIDATED`（独立水力观测）、`WET_SAND_EFFECT_VALIDATED`（局部阈值与主观效果）；前者不能替代后者。OFF 旧场景逐步回归，ON/default 首版与 v2 不承诺跨版本位精确，必须版本化独立报告。`v2a` 只可判前两层，`v2b` 和本构定标后才能判第三层。
