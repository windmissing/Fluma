## 可见现象

| 文件时间 | 直接观察 | 对效果目标的含义 |
|---|---|---|
| 约0–0.5秒 | 容器呈斜置状态并开始回转，绿色区域上界较平滑，内部细碎纹理广泛分布 | 关注连续物质区域的轮廓与纹理运动，单颗活动粒子的可见性不是唯一观测量 |
| 约0.5–1.1秒 | 容器逐渐接近画面正置，绿色区域相对容器的界面形状随之变化 | 比较运动须使用容器坐标；不能把相机/容器刚体转动当成物质流动 |
| 约1.1–2.125秒 | 容器姿态变化减小后，绿色区域上界和内部纹理仍继续变化，界面逐渐变得更平缓，保留局部起伏 | 目标应覆盖姿态之后的滞后、持续重排与逐步减速；末帧不构成完全静止证据 |

这是视觉观察。浅色上层的真实组成、绿色区域的固相比例、颗粒大小、密度、黏度与是否沉积，均不能从本片确认；不据此命名成干沙、湿沙、自由水或不互溶液体。文件为带界面的短视频录屏，含压缩、透视、遮挡和未知拍摄处理。

## 对下一轮设计的建议

以用户确认的**流动观感**为目标，倾角由用户调节，沙面安息角单独定义。效果参考不绑定固定角度；具体可调范围仍需算法证明和实现覆盖。继续GPU驻留及XComponent+shader完整帧路径。

1. 在明确支持的角度范围内，冻结可重复的“0→用户设定角→保持→0”和左右镜像输入；缓转与快转分别比较。各测试记录实际角度和时间，不从本片反推，不把45°强加为本片的效果门槛。
2. 同一重力驱动沙与水；轮廓应连续变化，并在固定姿态后持续重排、逐步停止。需要同时观察床面、活动沙和水的实际库存，不能只移动材质纹理表示物质搬运。
3. 将外部姿态引入的短暂超临界与材料写入安全分账。已有`design-P011-large-angle-external-tilt-v2.md`可作为语义基础，仍需结合现有GPU整数核、复合通量、容量与预算另版定稿。
4. 先验证现有床面与粒子表示在拟支持角度范围内的可达性、流动速率和稳定终点；本片不足以决定必须更换求解器，也不足以证明当前框架已经能够复现。
5. 内部纹理的连贯流动是效果项。若需材质随物质输运，应以实际输运量驱动、单独设计接口；不能用屏幕动画替代守恒或运动证据。

## 尚不能从本片制定的指标

- 视频真实倾角、姿态响应延迟和左右对称性；精确复现片中角度不属于用户要求。
- 从旋转停止至完全静止的时长、恢复终点与安息角。
- 内部颗粒速度场、各相质量或水体动量；压缩纹理变化不等于已测量速度。
- 明水自由面、飞溅、摇晃再悬浮、180°翻转等扩展效果。

本片已足够作为第一轮观感参考，无须等待用户补材料才启动设计。速度与恢复时限先标待定标；后续若需要实物定量对标，可补固定机位和完整静止等待段的原速视频，当前不要求用户提供角度标尺。现有300/s等冻结预算与历史5.1秒目标的冲突须量化交manager裁决；本片效果参考不自动继承该历史时限，也不构成修改预算的授权。
