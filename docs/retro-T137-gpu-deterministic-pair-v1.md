T130把GPU限制在整数索引建议而非权威物理，这是保留现行F64与事务顺序的关键。本轮将它落实为CPU原谓词边界、全局Y秩分段表、每元素唯一rank的并行merge、每a严格大ID查询及字典序min归约，避免“GPU选到合法pair”冒充“选到原最小pair”。

考虑并拒绝了atomic先到赢家、F32高度桶、N²全pair与一批不冲突pair。这些分别改确定性、数值域、复杂度或串行质心依赖。选择分层稳定merge的代价很具体：192/512分别11/12 dispatch，每次CPU merge后重新准备／上传／完整链尾读回，主规模并不预设能赢CPU O(NlogN)。

范围证明发现rounded y±r不是原RN差谓词的等价变形；MAX_ID也不能作空哨兵。单独valid、原Yrank、无符号比较和重复ID拒绝把这些身份问题显式化。离散模型核对层内唯一写、标准段覆盖、全局最小性；它不是设备GL同步测试或产品收益证明。
