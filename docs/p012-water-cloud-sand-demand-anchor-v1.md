# P-012 水云雾与沙颗粒效果目标锚定 v1

日期：2026-10-23。责任：designer。来源：用户 2026-10-23 08:54 澄清——“水的部分渲染成上面白色云雾的效果，下面沙的部分渲染成沙子的效果”。状态：**需求锚定 / 待真机视觉核对**。本记录解释效果方向，不变更 `goals.md`、冻结锚点、SV 量表或已签收结论。

## 1. 可引用的效果定义

水与界面上方应读作**明亮、近白、柔和斑驳的云雾水体**：在悬浮/扰动关键帧有连续的雾团、深浅和体积层次，界面从沙向水自然过渡；静置清水仍可保留低对比的介质光照斑驳，不应凭渲染制造永久悬沙或将整个画面刷成均匀纯白。沉积区应读作**明确的沙子**：细颗粒、材质色差和可辨的沉积层次附着于沙体，流动时随材料运动；沙面轮廓与下层颗粒不能被白雾遮成一整块平涂。界面可以柔和混合，但上下两种材质须一眼可分。

这一定义沿用只读物理场及外观/物理验收隔离纪律。云雾限制在水体及界面光学区域，颗粒/层理限制在沙体材料区域；不改物理 128 列、库存、checker 或 routeId。

## 3. 待验证差异与 E2 顶光衔接

1. **白色云雾观感**：以 s133 默认构建为现状基线，选同一设备、同一显示尺度的静置、倾斜、摇晃后过渡关键帧，与目标参考帧并排核对水体/雾带 mask。记录“白而有层次”是否成立，区分色阶偏绿/偏暗、雾幅度不足、块状残留和水体过于磨砂等原因。当前 RGB 值仅是实现事实，不能代替真机观感结论。若确有差异，按 E/A 参数候选与锚点 revision 流程评估，不临场改冻结线。
2. **沙子仍像沙子**：同一组画面核对沙体内部细粒、层纹、重轻沙色差以及云雾覆盖边界。E3 防抹平 `stdRatio` 主要保护雾带幅度，不能替代沙区颗粒验收；沿用 B/C 和 SV-06/07 的既有证据口径。
3. **E2 顶光立体感**：[差距表 E2](gap.md)尚缺独立效果定义和基线。其候选作用是让下层沙丘迎光/背光面出现柔和、连续的体积明暗，同时给上层云雾适度的受光层次；顶光若把雾打成纯白平板，或把沙粒/层理压成暗块，即与本目标冲突。E2 开题应同时检查雾带明暗幅度、沙区颗粒可辨和沙丘整体塑形；不能用 C 层纹或单纯提高水体白度冒充 E2 完成。

后续 effector 可在既有 `SV-05/06/07` 量表下附一张“水体云雾 / 界面过渡 / 沉积沙质感 / 顶光立体感”的分区观察记录。该记录是差异诊断材料，**不是新增 PASS 阈值**；需要改颜色或冻结锚点时另走正式 revision。
