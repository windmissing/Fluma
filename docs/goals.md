# 项目目标（goals）

> 维护人：manager。只在目标正式变更时修改，每次修改注明日期与原因。
> 本文档是整个流水线的"北极星"：所有 gap 分析、优先级排序、方案验证都以它为准。

## 目标清单

> 当前推进顺序：G2（场景二）优先，G1（场景一）次之，G3（通用容器动态）贯穿验证。
> 验收口径：每个目标必须同时具备可执行的客观测试用例与主观效果用例；当前 `docs/test-cases.md` 与 `docs/effect-cases.md` 仍为占位，目标状态不能仅凭实现完成而判定达标。

| 目标 ID | 描述 | 量化指标 | 状态 |
|---|---|---|---|
| G1 | 场景一：两种不互溶液体（油水分层），完整复现 `docs/PROJECT_GOALS.md` 的目标场景 | 1）重相、轻相在模拟层与渲染层各自总量漂移均 < 0.1%；2）翻转后 90% 上下交换发生在 2~4 秒；3）扰动停止后 ≤ 4 秒恢复近似水平界面；4）界面过渡带宽 1~2 像素，无锯齿 | NOT_STARTED |
| G2 | 场景二：水中重沙/轻沙三相堆积，完整复现 `docs/PROJECT_GOALS.md` 的目标场景 | 1）水、重沙、轻沙各相总量漂移 < 0.1%；2）重沙在沙堆上 1/3 的占比 / 下 1/3 的占比 ≤ 0.5（初值）；3）扰动停止后 ≤ 8 秒（初值）完成再沉降与堆积稳定；4）动态连续平滑、无粒子瞬移，实测帧率 ≥ 100fps | NOT_STARTED |
| G3 | 两场景通用容器动态：快速旋转、倒立、摇晃下保持物理稳定与守恒 | 1）任意动态操作全程各相总量漂移 < 0.1%；2）支持 ±180° 连续重力方向变化，倒立渲染相序正确；3）暂时混合必须在 G1/G2 规定时限内恢复稳定态；4）无数值爆炸、永久乳浊或永久悬浮 | NOT_VERIFIED |

> 状态说明：`NOT_STARTED` 表示目标能力尚未按 B1~B4 实现并验证；`NOT_VERIFIED` 表示已有基础能力，但当前 `test-report.md` 与 `effect-report.md` 均无有效验收数据。目标语义以 `docs/PROJECT_GOALS.md` 为唯一事实来源，本文档不重复完整需求。
