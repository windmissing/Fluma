# 项目目标（goals）

> 维护人：manager。只在目标正式变更时修改，每次修改注明日期与原因。
> 本文档是整个流水线的"北极星"：所有 gap 分析、优先级排序、方案验证都以它为准。

## 目标清单

> 当前主线：**G2+G3**（场景二在容器动态下的表现）优先；**G1+G3**（场景一在容器动态下的表现）为独立支线，另行开题。
> 验收口径：每个目标必须同时具备可执行的客观测试用例与主观效果用例；当前 `docs/test-cases.md` 与 `docs/effect-cases.md` 仍为占位，目标状态不能仅凭实现完成而判定达标。

| 目标 ID | 描述 | 量化指标 | 状态 |
|---|---|---|---|
| G1 | 场景一：两种不互溶液体（油水分层），完整复现 `docs/PROJECT_GOALS.md` 的目标场景 | 1）重相、轻相在模拟层与渲染层各自总量漂移均 < 0.1%；2）翻转后 90% 上下交换发生在 2~4 秒；3）扰动停止后 ≤ 4 秒恢复近似水平界面；4）界面过渡带宽 1~2 像素，无锯齿 | NOT_STARTED |
| G2 | 场景二：水中重沙/轻沙三相堆积，完整复现 `docs/PROJECT_GOALS.md` 的目标场景 | 1）水、重沙、轻沙各相总量漂移 < 0.1%；2）重沙在沙堆上 1/3 的占比 / 下 1/3 的占比 ≤ 0.5（初值）；3）扰动停止后 ≤ 8 秒（初值）完成再沉降与堆积稳定；4）动态连续平滑、无粒子瞬移，实测帧率 ≥ 100fps | NOT_STARTED |
| G3 | 两场景通用容器动态：快速旋转、倒立、摇晃下保持物理稳定与守恒 | 1）任意动态操作全程各相总量漂移 < 0.1%；2）重力方向在 ±89° 内连续变化，90° 跨越采用经审计的 `invert180()` 事件语义，事件前后倒立渲染相序正确；3）暂时混合必须在 G1/G2 规定时限内恢复稳定态；4）无数值爆炸、永久乳浊或永久悬浮；严格连续过 90° 不在本期目标内，若需要须另立 v3 | NOT_VERIFIED |

## 2026-10-18 双输入模式与自动验收目标（当前生效）

> 日期：2026-10-18。原因：用户明确要求“构建两种模式，测试模式（自己构建出手机倾斜状态并测试），体验模式（通过传感器获取手机状态）”。这是用户已授权的输入/验收方式变更，取代此前必须用户手持手机才能完成 P-011 验证的约束；物理机制及全部客观/主观阈值不变。

1. **测试模式**：程序生成带时间戳的可重复手机姿态序列，覆盖 P-011 静态、连续、反向、回正和快速变化场景，自动采集客观遥测及视觉证据。合成姿态进入与体验模式共用的姿态转换、重力/倾角处理、物理与渲染链路，不能直接改写沙体状态或评分输入。
2. **体验模式**：读取真实手机传感器姿态，驱动共用后续链路。合成姿态仅在测试模式生效，两个输入源互斥；进入/退出/重启模式时隔离残留脚本、传感器滤波、手势覆盖等状态。
3. **自动验收**：P-011 客观测试与视觉效果评估可使用可复现模拟姿态完成，无需用户手持操作。补充输入隔离、模式切换/重启、序列复现与传感器接线用例，缺少时先补用例再实现。HG-TT-04、主观 0~10 分且 ≥6 及全部既有客观门槛继续有效；连续录像与 hilog 对齐等证据要求也继续有效。
4. **能力边界**：报告注明 mode、输入来源/序列、时间戳、证据身份和未覆盖项。合成姿态验证应用的输入处理、物理与渲染响应；真实硬件噪声、标定、人体手持体验只有取得对应实测证据才能声称验证，不作为必须等待用户操作的自动验收前置。

## 子目标拆解（2026-10-14）

> 拆分原则：重要 > 视觉效果好 > 容易实现。目标按两条组合线组织：**G2+G3 主线** 与 **G1+G3 支线**；G3 不是独立交付项，而是分别并入两条组合线的容器动态能力。

### G2+G3 主线子目标

| 子目标 | 验收标准 | 可测试指标 / 对应用例 |
|---|---|---|
| G2.1 三相守恒与静置分选基线 | 水、重沙、轻沙总量漂移均 < 0.1%；静置后重沙/轻沙分选稳定；沙堆轮廓与安息角达标 | `TC-WS-01~04`、`TC-WS-10`；`EC-WS-01`、`EC-WS-03`、`EC-WS-04` |
| G2.2 静态倾角响应 | ±15°/±30° 倾角下水面方向正确、表层沙滑移连续，无跳变或破面 | `TC-WS-05~06`；`EC-WS-02`、`EC-WS-05` |
| G2.3 连续翻转时序 | 重力方向在 ±89° 内连续变化时沙体响应连续；90° 由经审计 `invert180()` 事件跨越，无非法状态改写 | `TC-WS-07`、`EC-WS-07`；需补“连续重力扫描 + 时序”用例 |
| G2.4 倒置分选动态 | 倒扣后轻沙上浮、重沙下沉，分选反转过程可见且稳定；倒置后 ≤ 8s 达到稳定相序 | `TC-WS-07`、`EC-WS-07`；需补“倒置过程时序/交换完成度”用例 |
| G2.5 相序交换完成度 | 倒置与翻回后相序正确、体积守恒、无镜像错位或双份沙堆 | `TC-WS-07`、`EC-WS-07`；需补“交换完成度评分”用例 |
| G2.6 摇晃混乱与再沉淀 | 剧烈摇晃时按比例扬起并形成可信悬浮；停止后 ≤ 8s 完成再沉降与堆积稳定 | `TC-WS-08~09`；`EC-WS-06` |
| G2.7 渲染一致性与流畅度 | 模型与渲染三相分类偏差 ≤ 5%，动态过程无瞬移，`fpsP95 ≥ 100` | `TC-WS-11~12`；`EC-WS-08` |

### G1+G3 支线子目标

| 子目标 | 验收标准 | 可测试指标 / 对应用例 |
|---|---|---|
| G1.1 双相守恒与基础分层 | 重相、轻相总量漂移 < 0.1%，静置后形成稳定上下分层 | 需补客观/主观用例 |
| G1.2 翻转交换时序 | 翻转后 90% 上下交换发生在 2~4 秒，过程连续自然 | 需补客观/主观用例 |
| G1.3 界面恢复与视觉稳定 | 扰动停止后 ≤ 4 秒恢复近似水平界面，过渡带宽 1~2 像素，无锯齿 | 需补客观/主观用例 |

### G3 共享动态子目标（并入两条组合线）

| 子目标 | 验收标准 | 可测试指标 / 对应用例 |
|---|---|---|
| G3.1 事件式 90° 跨越语义 | ±89° 连续变化 + 经审计 `invert180()` 事件跨越 90°，事件前后相序正确且不改写数据模型 | `TC-WS-07`、`EC-WS-07` 部分覆盖；需补专项事件语义用例 |
| G3.2 动态守恒与状态稳定 | 快速旋转、倒立、摇晃全程各相漂移 < 0.1%，无数值爆炸、永久乳浊或永久悬浮 | `TC-WS-01`、`TC-WS-10`；`EC-WS-08` |
| G3.3 长时回归矩阵 | 组合姿态、倒立、摇晃与静置后，系统在规定时限内恢复稳定 | 需补全量回归用例 |
| G3.4 测试/体验双输入模式（2026-10-18 用户正式新增） | 测试模式生成可复现手机姿态，体验模式读取真实传感器；输入互斥且共用后续处理链路，P-011 自动验证无需用户手持 | dual-input-v1 已实现/安装，39 项产品测试及模式真机 smoke 通过；P-011 默认重层响应另为 FAIL，完整视觉验收未完成 |

> 状态说明：`NOT_STARTED` 表示目标能力尚未按 B1~B4 实现并验证；`NOT_VERIFIED` 表示已有基础能力，但当前 `test-report.md` 与 `effect-report.md` 均无有效验收数据。目标语义以 `docs/PROJECT_GOALS.md` 为唯一事实来源，本文档不重复完整需求。
