## 3. 场景执行脚本

### EC-TT-01 慢速持续倾斜下的底层跟手

1. 前置：设备近似直立，底层沙稳定，无其他输入。
2. 执行：静置 2 秒；约 3 秒缓慢右倾到目测约 15°；保持 3 秒；约 3 秒回正；静置 2 秒；再按相同节奏向左重复。
3. 期望：底层沙随倾斜连续响应，方向符合重力预期，保持阶段有可信滑移/再堆积，无明显等待动画。
4. 评分维度：跟手即时性、连续性、回正/反向自然度、运动真实性、稳定流畅度。

### EC-TT-02 快速倾斜、回正与反向切换

1. 前置：设备近似直立，底层沙稳定。
2. 执行：快速右倾到目测约 20°，保持 1 秒；快速回正保持 0.5 秒；快速左倾到目测约 20°，保持 1 秒；回正静置 3 秒；重复 2 次。
3. 期望：快速输入有可信响应，回正与反向方向明确，不出现长时间静止或固定动画感。
4. 评分维度：跟手即时性、连续性、回正/反向自然度、运动真实性、稳定流畅度。

### EC-TT-03 连续交替倾斜中的连续与迟滞观察

1. 前置：设备近似直立，底层沙稳定。
2. 执行：以约 1Hz 在目测 ±10° 之间连续交替 6 秒；随后停止输入静置 5 秒。
3. 期望：底层运动明显、连续、不迟滞，反向转折仍可理解；停止后自然回稳。
4. 评分维度：跟手即时性、连续性、回正/反向自然度、运动真实性、稳定流畅度。

### EC-TT-04 底层与水面/表层运动协调

1. 前置：设备近似直立，水面/表层与底层均可观察。
2. 执行：右倾 15° 保持 3 秒；回正 1 秒；左倾 15° 保持 3 秒；回正静置 3 秒。
3. 期望：底层与水面/表层可存在层次或速度差，但方向和节奏应像同一容器内的物理响应。
4. 评分维度：底层-表层协调感、跟手即时性、连续性、运动真实性、稳定流畅度。

### EC-TT-05 滞后、抖动、假动或不动专项复查

1. 前置：复用 `EC-TT-01~EC-TT-04` 同路线录像；不新增手持输入。
2. 执行：依次 1 倍、0.5 倍、0.25 倍速回放；检查每个转折点与疑似异常段，并对照手部姿态、水面/表层和底层运动。
3. 期望：底层运动与输入有可理解因果；无持续粘滞、无输入抖动、纹理假动、逆向漂移或应动不动。
4. 评分维度：跟手即时性、连续性、回正/反向自然度、底层-表层协调感、运动真实性、稳定流畅度。

## 4. MUST-PASS 硬门槛

| 编号 | 判定 |
|---|---|
| HG-TT-01 | 崩溃、白屏/黑屏、冻结超过 1 秒，任一出现即触发。 |
| HG-TT-02 | 画面撕裂、破面、持续闪烁，任一出现即触发。 |
| HG-TT-03 | 底层沙瞬移或逐帧不连续位移，零容忍。 |
| HG-TT-04 | 有效倾斜输入持续 2 秒且底层沙可分辨时，底层完全无可辨运动，零容忍。 |
| HG-TT-05 | 持续 `>= 1` 秒且影响观察的非输入性高频抖动，零容忍。 |
| HG-TT-06 | 主观可见持续卡顿或持续流畅度失败；精确 `fpsP95` 移交 tester。 |

## 5. 执行与判定纪律

1. 每个适用维度单独评分，禁止把场景分数平均成场景总分后再判定；适用维度全部 `>= 6` 且无硬门槛触发才判 `PASS`。
2. `N/A` 只允许用于底层沙不可分辨、场景不适用等可说明原因，不参与平均。
3. 崩溃、冻结、掉帧、精确时延、相位滞后、跟踪率、传感器采样异常和 `fpsP95` 问题标注移交 tester，不得当作主观扣分。
4. 同一路线上一版只能对比 `bottom-creep-v2.6` 有效报告；禁止跨路线做 dominance 判定。
5. 报告追加写入，不覆盖历史记录；不同路线不得合并。
