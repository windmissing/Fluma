## 2. 当前实现值与可调域候选

当前值核对来源为 `entry/src/main/ets/render/P012WaterSandRenderer.ets` 中 B/C/A/E3 常量、`buildGrainBitmaps`、`buildStratBitmaps`、`staticTau` 和 `mottleEquiv`。以下是 2026-10-22 工作区实现快照，**不是全部参数已经对外可调**；正式实现前须绑定 E3 验证通过的构建/hash，防止将工作区常量等同已验收基线。

|---|---|---|---|

这些是单轴研究域，**不表示其笛卡尔积全部可上线**。sigma=12及柔化端可能不满足旧冻结 B std≥15 等锚点；不能一面开放这些值一面宣称旧锚点全域成立。上线前应通过参数化锚点适用域 revision：保留推荐配置既有 MUST-PASS，另冻结探索配置的可辨识性、风格与安全要求；若未获批准，只开放证明符合当前适用锚点的子域。这不追溯改变 EAB 历史验收。

### 2.1 可直接翻译的映射

设 f=雾浓度倍率、c=清水对比倍率，m为当前选定噪声实现的mottle：

```text
z(c,m) = clamp(1 + 2.2*c*(m-1), 0.2, 2.0)
tauStatic(c,m) = max(0, 0.55 + 1.8*(z(c,m)-1))
tauWater = 原水体路径的悬浮光学项 + tauStatic(c,m)
alphaWater = min(0.78, existingFogAlpha(f*tauWater))
alphaInterface = 原界面路径，仍受0.55上限约束（首版不随f改变）
ampOrdered = 6*strataStrengthScale
ampMixed = 3*strataStrengthScale
```

`existingFogAlpha` 指现有光学厚度到alpha的函数，不新造一套传递函数。f=c=1恢复同构建推荐链；f改变水体呈现而不改变 qH/qL。静水验证c时使用q=0的固定快照；动态另列，不把物理搬运差异归于控件。

E3当前默认以连续噪声 `m=1+1.63*n` 替代旧64px周期tile；消融才回旧mottleAt。旧函数 std=0.5494（64²、n=4096、seed=20261021）的实测不能当成 E3 新场的常数，更不能继续把0.35估算当实测。新方案固定 E3 噪声结构、seed与平流相位机制，只在上述链增加c；E3最终基线以验证回执为准。

颗粒原算法在归一化后截幅，最终sigma、source-over后的图像std不是同一量；不得用“sigma×0.75”替代成图测量。改变fine时重新生成同seed纹理，保留归一化、截幅、envelope关系；不靠减低分辨率模拟粗颗粒。

### 2.2 λ与alpha的实现陷阱

当前有效周期为 `lambdaPx=256/max(1,ceil(256/(lambdaMaterial*pxPerMaterial)))`。例如pxPerMaterial=4、名义λ=24，实际为85.333px即21.333材料单位，偏差约11.1%；现有注释“偏差<1%”不能作为全域保证。候选观测同时登记 requested/effective λ、几何比例与周期数k；合并同k的控件档，避免滑动无变化。不得未评审就修改对齐算法；若产品需要连续调节，另交architect评估。

C位图是灰度128±delta以source-over合成，直接改alpha会连带改变沙体平均亮度，不只是条纹强度。因此首版保持C alpha=0.5、C3=0.10，只调delta幅度。alpha的[0.35,0.5]仅作后续离线研究候选，**不纳入首版公开控件**；当前值和可调取舍在此显式登记。

## 3. 与26/20配置同构的暴露方式

复用“草稿→校验→应用／取消→恢复推荐值”的交互和持久化组织，不复用物理状态重置副作用。现有起停角由 `SandCanvas.ets` 的草稿应用进入 `WaterSandField.configure()`；外观不应塞进该物理引擎通道，否则仅调雾也可能清理物理路线状态。

建议页面聚合配置 `WaterSandScreenConfig { physics: WaterSandParams, appearance: P012AppearanceParams }`：physics继续原configure；appearance由只读adapter之外的渲染配置入口接收，renderer持有已验证配置。若工程选择在页面既有配置接口增设appearance嵌套字段，也必须在进入物理configure前剥离，由architect明确类型归属。

面板分“画面质感（仅改变外观）”：颗粒粗细三档、颗粒对比、雾浓度、层理疏密、层理强度、清水斑驳。标注“推荐”而非“物理标定值”；不向用户显示hfH、CI或参考带。恢复推荐恢复E3验证构建绑定的完整appearance对象。

配置字段至少含schemaVersion、styleFamilyId=`soft-water-sand-v1`、rendererVersion、六个实际参数、source（factory-recommended/user/preset）及configRevision。范围、步长、相互约束、有限数全部在应用前校验；非法输入拒绝整包并显示边界，不偷偷clamp成用户未选值。公式内有限颜色截幅是算法行为，与输入拒绝区分。

资源与状态生命周期：草稿滑动不逐事件烘焙；应用时准备新资源，成功后在帧边界原子切换，失败维持上一合法包并提示。最多一个待替换包，过期构建结果丢弃并释放；旧位图在无引用后释放。尺寸/geometryEpoch改变按现有机制重建；参数变更不重置物理场、材料相位或随机seed。TEST/EXPERIENCE切换可保留外观选择；canonical物理证据路径继续按既有隔离规则，不写入物理ledger。来源/hash写外观测量manifest，不冒充thresholdCalibrationId。持久化可沿用页面延迟写入模式；版本迁移失败提示并使用已知合法包，冷启动无合法包才使用版本化推荐值。

## 4. 安全与风格边界

| 边界 | 处理与验证候选 |
|---|---|
| 物理不变量 | 相同初态/输入下，外观参数前后物理状态与路线账本应相同；只读adapter及相库存校验保留，不改变guard/预算/守恒/倾角、128列或悬沙 |
| alpha工程上限 | 水体≤0.78、界面≤0.55作为候选配置继承的既有上限，不让用户调cap。二者覆盖同像素时合成不透明度可达`1-(1-.78)*(1-.55)=.901`，故单一cap并不能证明“绝不全屏雾”；需另验界面/沙面可辨与高覆盖面积 |
| 高亮度、低饱和基调 | 首版锁定E调色盘/光照/色调映射与雾RGB，不开放曝光/饱和度/色相；仍需在极端组合核查是否灰暗、过曝或遮没层次，锁palette不是成图风格保证 |
| 连续性与真实性 | 参数不得用每帧换seed制造闪烁，不恢复64px周期网格；复用E3验证后的采样和MaterialColumnSampler，不以浓雾掩盖竖向阶梯；E3最终冻结指标对组合配置的适用域须显式登记 |
| 性能 | 不改物理分辨率，不新增无界缓存；沿用已通过第一梯队性能口径并与E3通过构建配对比较。用户调参的烘焙尖峰也计入交互评估，不预判100fps或90Hz满帧可达 |

## 5. 锚点候选：调出同风格的不同效果

所有数字档位都是**候选采样点，不是PASS线**。沿用Q1已登记的native/display双轨methodId，固定显示尺度/缩放方式/mask/ROI/编码；静态与动态、沙与清水分列，支持不足不补成有效结果。参考带只作描述性对照。先单轴后组合，固定物理快照、几何、seed、平流相位和其它参数。

| 参数与候选点 | 客观观察／预期可辨变化 | 主观验证及反例检查 |
|---|---|---|
| fine 2/4/6 | 频谱重心、自相关长度、hfH和std；粗档应表现更长相关尺度，但不强求hfH单调 | 同风格的细／粗颗粒可辨，非大块马赛克或周期瓷砖；沿SV-05既有相关条目记录，不创立新分数线 |
| sigma 12/20/24 | 同一纹理的std、亮暗分位数、截幅比例；实测增加对比的响应与饱和点 | 颗粒存在感不同而非曝光变化；旧B锚点适用性单列，不把低端失配静默判过 |
| fog f=0.5/0.75/1 | alpha分布/上限覆盖率、清水亮度、边界可辨度；同tau的alpha应非减，但水体std不保证单调 | SV-06中自然云雾与沙面可见；浓档不能掩盖网格，淡档不变成断裂贴片 |
| λ=16/24/32（去重后） | requested/effective周期、row-mean显著极值间距/数量与ROI支持；不同有效周期应可辨 | SV-07层理疏密变化，仍像沉积层次，不为了22–43次参考振荡凑条数 |
| C强度=0.5/1/4⁄3 | 同位置条纹prominence、row-mean振幅及平均亮度漂移；混合层幅度较弱 | SV-07历史层次由柔到清楚，无斑马条纹；不能以整片变暗冒充层理增强 |
| mottle c=0.5/1/1.25 | q=0时水体std、分位数、cap覆盖率、自相关与时间稳定性；冻结空间尺度 | SV-06下较平静／丰富斑驳可辨，无均匀蒙版或噪点闪烁；不假定std随c全域单调 |

风格候选诊断同时记录Y的P10/P50/P95、饱和度`(maxRGB-minRGB)/maxRGB`（全黑定义0）的P50/P95及通道截幅比例，用推荐配置与参考同尺度描述统计提供依据，再由effector/manager冻结适用域。当前不凭空给出亮度/饱和度PASS阈值，也不以与参考数值相等替代真实感。既有SV量表和3分及格线不变；新条目映射/描述锚点必须走候选→冻结流程。

可辨变化的量化幅度须超过同配置重复测量误差带，误差带与盲评判据在采前登记；本设计未测该误差，不能声称各端点已有效。A→B→A在相同快照、seed与相位下检查推荐效果可恢复；若后端非逐位确定，容差须事前冻结，不能跑完补标准。

## 6. 成本、组合与执行顺序

初轮离线单轴为6×3=18个配置条目，共同推荐点只有在manifest完全一致时复用。另建议四个组合探针（按fine/sigma/fog/λ/C强度/mottle顺序）：柔细 `(2,12,.5,24,.5,.5)`、推荐 `(2,20,1,24,1,1)`、粗密 `(6,24,1,16,4/3,1.25)`、粗清 `(6,20,.5,32,1,.5)`。它们只是交互风险样本，不是六维域覆盖证明；tester后续须在执行前补齐两两组合或缩小公开域的策略。

候选架构复用三张256²颗粒位图（RGBA原始约0.75MiB）、三张64×256层理位图（约0.188MiB），不缓存全部参数组合。一次原子换包可能短时同时持有新旧包，原始像素上限约翻倍，另计ImageBitmap后端副本与E3缓冲，不能把原始字节当总内存。fine/sigma重烘颗粒，λ/强度重烘层纹，fog/mottle使现有雾缓冲失效；重烘成本须实测，参数控制不承诺零成本。帧内仍复用E3验证后的连续采样/缓冲路径，禁止为控件另加逐像素第二遍或绕过既有缓存失效规则。

路由：**E3验证完成→manager验收本候选与参数化锚点revision需求→architect细化配置/资源接口→tester＋effector冻结测量和风格适用域→manager排实现与验证→据结果冻结可公开范围**。离线未通过或存在风格/性能冲突时缩小候选域、改映射或保持设计待定；不回退EAB签字、不降低已冻结门槛求绿。Q1仍是独立非阻断轨道，不要求先关闭Q1才能推进本设计。
