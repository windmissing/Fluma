## 2. SV-05 界面观感：4 分

### 客观锚点复核（effector 用冻结脚本独立复测，非转抄 developer 数字）

用 `tools/measure_render_p012.py --profile off-ws0` 复测 `eab-s97-pair1-eab-w0.jpeg`：
- **界面 maxGrad = 16.3**（与 developer 报告一致）——低于目标参考帧区间 20.7~60.9 的**下限**，即过渡比目标最缓的帧还要柔和
- **过渡宽度 10-90% = 74 行**（OFF 基线为 1 行）——"数十行级"要求达成
- OFF 基线 maxGrad 116.5 → EAB 16.3，**改善 7 倍**

### 主观判断依据

- 垂直剖面实测（x=640）：水体灰绿平台（~187）→ 雾带缓升（216→228）→ 亮 cream 带（246）→ 沙面（~160），全程无一条 >8 亮度/行的硬边；对照 OFF 档同位置 1 行内跳变 77 亮度（悬崖），改善性质是"从悬崖到云雾"
- 液面/界面平直度保持（0° 静置水平，与目标 f0 一致）；表面张力感依赖的液面高光不在 E/A/B 范围（属后续档），未扣分
- **扣 1 分原因**：雾带内部由矩形块拼接（实测 y=1600 行 800px 内 138 个色段，块边界可见直角转折，见 `eab-detail.png`）；目标帧的悬浮云雾是连续渐变无块结构。观感上"柔和"达标，"自然度"打折

## 3. SV-06 质感平衡：3 分

### 客观锚点复核

- **sand lumStd = 17.89**（≥15 ✅；落在目标参考 15.0~27.2 区间内）——effector 复测与 developer 一致
- **sand hfH = 8.075**：远超 §5.3 门槛 0.8；与附表目标参考 1.16~1.75 不同是**分辨率差异**（OFF 档同 ROI 网格噪声即 3.1），developer 已用 FFT 谱分析补充论证：EAB 最强谱峰 12.4px/峰比 2.3（宽谱、团簇尺度、无主导周期）vs OFF 5.6px/峰比 88.0（CA 网格节距尖锐峰）——**"无网格感"的量化证据成立**，本评审采信
- **动态无贴纸感**（16 帧连拍逐帧核对）：颗粒带随倾斜平流偏移 0→208 tile px，H/L/M 三带推进速度不同（重沙带最慢、悬浮带最快），水面随重力微动——纹理与几何**同源运动**，不存在"纹理不动几何动"的贴纸病征。中途两次 `pair=X` 冻结帧按设计自愈回 `pair=V`，录像中无可感知卡死
- **静态无闪烁**：pair1 静止段 3 帧 SHA256 全同；注填推进期 8 帧互异且变化全部由物理态驱动

### 主观判断依据

- 沙面 400% 放大（`eab-detail.png`）：细密双色颗粒交织，粉质感成立，与目标"闪粉感"方向一致
- **扣 2 分原因**：①水体斑驳 lumStd 17.38 达标（≥15），但斑驳由矩形块构成（128 列逐列计算 × 段状 alpha 桶的产物），块状结构近看暴露"程序感"，与目标的连续悬浮云雾有质的差距；②液体整体观感上，EAB 水体偏"磨砂玻璃"而非"浑浊液体"——目标帧水体内部有更绵密的悬浮颗粒雾，EAB 的块尺度（~10-30px）明显大于目标的连续雾尺度
- 网格感、闪烁、贴纸感三个退化方向均未出现——按量表"偏纯液体或偏纯沙，但可接受"= 3 分档

## 4. SV-07 整体相似度：4 分

### 客观锚点复核

| 锚点 | 目标参考 | OFF 基线 | EAB 实测 | 判定 |
|---|---|---|---|---|
| 水体 lumMean | 202~221 | 64.90 | **207.57** | ✅ 落在目标区间 |
| 水体 RGB | (192,202,196) 淡薄荷 | (36,71,113) 荧光钴蓝 | (199,212,208) | ✅ 色相一致 |

### 主观判断依据

- 静置对照（并排图第一行）：OFF 档一眼"屏幕元素"（暗底、荧光蓝），EAB 档整体明度、色温已与目标同档，"不看说明当成真流麻"在缩略图距离上成立
- **扣 1 分原因**：①雾带块状结构（同 SV-05/06）；②沙/水比例与目标不同（EAB 测试场景沙层薄、雾带厚，目标帧沙丘占画面 2/3）——此差异源于测试场景初态而非渲染算法，不重复扣分但影响整体印象；③目标帧的顶光立体感（沙丘受光面/背光面）尚未实现（属后续 C/D 档与光照项）
