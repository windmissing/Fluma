## 2. 关键实现决策与理由

### 2.1 CanvasPattern 采样会把烘焙 alpha 的像素按 1/alpha 放大并钳位（本批主缺陷）

**现象**：s93/s94 首次真机出图，混合带与轻沙带整片变白（实测 (218,231,182)/(250,246,235)，随帧累积更亮），沙体 lumStd 只有 6.99。

**定位过程**：
1. 盒参数诊断排除了画布缩放/浮层导致的坐标错位（盒恒为 `[51,215,w=263,h=311]`）；
2. 竖直/水平像素切片确认白带严格局限在容器盒内（y=1760~1925），细采样为纯 (255,255,255)；
3. 按 `renderSeed` 做逐项消融（999 无颗粒 / 998 无雾 / 997 无亮粒）：去掉颗粒后混合带恢复橄榄色 (177,201,151)，去掉雾再变暗，去亮粒无变化 → 成本在颗粒层；
4. 颜色反演验证：若位图像素带 alpha=140（0.549）而采样值被放大 1/0.549 后钳位到 255，则合成结果 = base×0.451 + 140。重沙带基色 (145,168,111) → (205,216,190)、高光色 (188,205,158) → (225,232,211)，与观测白带 (218,231,182) 同量级且逐通道单调一致（颗粒 tile 零均值、逐像素 ±20 级摆动解释通道残差）。结论：ArkTS `CanvasPattern` 采样对带 alpha 的像素按 ≈1/alpha 放大颜色分量并钳位（140/255 → ×1.82 → 饱和），不是本项目代码里的合成系数错误。

**修复**：位图纯不透明（`pxAlpha=255`），叠加强度改由 `ctx.globalAlpha` 控制（save/restore 作用域内自动恢复）。数学上 alpha 复合 `base + a·delta` 与 §5.1 加性模型 `Y=Ymaterial + sigmaG·nG` 等价，等效 sigmaG = a×sigmaG。修复后白带消失，混合带 (242,240,227)、重沙带呈颗粒明暗摆动 lum 168~185。

### 2.2 叠加强度 0.55→0.75（锚点定标）

修复后 `sand lumStd=14.38 < 15`（冻结附表 §3.3 验收线）。按等效 sigmaG = a×20 反推：base 方差 ≈ 14.38² − (0.55×19)² ≈ 97.6，a=0.75 预测 lumStd = √(97.6 + (0.75×19)²) ≈ 17.3。实测 **17.89**（与预测差 0.6），G 通道 std **16.86**，落在 §5.3 锚点（≥15，参考 17~23）与附表区间（15.0~27.2）内。

### 2.3 交付清理（s97）

移除 s94/s96 期间为定位白加入的诊断代码：`renderSeed` 消融门（999/998/997）、`skipSpark` 形参、`grainDiagFrames` 前 5 帧路径日志、`lastDiagBox*` 盒变化日志、`geomLogFrame` 每 60 帧几何日志。保留一次性路径日志（`pattern fill path used` + `grain: geom col=64`，每会话各一条，用于后续现场分诊）。`P012RenderTypes.renderSeed` 作为帧上下文契约字段保留（颗粒 tile 用 §5.1 规定的 renderer 独立固定种子 20261022/23/24，不读 renderSeed）。

**清理零影响验证**：s97 与 s96 在同一配对场景下四项指标逐位一致（sand lum/std/hfH = 168.17/17.89/8.075，water lum/std/hfH = 207.57/17.38/0.979）。

### 4.2 hfH 8.075 与附表 1~2 参考带的差异论证

附表 §4 注 3 已声明"hfH 在 ws 档虚高（3.2~3.4）来自逐格纯色填充的网格周期噪声，不是颗粒质感"，注 4 声明跨分辨率可比性经 effector 主观核对成立。本批用离线谱分析给出可核查的区分证据（沙 ROI 逐行 1024 点 FFT，26 行平均功率谱）：

| 判据 | EAB | OFF（对照） |
|---|---|---|
| 最强谱峰位置 | 12.4px（团簇包络尺度） | **5.6px（CA 网格节距）** |
| 峰/邻域中值 | **2.3**（宽谱、多尺度、无主导周期） | **88.0**（尖锐周期峰） |
| 次强峰/最强峰 | 0.97（多尺度并列） | 0.56（单一主导） |

即：OFF 的 hfH 由单频网格周期主导（附录点名的"虚高"），EAB 的高频来自真实随机颗粒（无周期性）。颗粒物理尺度与参考视频等效匹配：细粒特征 2 tile px × (931/256) ≈ 7.3 屏幕 px，参考视频同尺度折算 ≈7.0 屏幕 px（缩放比 931/200=4.655）。面积平均降采样到参考分辨率（×4.655）后 hfH 8.075→5.021，残余差异归因于测量介质：参考为视频压缩帧（编码低通削高频），本机为原始帧缓冲截图。结论：hfH 按 §5.3 判据（≥0.8）通过；附表 1~2 带在设备原始分辨率下不适用，按附表注 4 交 effector 主观核对。

bootstrap 按 P-011 §1607-1611 协议：10,000 次 run-cluster percentile 重采样、固定种子 `20261019`、2.5/97.5 百分位。区间退化为点，因为三块在冻结口径下**逐位一致**——这是确定性（同 seed、同 step 序列、同脚本）的直接证据，强于窄区间本身。

**同物理 step 序列一致性（DoD ③）**，三条独立证据：
1. 代码路径：物理步进 `ws.step(frameDeltaMs/1000)` 在渲染分发上游；`p012ShouldUseP012Renderer` 只在两个渲染分支间互斥选择，两者对 snapshot 均只读；`setP012AppearanceTier` 只改渲染状态并调用 `resetContinuity()`（清 UV 连续性，不触碰物理）。
2. 跨块同一 wall-clock 点的测量逐位一致 → 切换外观不改变物理轨迹。
3. 静止段帧级确定性：pair1 的 EAB 三帧 SHA256 完全相同（同物理态 → 同画面，无逐帧随机）。

### 4.4 静态无闪烁 / 动态无贴纸

- **静态**：`dyn-s96-static-*.jpeg` 8 帧在注填推进期互不相同（物理在动，`sandTopY` 510.7→484.2 单调下降，与 geom60 日志逐帧对应）；pair1-EAB 静止段 3 帧哈希全同。合起来说明帧变化完全由物理态驱动，渲染无逐帧抖动。
- **动态**：全宽 swipe 倾斜后，颗粒平流偏移从 0 → 179.98 → 195.97 → 203.96 → 207.96 tile px（H/L/M 三带各自推进，`pair=V` 保持有效），水面 `waterTopY` 347.8→346.9 随重力倾斜；中途两次 `pair=X`（通量校验瞬时不通过）按设计冻结该帧纹理并自愈回 `V`，无卡死。录像替代物：`test/artifacts/p012-measurements/dyn-s96-motion.gif`（静置 2 帧 + 倾斜 16 帧，容器盒裁剪），供 SV-06 主观判定。

### 4.5 性能配对（同相位 25s 静置，FPS 取自页面计数器三帧窗口）

| 档位 | 外观 | FPS 窗口 | 备注 |
|---|---|---|---|
| tier0 | legacy OFF（原渲染） | 30 / 36 / 60 | 注填推进后达 vsync 上限 |
| tier1 | E | 30 / 34 / 31 | 与 OFF 同相位持平 |
| tier2 | EA | 38 / 31 / 32 | 与 OFF 同相位持平 |
| tier3 | **EAB** | **12 / 12 / 11** | **约 3 倍帧时劣化 → PERF_BLOCKED** |

成本定位到 B 档颗粒合成：算法稿 §5.3 的预算约束的是 CPU 侧 `O(128)` 差分与 ≤48 次 draw（当前实现 3 次 fill，CPU 侧远低于预算），真机成本在 Canvas2D 光栅化——每帧 3 带各一次 `createPattern` + 254 点 Path `clip()` + `fillRect(boxX-256, boxY-256, fullW+512, boxH+512)`（≈1443×1611 冗余面积，而重沙带实际仅约 140px 高、空带仍走完整 fill）。E/EA 与 OFF 持平、仅加入颗粒合成即塌到 1/3 帧率，隔离结论明确。

## 6. 红线自查

- **只读物理场**：B 档只读 `WaterSandSnapshot`（`sandTop/bh/bl/mh/ml` 经 adapter 访问器），不改库存、不新增字段、不读 P011 日志反驱动画。

- **一次帧一个分支**：if/else 互斥，无叠加；canonicalEvidence 采集强制 OFF 分支。
