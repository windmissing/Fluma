## 2. 三种量的关系：全局坡度、局部硬约束、参考倾角

取 `N=128, dx=1, H=tan30°=0.577350269`；`g_e=S[e+1]-S[e]`，`theta` 是已提交 effectiveTilt，`phi` 是全宽表面 OLS 坡度角。以下正向推导对负向按符号镜像成立，不用绝对值掩盖反向流动。

在 `theta=45°` 时，全边硬约束要求：

```text
|g_e-1| <= H  =>  0.422649731 <= g_e <= 1.577350269  (每条边)
```

**纠正停机报告的几何解释：** 同向30°线性沙面 `g=tan30°` 的残差为 `1-0.577350=0.422650<H`，它与45°参考下的硬约束相容；反向30°的残差才是1.577350。当前冲突是近乎水平/含反向局部边的实测场无法及时变成所需坡面，不是“30°目标本身违反 tan30”。硬约束也不要求沙面严格平行45°。

全宽 OLS 斜率是所有相邻坡度的正权重平均：

```text
D = sum_c (c-63.5)^2 = N*(N²-1)/12 = 174752
m_OLS = sum_e w_e*g_e
w_e = (e+1)*(127-e)/(2*D),  w_e>0,  sum_e w_e=1
```

因此45°下全边合法必有 `m_OLS>=1-H`，即 `phi>=22.911337°`；这是必要条件，达到这个全局角也不保证每边合法。28°～32°目标比这个最低几何要求更高。

| manager 能力输入（假设同向且近线性，仅用于估算） | `tan(phi)` | 45°参考下 residual | 超出 H 的量 | 距28°最易验收端 | 达到28°所需斜率倍数 |
|---|---:|---:|---:|---:|---:|
| 0.17° | 0.002967 | 0.997033 | 0.419683 | 27.83° | 179.20倍 |
| 0.45° | 0.007854 | 0.992146 | 0.414796 | 27.55° | 67.70倍 |

中心30°对应斜率倍数约194.59/73.51。角度直接相除并不是材料搬运量的比例，额度分析必须用 `tan(phi)`。非线性实测场应逐边计算 residual，表中估算不能取代审计。

## 3. 能力缺口哪些可缩小，哪些受结构约束

### 3.1 相邻输运的一阶矩上界：不要求终态恰好线性

在表面高度变化全部来自相邻守恒输运、无边界注入/删除的分支，令 `F_e` 为整个窗口跨边e的净右向材料通量。单位材料右移一列使中心一阶矩增加1，因此：

```text
M = sum_c (c-63.5)*S[c]
M1-M0 = sum_e F_e
|m1-m0| = |sum_e F_e|/D <= sum_e |F_e|/D <= B/D
B <= 300*Tphysics <= 300*5.1 = 1530
```

上式假设每单位相邻搬运至少消耗1单位共享额度，且把全部额度给有用方向、忽略其它通道竞争和局部 cap，已经偏向最乐观情形。它把 §8.14 的线性目标累计通量公式扩展为**任意终态全宽 OLS 斜率的必要条件**；不靠放松 R²、堆端点尖峰绕过。

平坦基线 `m0=0` 时，5.1s最多产生 `atan(1530/174752)=0.501627°` 的 OLS 坡度。这是该相邻输运分支的上界，不是整个含悬浮/升降系统的通用上界。对真实非平坦相位须用 `D*|m_target-m0|`；即使宽松赠予同向初始坡度0.6°，上界也只有约1.10°，距28°所需额度仍约59.5倍。

| 从平坦场所需目标 | 必需净相邻通量/矩增量 | 与1530额度之比 | 仅总额度给出的最短物理时间 |
|---|---:|---:|---:|
| 45°参考全边合法的必要全局下界22.911337° | 73,858.89 | 48.27倍 | 246.20s |
| target-based t90：27° | 89,040.59 | 58.20倍 | 296.80s |
| 收敛容差最易端28° | 92,917.29 | 60.73倍 | 309.72s |
| 中心30° | 100,893.11 | 65.94倍 | 336.31s |

这些时间只是无竞争必要下界，不是可执行预测或延长时限建议；真实局部库存、80/s边 cap、28/s local cap 和预算竞争只会更严。§8.14 六项表中27°的“89,075”按该节公式应为89,040.59（其后明细表89,041正确）；本稿统一重新计算，保留原文历史。

run-001 正/负 overshoot 的总额度实际只有1170/1140（约3.9/3.8s物理时间），已用1127.17/1084.57；比上述赠予的1530更小。故不应把截图/命令壁钟直接当作5.1s满额物理积分。0.17°～0.45°不是永远不变的常量，但仅调限幅/guard无法填平48～66倍的相邻输运额度缺口。

### 3.2 限幅与 guard 的可期待效果

§8.13 的安全投影为 `thetaNext∈intersection_e atan([g_e+deltaG_e-H, g_e+deltaG_e+H])`；材料 writer guard 在提交前验证增量及邻边影响。它们能消除参考倾角越线、拒绝恶化边的搬运、改变预算竞争和实际轨迹，因而可能改善局部滑移效率、减少反复纠偏；也可能裁剪更多请求并减慢可见响应。**目前两个实测 run 均未包含这套组合，没有可支持固定改善倍数的 A/B 数据。**

在近线性0.17°/0.45°坡面上，合法正向参考上限仅为 `atan(tan(phi)+H)=30.127°/30.336°`，离45°尚差14.873°/14.664°。一般非线性场精确上限由 `min_e(g_e+deltaG_e+H)` 决定，可能更低；全局 OLS只能给乐观上界。即便全额度优化得到0.5016°，也不能据此承诺有效参考达到45°。

因此，“零越界”可能体现为 effectiveTilt 长时间保持在约30°或更低；必须同时报告 requested/accepted angle、hold时长、最紧边和 signed slope。若实际参考未到45°，不能把该 run 的安全通过标成“45°物理平台收敛通过”。只改 gate 不会改变任何 `S`；guard 减少非法提交也不等于产生28°全局坡面。

100ms指标沿用 §8.13：死区越过到首个有效 bottom 位移的 P95，不等于参考角到90%，更不等于沙面27°的 t90。限幅后的材料首响应是否≤100ms须实测；不允许用“reference未到位但首响应很快”冒充全坡面收敛。固定降低 maxTiltOmega 同样不能解除额度下界。

### 3.3 全通道与方案3的证明边界

若 lift/settle 产生逐列净垂向表面变化 `V_c`，则应审计：

```text
D*(m1-m0) = sum_e F_e + sum_c (c-63.5)*V_c
```

第二项允许暂时以悬沙库存改变表面一阶矩；它不受“每横移一列增加1”的单一解释，不能用上面的0.5016°宣称所有策略无解。仍须把 lift、settle、悬浮输运、库存及终点悬沙≤5%计入同一轨迹账本，证明变化方向和恢复后的表面有效。当前证据未给出满足30°±2°的这样的构造。

方案3新增悬浮平流可能改善定向输运，但若仍逐相邻边扣相同总额度、最终材料全部落回表面，单纯换通道名字不能绕过一阶矩成本。若依靠允许的残余悬沙、已有非均匀库存或更长位移算子，则必须分别给出真实物理/预算语义和完整构造，不得以“约30行代码”替代可达性证明。新增机制不是目标必达保证。
