## 关键语义发现（对 fixtures/设计的精确化）

**无 P 闭式分支在 H>孔隙容量域不满足 C8 精确等式**：S40F4（B=44，孔隙容量 22）H=27 时，
闭式分支一 `eta=2H4=54` 不满足 `C8(eta)==2H4`（C8(54 格点)=256Q≠216Q）；权威 C8 下界给
eta=49。这与设计 §3 原文一致——闭式仅为特例说明，`require C8(eta4)==target` 才是权威
约束。独立 oracle 以 C8 为准，实现侧（T567）必须用二分下界+精确等式断言，不能实现成
闭式直算，否则 H>孔隙容量场景水位错误。
