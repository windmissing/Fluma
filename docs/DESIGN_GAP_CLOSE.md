## 一、总体判断

1. Gap 确认。s76 的 VV-01..06 / VD-NEW / SV 34/40 全 PASS，验证对象是**旧两相混合模型**（FluidField ero 渗透 + CA 细沙）的天花板，与 PROJECT_GOALS 的场景一（不互溶零交换）、场景二（水中双沙三相）之间是结构性缺口，不是调参问题。
2. 关键冲突点：场景一要求"两相无质量交换"，而当前 FluidField 的 ero 机制本质是允许互渗（TC-05 验证的正是渗透 40s）。**必须新增零交换模式，而不是把 eroRate 调小**——渗透概率调到很小仍然非零，守恒语义不成立。
3. 执行顺序定为 **M1 → M3 → M2 → M4**（与任务建议一致），理由：
   - M1 改动最小，复用 FluidField 高度场骨架，快速验证"零交换+恢复分层"语义；
   - M3（倒立渲染）是 M1 交付后必须回归的渲染分支，合并进 B2 批次省一轮录制；
   - M2 是新模型（风险最大），放在骨架稳定之后；
   - M4 收口全矩阵回归。

## 二、B1（M1）场景一：不互溶零交换液体模式

### 2.1 模型层（FluidField.ets 扩展，不碰 CA）

1. 新增模式枚举 `FluidMode { MISCIBLE, IMMISCIBLE }`（用枚举不用 boolean，为场景二模式扩展留位）。
2. 零交换语义：
   - `eroRate` 置 0；step() 中 ero 改为强制衰减（`ero[c] = max(0, ero[c] - 0.05*ero[c]`），切换模式后旧混合带数秒内消失；
   - `migratePhase` 本身是列间质量重排，不发生相间交换，天然满足"无质量交换"，保留不动；
   - `lightT = totalT - heavyT` 的目标计算保留（s72 修复的关键约束不变）。
3. **摇晃暂时混合的表现**（本批次唯一新增状态）：
   - 物理层**不混合**——质量不交换，分相守恒在模拟层严格零漂移；
   - 新增扰动能量标量 `E`：由倾角变化率与角速度注入，指数衰减（半衰期约 0.5s）；
   - E > 0 时**渲染层**在界面附近绘制卷入液滴/液柱（蓝滴入绿、绿滴入蓝），幅度 ∝ E，位置用确定性相位噪声（逐帧连续、不闪、可复现）；
   - E → 0 后液滴消失，界面恢复平直。液滴不改模拟数据 → 这是"暂时混合的观感"与"永久零交换的守恒"并存的标准做法。
4. 界面回复时限：目标 2~4s 完成上下交换。当前 slowRate=0.008 → 2.2s（90% 重排）已在区间内，immiscible 模式下实测微调即可，不新开全局参数。
5. 调参面板新增：模式切换（三态变四态或独立开关）、E 注入系数、E 衰减率、液滴最大幅度。

### 2.2 渲染层

- renderHybrid 增加 immiscible 分支：混合带宽度=0（eroDepth=0 时三段贝塞尔自然退化为两相+1~2px 过渡带），叠加 E 液滴绘制。
- 渲染层守恒验证时，液滴像素按其颜色归入所属相统计（VV-01 语义不破坏）。

### 2.3 单元测试（Node 1:1 移植先行，照惯例）

- immiscible 模式多轮翻转+摇晃角序列：heavy/light 各自总和恒定（模拟层精确零漂移）；
- ero 全程为 0；
- 翻转后 90% 重排时间在 2~4s 区间；
- 长时静置界面斜率 → 0、ero 衰减到 0。

## 四、B3（M2）场景二：水中双沙三相模型

### 4.1 模型选型（关键决策，含否决项）

| 方案 | 结论 | 理由 |
|---|---|---|
| A：SandGrid CA 扩三相 | 否决 | CA 界面天然锯齿，拟合不出平滑沙丘；三相扫描规则与概率耦合复杂难调 |
| B：FluidField 直接加第三相 | 否决 | "两相平行界面"假设（solveLine 双截距）不适用于"沙堆轮廓+悬浮"形态 |
| **C：新模型 WaterSandField** | **选定** | 列标量结构化场，直接表达水面/沙堆/悬浮三种形态 |

### 4.2 数据结构（列标量三相）

```
每列 c：
  waterTop[c]        水面行号（浮点，全列由体积守恒解出）
  sandTop[c]         沙堆表面行号（浮点，沙丘轮廓）
  hs[c] / hl[c]      该列重沙/轻沙厚度（hs+hl = 水面到沙堆面的堆高）
  suspH[c] / suspL[c] 悬浮在水中的重/轻沙量
```

### 4.3 动力学（每帧）

1. **沉降**：悬浮沙按沉降速率向沙堆转移，vH > vL（初值比约 2~3 倍，调参面板可调）；v 的绝对值体现水介质阻力（低于真空气氛）。
2. **分选**：重沙落点在沙堆表面时以概率 pPen（0.3~0.5）穿透表层进入内部（穿透深度受限），轻沙停在表面 → 重沙集中于下部/内部、轻沙覆盖上部/外围；混合带宽度由 pPen 与穿透深度控制。
3. **安息角**：相邻列 sandTop 高差超过 tan(安息角) 时表层沙（先轻后重）向低列滑移，滑移量限速（复用 FluidField budget 思路）保证平滑。
4. **摇晃悬浮**：复用 E 扰动能量，E 注入时沙堆表层按比例转回 susp（重沙先扬起），E 衰减后重新沉降 → "摇晃悬浮、静置再堆积"。
5. **水面**：由"总水量 - 沙堆占体积"反推 waterTop，静置水平、倾斜时按 tan 倾斜（复用 solveLine 二分求水平线方法）。水与沙之间无质量交换。
6. **守恒**：water、Σhs、Σhl 各自为常量；susp ↔ 沙堆是相内转移，不改变相总量。
7. **倒立**：沙堆永远贴重力近端；渲染与 step 的行号基准随重力方向翻转（同 B2 经验）。

### 4.4 渲染

- 新增 MODE_WATERSAND（调参面板第四模式）：水区纯色/微渐变 + 沙堆轮廓（sandTop 贝塞尔平滑，两沙按 hs/hl 堆叠 + 混合带）+ 悬浮沙散点（确定性相位噪声，密度 ∝ susp，E 衰减时向沙堆收拢）+ 液面高光。

### 4.5 已接受的近似（设计取舍，明示）

- 列标量无法表达"单列内重沙夹在轻沙中间"的多层结构，接受单混合带近似（与 FluidField ero 同一取舍）；PROJECT_GOALS 只要求"整体上两沙颜色分区可辨"，满足。
- 悬浮沙先按沿水深均匀分布实现；若 SV-05/06 打分不达标，再引入按沉降速率的深度分布。

### 4.6 单元测试

- 三相各自守恒（摇晃角序列下 water/Σhs/Σhl 恒定）；
- 分选：静置后沙堆上 1/3 区域重沙占比显著低于下 1/3（阈值断言）；
- 安息角：超角沙堆倒塌、亚角静止零操作；
- 沉降时序：vH 先于 vL 沉完；长时静置沙堆零漂移。

## 七、风险与预案

1. **E 液滴仅渲染层**可能被质疑"物理不真实"：在测试报告 §5 结论区分中明确——模拟层零交换是**更强保证**（守恒精确成立），液滴为渲染层观感装饰，SV 打分确认观感即可。
2. **WaterSandField 列标量近似**导致沙堆内部结构单一：见 4.5，满足目标文档要求；如后续要求真多层，需引入每列分层表，成本显著上升，暂不做。
3. **场景二性能**：新增三相每帧计算为 O(cols)，与现有同量级，预计不影响 60fps 目标；如悬浮沙散点绘制开销大，降为按列条带绘制。
4. **渗透相关旧断言**：SandGridTest 中与异相推挤/slideChance 相关的断言在场景二调参时需同步更新（遗留已知项）。
