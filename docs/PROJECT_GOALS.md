# 流沙画（流麻）App 工程目标文档

> 文档版本：v1.0　日期：2026-10-13
> 工程：HelloWorld（HarmonyOS 流沙画 App，com.example.helloworld）

---

## 一、总目标

在手机容器（画布）内高保真复现"流沙画/流麻"的物理表现与视觉观感，对标抖音流沙画视频的验收标准：**细沙质感、平滑沙丘界面、倾斜即流动、静止后稳定**。

工程当前已有两种物理模型与三模式渲染（细沙 / 流体 / 混合），本文件明确后续开发必须达成的**两个目标场景**与**容器动态要求**。

---

## 二、目标场景

### 场景一：两种不互溶液体（油水分层）

**初始状态**
- 容器内装有两种不互溶、密度不同的液体（例如蓝色水 + 绿色油），初始可以混合摇晃后注入，或直接分层注入。

**物理要求**
1. **不相溶**：两相之间无质量交换，各自体积（粒子数/积分量）严格守恒。
2. **密度分层**：静置时重相（水）沉底、轻相（油）浮顶，界面为**近似水平的直线**（允许轻微波动，不允许沙丘状起伏）。
3. **界面动力学**：摇晃/旋转扰动后界面出现波纹与卷曲，静置后界面在数秒内恢复水平。
4. **快速回复**：翻转容器后两相在 2~4 秒内完成上下交换（重相重新到达底部），期间可出现液滴/液柱形态，最终回归层状。

**验收标准**
- 分相守恒：模拟层与渲染层分别验证，重相、轻相各自总量不随时间变化（误差 < 0.1%）。
- 静置判据：连续 N 秒液面斜率与界面斜率均小于阈值；界面波动幅度小于指定像素数。
- 视觉判据：界面线平滑、无锯齿；两相颜色边界清晰，允许 1~2 像素过渡带。

### 场景二：水中两种重量的沙（需堆积成形）

**初始状态**
- 容器内为水（液体相），另有两相颜色不同、**沉降速度不同**的沙（重沙 / 轻沙），初始混合注入。

**物理要求**
1. **液体环境**：沙粒在水介质中受浮力与阻力，沉降速度明显低于真空气氛，且**重沙沉降快、轻沙沉降慢**。
2. **堆积与安息角**：沙沉到容器底部或既有沙堆表面后堆积，形成**平滑沙丘状轮廓**；安息角可调（由滑移概率控制），超过安息角的表层沙缓慢滑落。
3. **两沙区分**：重沙先沉、集中于沙堆下部与内部；轻沙后沉、覆盖于上部与外围。允许渗透混合带存在，但整体上两沙颜色分区可辨。
4. **沙在水中的整体表现**：静置后沙堆稳定不漂浮；摇晃时沙被整体扬起、暂时悬浮于水中，静置后重新沉降并堆积。
5. **水相表现**：水保持水平液面；沙堆不占用的水域在静置时无明显对流。

**验收标准**
- 分相守恒：水、重沙、轻沙三相各自总量守恒。
- 堆积判据：静置后沙堆轮廓平滑（贝塞尔/曲线渲染无锯齿），沙堆坡度不超过安息角上限。
- 分选判据：沙堆下部重沙占比显著高于上部（量化：上/下区域颜色统计比达到设定阈值）。
- 动态判据：摇晃→悬浮→沉降→堆积全过程连续平滑，无粒子瞬移、无卡顿（目标 60fps，实测 ≥ 100fps）。

## 三、容器动态要求（两场景通用）

容器必须支持以下三类快速操作，且物理响应平滑、无数值爆炸：

| 操作 | 触发方式 | 物理要求 |
|------|----------|----------|
| **快速旋转** | 手势拖动（倾角映射）/ 传感器 | 重力方向连续变化（±180° 环绕归一化），角速度限制使翻转呈渐变而非跳变；旋转过程中液体翻卷、沙被扬起 |
| **倒立** | 180° 快速翻转 | 倒立状态渲染正确（重相画在"视觉顶部"对应位置，数据模型不因渲染分支改变）；翻回后正常回复分层/堆积 |
| **摇晃** | 快速往复手势 | 产生瞬时扰动使两相暂时混合（液体卷入液滴、沙悬浮水中）；停止后**必然恢复分层**——场景一回归油水分层，场景二沙重新沉降堆积 |

**通用约束**
1. **暂时混合 ≠ 永久混合**：任何摇晃强度下，静置足够时间（数秒~数十秒）后系统必须回到分层稳定态，不允许出现永久乳浊/永久悬浮。
2. **守恒始终成立**：旋转、倒立、摇晃全程，各相质量守恒（这是最高优先级不变量，任何改动不得破坏）。
3. **传感器与手势切换**：手势操作期间传感器不接管；手势结束后传感器自动恢复（现有机制保持）。
4. **测试模式隔离**：录制验证期间重力全由手势构造，传感器永不接管，保证测试可复现。

## 四、当前实现基础与差距

| 能力 | 现状 | 与目标的差距 |
|------|------|--------------|
| CA 细沙模型（SandGrid.ets） | 两相渗透、安息角、四向重力，可用作"细沙"模式 | 渗透速率/概率需按场景二两沙分选调参 |
| 流体/高度场（FluidField.ets） | Float 高度场平直界面 + ero 混合带，水平界面 | 场景一直接复用；需验证摇晃扰动→恢复水平的动力学 |
| 三模式渲染 | 细沙 / 流体 / 混合，FPS 116-120 | 倒立翻转的流体/混合渲染尚未处理（已知缺口） |
| 传感器 + 手势 | atan2 全角域、±180° 归一化、角速度限制、手势/传感器切换 | 已满足容器动态要求，保持回归验证 |
| 分相守恒测试 | SandGridTest 17 用例（部分断言待随渗透改动更新） | 需按两场景补充：场景一液体交换回复、场景二三相守恒与分选 |

## 五、里程碑建议（供开发/测试认领）

1. **M1 场景一打通**：FluidField 双液模式（两相不互溶、零交换），完成摇晃→静置→水平回复的自动化录制验证。
2. **M2 场景二打通**：SandGrid/FluidField 组合出"水中双沙"模式（水相 + 两沉降速率不同的沙相），安息角堆积 + 分选参数调定。
3. **M3 倒立渲染补全**：流体/混合模式倒立渲染分支，与传感器倒立数据打通。
4. **M4 全场景回归**：两场景 × 三操作（旋转/倒立/摇晃）的连拍录制 + 视觉验证套件固化。
