# P-012 C 层理锚点提案 v2：S4 界面联动与冻结前置

日期：2026-10-23。责任：designer。状态：**DESIGN_READY_FOR_MANAGER_REVIEW / ANCHOR_FREEZE_PENDING_REFERENCE_AND_DEVICE_BASELINE / NOT_VALIDATED**。承接 [v1 提案](design-P012-C-stratification-anchors-v1.md)，保留其历史数字与结论，不改 E/A/B `VALIDATED/CLOSED`、E3 已冻结锚点、SV 量表、物理 128 列或测试代码。C/D 为 `UNLOCKED / NOT_VALIDATED`。本稿只给候选方法与冻结所需证据；manager 验收后再排参考测量、正式锚点 revision 和实现。

## 1. 新证据的精确含义

[S4 开题 §5](design-P011-S4-deep-creep-bh-v1.md)要求 `S4 OFF/ON × C OFF/ON` 四格；物理界面弯而纹路不弯时，归因于 C 的只读映射缺口，不允许物理 PASS 代联合 PASS。[sweep 二轮回执](report-P011-S4-sweep2-v1.md)与[原始 JSON](../test/reports/s4-sweep-v2.json)给出候选 `{kDeep:0.1/0.2, muY:0, hMin:0.5}`：在**预先已有** `bh` 小起伏 5.41px 的定向场景，300s 后振幅分别为 4.68px/4.38px，衰减比 0.865/0.810；对应振幅改变量仅 0.73px/1.03px。这里的振幅是原脚本对 `bh` 去宽窗趋势后的 **P90−P10 显示像素差**，不是峰高、逐点位移或新生成的波。平直界面对称场景应无 S4 通量；73px 大起伏初态在域内参数下 300s 仅衰减 0.9–8%，不得借它宣称 2–8px 产品效果。S4 当前给的是**候选可观测物理底座**，仍不是最终物理 `VALIDATED`。

用户需求锚定仍是“上层白色云雾、下层明确的沙子颗粒与沉积层次”[需求稿](p012-water-cloud-sand-demand-anchor-v1.md)。C 的效果是内部沉积薄层随材料界面缓弯；顶光塑形归 E2，流束和前缘毛边归 D。C 不用整片迎光/背光色块、速度拉丝或加浓白雾凑锚点。

## 2. C1 数值候选复核：保留区间，改测量坐标

v1 的 `22–43` 显著极值/完整厚沙 ROI、`16.2–31.7` 个分析深度点/主周期、`±4–8` 灰度有序层调制与 `54–81` 灰度完整图像 row-mean 极差，**全部继续是未冻结候选**。S4 的 2–8px 空间起伏不直接证明这些数应提高或降低：若层纹在材料坐标中只是随 `bh` 平移，其真实层数和材料周期不变，单幅屏幕水平 row-mean 却会因各列相位错开而衰减。对简单纹路 `I(x,z)=cos[2π(z-bh(x))/λ]`，同一屏幕行的横向平均振幅乘以 `|mean_x exp(-i2πbh(x)/λ)|`，该因子可接近 0。因此“弯后 rowOscCount 下降”不能单独判 C 失败；也不能改滤波阈值强行把原 22–43 找回来。

**v2 候选主方法 `layerExtrema_C_v2_registered`：** 在同一纯沙 x 区及冻结材质 mask 内，采集可追溯的 `bh` 显示界面 `b(x)`，把轻沙层的纵向采样注册到 `ζ_L=z-b(x)`；重沙层只在靠近 `bh` 的有限材料深度范围做连续位移 `ζ_H=z-w_H(z,b)·[b(x)-mean_x b]`，其中 `w_H` 从远离界面的 0 平滑到界面处的 1。混合层由本层真实边界单独注册，边界两侧不得拼出假峰谷。`w_H` 的作用宽度、插值与遮罩过渡须在实现前固定并做静止/动态消融，不能按每帧观测结果选择；轻沙的基准相位跟 `bh`，重沙远底层不因 `bh` 微动全层呼吸。此式是**只读渲染映射和测量坐标候选**，不改 `bh/bl/mh/ml`、材质库存或 C1 的稳定深度相位。

同一批帧必须并列输出：旧 `rowOscCount`/原生屏幕 row-mean、v1 `layerExtrema_C_v1`、v2 **注册后**的整段极值及 H/L/M 分带计数、原生行数/有效层厚、P90−P10 行均值极差、三横向子区剖面。`N_total` 只在各分带有原生支持且边界峰谷去重时可汇总；22–43 原先是**整块厚沙区域**的候选，不给每个薄分带各复制一份 22–43。`350` 点仅为分析坐标，不能当 350 个原生像素。主要周期候选必须同时换算回原生 px 与材料深度；每周期原生有效行少于 v1 候选的 4 行、纯沙区不足以容纳目标层数时出 `INSUFFICIENT_LAYER_SUPPORT`，不得靠放大/插值生成层数。完整图像极差 54–81 仍是**参考匹配诊断**，`±4–8` 调制按 `R_full(ON)≤R_full(OFF)+16` 的 v1 上界约束，不让 C 为追整图动态范围抢 E2 的职责。

**冻结前数值决策：** 先在目标参考与当前 C OFF 真机基线上，以同一 `methodId/ROI/显示尺度/mask` 重测；C ON 属于**冻结后实现验证**，不能用它的结果倒调阈值。若目标在注册后不落原 22–43 或 54–81，保留原记录并给差异归因，由 manager 批准正式 revision 的适用区间。没有可辨 `bh` 参考界面时，报告 `REFERENCE_INTERFACE_UNIDENTIFIABLE` 并用可见层线人工标注误差作补测，不把应用端的物理 `bh` 真值与参考帧的猜测界面当同精度配对。C1 静态层数的正式阈值、幅度上限和薄沙适用范围在上述结果出来前均不冻结。

## 3. S4 × C 四格与条纹跟随算子

同一合法初态、输入、物理 seed、renderer seed、设备显示尺度与构建版本；保存 S4 OFF/ON **两份物理快照**，每份各渲染 C OFF/ON，禁止四格各跑不同随机轨迹。至少覆盖平直零驱动对照、分选后 5.41px 小起伏候选及另一个 2–8px 合法幅度档；时间窗至少有 `t=0/30/60/120/300s`，实际采样密度及场景由 tester/effector 预注册。真实 `S4 ON` 的 `bh` 来自物理快照，C OFF/ON 仅改变只读渲染；S4 路线私有 `routeId` 与 C 外观配置分别记账。该实验不与 `±45°/5.1s` SLIP 收敛目标混作一项。

| 物理 × 外观 | 要回答的问题 | 不能宣称的结果 |
|---|---|---|
| S4 OFF / C OFF | 基准 `bh` 轮廓、沙面和 E/A/B 材质；画面无 C 层纹 | 没有层纹不等于物理平直 |
| S4 ON / C OFF | `bh_ON−bh_OFF` 是否真由 S4 守恒交换造成、S 是否不变、零驱动场是否零通量 | 界面动了不等于条纹跟着动 |
| S4 OFF / C ON | C1 的静态层数、周期、幅度和原有 `bh_OFF` 的形状附着 | 已有弯纹不等于响应 S4 新变化 |
| S4 ON / C ON | C 的纹线是否从 `bh_OFF` 随 S4 变化到 `bh_ON`；纹理不滑屏、不呼吸 | 四格最显眼的一帧不能代替长窗联动 |

在 `bh` 上下各选至少一条持续可追踪的内部明暗脊线 `y_j(x,t)`，剔除边界亮线、混合区不连续片段和水雾。与 `b(x,t)` 使用同一列插值/显示尺度，先去各曲线的横向整体平移，再分别计算：

- **空间弯曲量** `A_b(t)=P90−P10(detrend[b])`、`A_j(t)=P90−P10(detrend[y_j])`，方法与 S4 sweep 的宽窗去趋势保持同源；报告 `A_j/A_b`、曲线相关 `ρ_j=corr(detrend[y_j],detrend[b])` 与最佳横向相位滞后 `lag_j`。对底部远离 `bh` 的重沙纹线允许较小弯曲，但必须与预注册的 `w_H` 衰减一致；靠近界面的纹线才用于满幅比值。
- **动态跟随量** 对同一 `t` 比较 `Δb=b_{S4 ON}−b_{S4 OFF}` 与 `Δy_j=y_{S4 ON,C ON,j}−y_{S4 OFF,C ON,j}`，各去全局纵移；报告 `corr(Δy_j,Δb)`、两者 P90−P10 幅值比、残差 `P90|Δy_j−Δb|` 与逐帧抖动。若层纹仅在初态弯曲却不随 S4 的 `Δb` 更新，静态可读性或许成立，**联动 FAIL**。只看 C OFF/ON 的颜色差或屏幕 row-mean 无法替代这条空间位移证据。
- **可辨识门** 先用同帧重复描线、重复导出和两人界面标注估计 `σ_b/σ_y`；候选要求 `Δb` 的配对信号至少大于合成测量不确定度的 3 倍，否则标 `S4_C_DYNAMIC_UNRESOLVED`，不报 PASS/FAIL。此门的最终倍数及 `ρ/幅值比/lag/残差` 阈值须在参考同口径复核、S4 `bh` 离线数组和**与实现无关的理想弯曲/固定屏幕相位两种合成 oracle**上由 manager 采前冻结；正式 C ON 四格只用于验证，不参与调线。现有候选参数 300s 的振幅改变量仅 0.73–1.03px，不能预设单帧 JPEG 肉眼或整像素跟踪足以辨认；可用原始帧的亚像素脊线拟合与时间配对，但**放大图像不算增加物理可见层数**。

**联合 PASS 的三层逻辑（数值线待冻结）：** ① S4 物理臂先独立通过其 H/L 守恒、预算、`S` 不变、非均匀驱动归因和 `bh` 时序验收；sweep 候选命中不是这一步的最终签字。② C 渲染臂在相同物理快照上通过已冻结的层数/周期/幅度、E/A/B+E3 回归、帧时与既有 SV≥3，C OFF/ON 不能靠雾/颗粒变化凑数。③ 四格联动的空间及动态跟随算子在可辨识门内达到**参考导出的**容差，effector 确认“沉积层随界面缓弯、沙仍像沙、无屏幕贴纸感”。三层全满足才写 `S4×C JOINT_PASS`；缺任一层写对应 `PHYSICS_PENDING / C_ANCHOR_PENDING / COUPLING_UNRESOLVED / COUPLING_FAIL`，不以另一层 PASS 代偿。

## 5. C2/C3 处置与 C/D/E2 归属

| 候选 | v2 裁定 | 重新开启条件 |
|---|---|---|
| **C1 稳定材质深度层纹** | 继续作为主路线。只读现有相层，采用 §2 的材料注册坐标与 S4 §5 四格联动；视觉“历史感”仍是代理，不声称真实沉积年代。 | 若参考证明目标层纹必须由真实批次身份维持，或动态跟随在合法只读映射下持续失败，再重评表示。 |

**本轮完成判断：** v2 已把 C1 的弯曲测量、S4×C 四格、不可辨识分支、参考/真机资产和 C2/C3 路线边界写成可执行提案；由于目标同口径测量、当前 C OFF 厚沙基线与独立合成 oracle 尚未齐备，状态维持 `ANCHOR_FREEZE_PENDING`，**不能写 `FROZEN` 或 `VALIDATED`**。C ON 构建与真机四格是冻结后的效果验证资产，不应倒置为设定锚点数字的依据。
