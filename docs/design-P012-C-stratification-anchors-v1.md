## 1. 可观测效果定义：看得到沉积层次，不虚构年代

**C的成功现象**：在有足够可见厚度的沙体内部，出现横向连续、间距与强度有缓慢变化的明暗薄层；明暗层能在颗粒纹理下面被读出，随已有层界面起伏，局部混合时变淡。静止时层纹稳定；沙层增长时逐渐露出新层纹，侵蚀时从实际被削去的部分消失；倾斜/回正后仍附着于材料区域，不能像贴在屏幕上的横线或逐帧滚动的百叶窗。

这里的“历史感”是**沉积层次的视觉代理**。现有 `bh/bl/mh/ml` 只有当前有序重层、有序轻层和混合层库存，没有沉积时刻、每批来料身份或真实逐层年龄。推荐路线不声称记录了“某时刻沉下来的这批沙”。明暗条纹形成机制假设为：真实材料沉积中局部配比/堆积差异可能产生层状色调；本设计用稳定的层内深度纹理表达这种外观，物理机制真实性未由当前字段证明。

| 可观察情形 | 应出现的C效果 | 不可据此替代的目标 |
|---|---|---|
| 厚沙体静置 | 多层弱明暗带、横向可跟踪，不闪烁；不是只有一条heavy/light分界 | 单靠颗粒噪声多出局部极值不算层理 |
| 当前层厚增加/减少 | 真实mask内增加或裁掉条纹，不整层重新缩放条纹凑条数 | 不增加库存、几何厚度或沙丘高度 |
| 混合层增大 | 层纹对比低于有序层，配比变化连续 | 不把混合瞬间解释为真实地层年龄重排 |
| 局部倾斜/流动 | 层纹弱随层界面和可信材质位移变化，静止即停 | 沿流线拉丝、前缘毛边属于D；顶光迎/背光分区属于E2 |

原差距表“2–4块迎光/背光分区”保留为E2联合诊断，不要求C通过加黑白块伪造受光面。水雾矩形块不属于沙内层理。

### 2.1 有尺度的数值提案

测量对象为同一纯沙ROI的横向平均亮度剖面；将该ROI的有效纵向深度参数记为 `u∈[0,1]`。为算法和报表统一表达，使用350个分析深度点（不是把物理或屏幕改为350行，也不是新造图像细节）。**350是本次提议的分析坐标，源于历史350行分析的可读性，绝不是已证实目标22–43次使用的原ROI高度。** 所有候选区间均须按§2.2对参考复核后冻结。

| 项 | 候选区间/判定 | 论证与适用限制 |
|---|---|---|
| 显著极值数 `N_C`（峰与谷都计） | **目标22–43/完整有效ROI；候选最低可接受20，超过43列过密待复核** | 22–43沿早期参考，20沿原算法≥20。不能写成22–43个完整周期；对应约11–21.5个周期。未完成参考复核前，不作为正式MUST-PASS |
| 归一化极值密度 | `N_C/349≈0.063–0.123`/分析行；候选下限20/349≈0.057 | 显式绑定ROI深度；不能在26px薄带和350px厚带上直接比较绝对次数 |
| 主要明暗周期 | `lambda_350≈2*349/N_C`，目标约 **16.2–31.7** 分析行/周期 | 原算法12–18显示px若直接用于350行ROI，约产生39–58极值，可能过密。候选按材料深度标定，禁止简单把12–18px硬编码于所有设备 |
| 完整合成row-mean极差 `R_full` | **54–81灰度级：参考匹配候选区间，联合诊断，不是C独立增益下限** | 需包含相同E光照、B颗粒及同构图，当前v1参考并非全部在此范围；不可强迫所有参考帧/薄带都达54 |
| C自身亮度调制 | 有序层幅值候选 **±4–8** 灰度级；混合层减半 | 延续§6温和层纹方案，避免画成硬条码；不是把总极差54–81全交给C |
| 单项主观 | SV-07重点判断沉积层次/自然度；SV-05看过渡是否新增硬边，SV-06看颗粒与液体质感是否退化；沿现有单项**≥3**口径 | 不新建或改写评分量表。需完整既有动作录像与C OFF/ON对照，说明层理的可读改善，不能凭静态计数代替主观 |

**幅值可行性约束：** 若同ROI下C对最终亮度的逐像素增量满足`|deltaY|≤8`，则行均值增量也≤8，`R_full(C on)≤R_full(C off)+16`，且`R_full(C on)≥max(0,R_full(C off)-16)`。所以不能保证C能把任意基底抬到54；例如旧s99w薄带rowOscRange=35.2，即便加到最大也只有51.2的理论上界（此薄带本身不适用完整层理数量目标）。若匹配厚沙区也缺全局明暗范围，交E2/场景归因，不加大C条纹反差去冲数。

### 2.2 拟议测量协议：避免“数出噪声就通过”

1. **身份/场景**：同物理build、初态、输入、renderSeed、E/A/B配置，至少3对 `EAB` / `EAB+C` 配对；静置、慢倾、回正分开。参考f0/f5静态、f2/f6动态分别对照，8帧全保留。沿既有场景，不为纹理验收改物理预算/geometry；缺厚沙支持须由effector登记适用场景，经manager认可后补场景，不能把薄沙带画厚。
2. **ROI与尺度**：effector采前标注同材质沙内区域，排除界面雾、边框、纯背景、明显跨相界线；固定显示尺度和有效横向支撑，记录原生宽高。优先选连续纯沙矩形，不能让每行参与平均的列集合任意改变。对应参考/ON/OFF都保留原坐标、mask、剖面及原生v1结果；350点分析用单调线性插值，低分辨率上采样不算新增独立样本。
3. **分辨率资格**：每个拟检测周期至少有4个原生有效行采样（设计抗混叠要求，待冻结），即22极值需约44个纵向采样间隔，43极值需约86个。26px薄带不能承载完整22–43目标，输出 `INSUFFICIENT_LAYER_SUPPORT`；不得归一化放大后硬凑条数。薄层仍需验“少量层纹自然、无阶梯、无假动”，但不据此完成厚层数量项。
4. **剖面定义**：`p(u)=mean_x Y(x,u)`，Y沿v1 RGB亮度公式。保留未滤波极差`max(p)-min(p)`；另对350点剖面做5点盒平滑，以交替峰谷的**峰谷落差≥2灰度级**和相邻极值距离≥3分析点筛选；不足prominence的相邻小峰谷合并后重查，平顶取中点，端点不计。该算子是新候选，不冒用v1的`rowOscCount`；命名 `layerExtrema_C_v1`，由tester在冻结前写清合并顺序与合成剖面算例。
5. **同口径参考先行**：先让tester/effector用上述候选协议解释目标帧是否真的给出22–43及54–81。如果不支持，记录原观察与新定义的差异，交designer/manager裁定修订区间或ROI；不得为了复现22–43反复试滤波器、挑帧。正式附表revision与参考结果未冻结前，当前数字只是设计提案，C保持 `ANCHOR_NOT_FROZEN`，不预签验收。
6. **C归属证据**：主比较保持B开启，测同快照`EAB+C − EAB`差分及纯C调制剖面，确认计数增量来自层纹；另做同素材B关闭诊断，C有/无都采用同条件。B关闭图只作消融，不能用于正式EAB+C通过。原生颗粒HF、G std及E/A/B已通过指标需回归；不以更高HF或随机点增加声称层理成功。
7. **横向一致性**：将同ROI按x等宽分成左/中/右三段，各报剖面、极值位置及带状连续性；明显仅一列的阶梯或几个噪点不算全宽层纹。弯曲导致全宽行均值相消时另报沿已知材料边界的深度剖面，标不同methodId，不用后者偷偷替换主计数。稳定时间段逐帧对照，禁止只取层纹最显眼的一帧。

“候选最低20、目标22–43、R_full参考54–81”均留待上述同口径冻结，不把早期观察升级为未经验证的硬线。本次不修改评分、冻结附表或测试用例；manager可先验收效果定义与路线，正式效果签字依赖本测量前置完成。

### 3.1 C1 公式、时序与生命周期

只读数据由现有 `P012MaterialFrameView` 提供：`bhAt/blAt/mhAt/mlAt/sandTopAt`，以及adapter身份/配对状态；几何单位与显示高度映射沿既有renderer。原始相库存仍用于守恒核对，不参与外观写回。

```text
hH=bh; hL=bl; hM=mh+ml; S=hH+hL+hM
baseH=0; baseL=hH; baseM=hH+hL
depth_j = materialHeight(y) - base_j(x)         // 只在该材料区mask内取值
phase_j = depth_j / lambdaMaterial_j + warp(x - acceptedUV_j)
deltaY_j = envelope_j * amplitude_j * bandNoise(seed_j, phase_j)
Yout = clamp(Y_E_base + deltaY_j, 0, 255)      // C先于B/A，保留原材料色相
```

`bandNoise`为零均值、有界[-1,1]的连续带纹，种子固定，相邻周期轻微不规则，禁止逐列独立随机相位。`warp`沿x慢变、幅度候选≤1/4周期，避免横向平均把层纹完全抵消；其数值仍属定标候选。`lambdaMaterial`在run首个合格厚层场景按约16–32分析行对应的材料深度冻结，之后不随每帧层高归一化，否则沉积一点会让整堆层纹伸缩；resize仅改显示映射。

有序层幅度±4–8，混合区±2–4；空层不绘制，边界envelope平滑衰减，厚度不足一个周期只露其实际片段。新增长度仅揭示稳定纹理的更多部分，不靠时钟推进条纹；已有UV代理仅在pairValid和可信材料位移时推进横向warp。当前字段无法恢复垂向真实拉格朗日运动，**本路线不承诺逐粒历史保真**；若动态出现纹理贴纸/整体游移，回到方案评审而非放行。

伪代码时序：`只读adapter验身份 → 计算层高与连续材质场 → E底色 → C层纹调制 → B颗粒 → A散射 → E高光/边框`。层纹缓存由renderer持有，profile/UV缓存复用，逐帧无全屏像素重生成，不构造128×层数的独立Path。具体缓存表示/采样可行性由architect在ArkTS/Canvas能力范围内翻译；这里只给复杂度与预算，不假定未核实shader接口。

生命周期：run/reset、注入、倒立、TEST/EXPERIENCE切换及物理实例变化按既有epoch断配对，重建当前材质基线，不保留虚构年代；方向反转不换seed；C开关恢复时按当前物理重建，不能追赶关闭期间的假历史。几何/DPI变化重建显示映射与必要bitmap，释放旧资源；空相消失，缺帧冻结位移相位。相同快照/seed/配置给相同层纹；无独立计时动画。C2若未来启用，批次栈同样随epoch清空。

## 4. 与E3的接口：共享连续材质采样，不增加物理列

水平层纹主要沿y改变亮度，列边界阶梯主要沿x产生跳变；方向有助于分诊，但并非完全互斥：warp、斜沙面和矩形tile都可混入两向频率。因此C不能通过降低水平梯度就宣称E3已修好，也不能把竖缝调亮后数成新的横层。

拟共享一个renderer内部 `MaterialColumnSampler`：输入只读128列层高、已批准显示坐标映射、geometry/config epoch；输出任意显示x的连续材料层高/配比供C着色，E3未来也可用于雾alpha/材质密度采样。**建议以非负权重线性插值各层厚度，再累加边界**，不分别做易过冲的无约束高阶边界样条。线性插值保非负、保层序；这只用于光学着色，轮廓和物理数组不改，仍按既有沙mask裁剪。

- C可先用现有曲线/连续采样能力实现，不能以等待E3全面修复为前置；新增共用接口只做C所需最小部分，E3稍后复用。
- 若提高**渲染**采样密度，显式登记倍率r与额外成本，工作量从O(128)变为O(128r)；物理cols=128不变。不要C和E3各建一套插值缓存，或每增加一采样列就增加一次透明draw。
- C使用跨列连续相位/同seed纹理；避免在列/组边界重置噪声、重置层纹高度或独立量化亮度。E3仍须单独处理雾64px/tile和颗粒256px重复问题，C不能靠叠条纹遮盖它们。
- 诊断分别看纵向剖面的水平条带、列边界处横向跳变、二维周期峰；正式效果仍由同场录像和SV判断，不能仅凭两个方向“正交”就免掉回归。

## 5. 与E3/F1的成本联合评估

这里的F1指gap表的 **100fps归因项**，不是旧架构§10中的同名“pattern缓存F1”。100fps对应单帧10ms时间尺度；C的0.15ms CPU目标约占1.5%，但GPU合成/overdraw可能大于CPU提交耗时，不能据此宣称100fps可达。

保持原C预算：增量CPU P95≤0.15ms、draw≤16、常驻≤0.25MiB；全路线≤160新增draw、常驻≤4MiB、重建峰值≤8MiB均不提高。以上为设计预算，必须测量。旧EAB34–60fps是已通过的旧窗口口径，不是100fps证明，也不把“还在30以上”作为C可任意降速的理由。

| 配对组合（后续执行） | 目的 |
|---|---|
| EAB ↔ EAB+C，E3关闭 | C自身CPU、GPU填充、draw、缓存、帧时P50/P95增量；至少3配对块，同build输入 |
| EAB ↔ EAB+E3，C关闭（E3交付后） | 分离插值/去周期成本 |
| EAB+C ↔ EAB+C+E3，同时对照前两组 | 捕捉共享缓存收益或额外合成成本，不能只把单项P95相加 |
| F1完整预算账本 | 由developer归因物理/UI/渲染/合成/呈现节拍与设备刷新能力，统一G2.7 fpsP95口径，不能把1000/帧时P95当fpsP95 |

C不等待F1最终结论才做效果实现，但实现应输出可归因成本供后续使用；不在本任务调度F1架构改造。新增纹理需要全容器透明覆盖时，优先评估与现有沙底色缓存合成/局部clip；不要重现旧颗粒层整盒平铺的性能退化。超预算回architect重排渲染，不能减物理列、漏step、隐藏关B/A或降帧求通过。
